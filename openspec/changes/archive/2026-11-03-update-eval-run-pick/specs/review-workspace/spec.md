## ADDED Requirements

### Requirement: 정답지 탭 검토 고르기
화면은 정답지·채점 화면 정답지 탭의 검토 목록 위에 검색 칸(검토 번호·검토 이름), [모두 고르기]·[모두 해제], 고른 수 "검토 n건 고름"을 보여야 한다(SHALL). [모두 고르기]·[모두 해제]는 검색으로 보이는 검토에만 적용하고, 고른 수는 검색과 상관없이 채점에 들어갈 검토 수를 센다. [제안]

#### Scenario: 검토 골라 채점하기
- **WHEN** 사람이 확인한 판정이 있는 검토 3건이 처음에 모두 골라진 정답지 탭에서 [모두 해제]를 누르고 검토 번호로 1건을 찾아 [모두 고르기]를 누른 뒤 "지금 채점하기"를 누르면
- **THEN** [모두 해제] 뒤 "검토 0건 고름"이, 찾은 뒤에는 그 검토만 목록에 보이고 "검토 1건 고름"이 보이며, 채점 요청에는 그 검토 하나만 들어간다
