## Context

`Eval.tsx`는 `pick`(검토마다 바꾼 넣기)과 기본값(`reviewed > 0`)으로 고른 검토를 정한다. `GET /api/eval/runs`는 모든 분석 끝난 검토를 준다.

## Decisions

- 검색은 화면에서 거른다(검토 번호·검토 이름에 든 글자, 대소문자 무시). 서버 API는 바꾸지 않는다.
- [모두 고르기]·[모두 해제]는 보이는 줄만 바꾼다. 검색해 둔 몇 건만 고르려면 [모두 해제] → 검색 → [모두 고르기]. 숨은 줄의 고름은 남긴다.
- "검토 n건 고름"은 전체 고른 수, 검색 중이면 "· 보이는 검토 m건"을 덧붙인다. 채점에 들어가는 수와 같다.
- 버린 대안: 처음 고름을 없애기 — 검토가 적은 DB에서 바로 채점하던 흐름이 바뀐다. 쪽 나누기 — 이번 요청 밖.

## Risks

- 검색으로 숨긴 검토도 채점에 들어간다. 고른 수를 늘 보여 알 수 있게 한다.
