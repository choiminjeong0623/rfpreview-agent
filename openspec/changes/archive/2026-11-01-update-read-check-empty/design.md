# Design

## 결정

- 0줄 판단은 화면이 받은 `/read-checks` 목록 길이로 한다. 서버가 이미 문서별로 모든 점검을 돌린 결과다.
- 살핀 것 네 가지는 탭 머리의 종류(표·그림·단위·위치)와 같은 말로 적는다. 그래서 "표 0 · 그림 0 · 단위 0 · 위치 0" 머리 표시와 이어진다.
- 읽지 않은 문서(스캔·그림 문서)는 "그림 · 문서를 읽지 않음" 줄로 나오므로, 0줄이면 모든 문서를 읽은 것이 맞다.
- 목업 v4.57에는 0줄 화면이 없다. `SCR-08-2_공유.md`에 남긴다.

## 대안

- 머리 표시를 "모두 확인함" 그대로 둔다: 사람이 확인한 것과 확인할 것이 없는 것이 같아 보여서 버림.
- 상신 창 줄도 "점검 없음"으로 나눈다: 결재 화면 응답에 전체 줄 수를 더해야 해서 이번에는 뺌.

## 위험

- 실제 RFP는 점검 줄이 많아 0줄이 거의 나오지 않는다. 시연용 합성 파일에서 주로 보인다.
