# Design

## 결정

- **"건"은 개수, "행"은 위치.** 판정·요구사항·목록 항목을 세는 말은 "건", 원문 위치(파일 · 절 · n행)는 그대로 "행".
- **상태 이름은 업무 결재·메일 용어.** 미발송 · 회신 대기 · 24시간 넘게 회신 없음 · 회신 완료. 진행 단계는 생성 → 메일 발송 → 회신 완료.
- **제외.** 일탈·질의 목록에서 빼기, 제안 포인트 버리기, 한꺼번에 확정에서 빼기를 모두 "제외"로 같게 쓴다. 상태 이름(DISCARDED·REMOVED)도 "제외".
- **스펙은 문장만.** 시나리오 이름·요구사항 이름은 바꾸지 않고(테스트 이름·추적표 연결), 본문 문구만 MODIFIED로 바꾼다.

## 대안

- 상태 이름을 영어 코드와 같게(예: 처리 중/완료): 협조 요청 흐름이 메일 발송·회신이라 업무 말이 더 맞아 버림.
