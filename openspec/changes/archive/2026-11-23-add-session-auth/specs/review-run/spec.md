## MODIFIED Requirements

### Requirement: 검토 정보
시스템은 실행마다 사람이 입력한 검토 정보(사업명, 검토명, 고객사, 국가, 제출 마감일, 담당 엔지니어)를 저장하고 검토를 시작할 때와 시작한 뒤에 받을 수 있어야 한다(SHALL). 제출 마감일은 시작할 때 꼭 받아야 하며, 없으면 실행을 만들지 않고 "제출 마감일을 입력해 주세요." 오류를 내야 한다(SHALL). 나머지 칸은 비어 있어도 되며, 시스템이나 언어 모델이 빈칸을 채우지 않아야 한다(MUST NOT, CR-04). 담당 엔지니어가 비어 있고 시작한 사람(로그인한 사용자)이 엔지니어 역할이면 그 사람으로 둔다. 담당 엔지니어는 엔지니어 역할 사용자만 될 수 있다(SHALL).

#### Scenario: 검토 정보와 함께 시작
- **WHEN** 엔지니어가 사업명 "Thai Binh", 검토명 "115·230 kV GIS 변전소 신설", 고객사, 국가, 마감일 2026-10-30을 넣고 파일 1로 검토를 시작하면
- **THEN** 실행 요약에 다섯 값이 그대로 보이고 담당 엔지니어는 시작한 엔지니어다

#### Scenario: 검토 정보 없이 시작
- **WHEN** 엔지니어가 마감일만 넣고 다른 검토 정보는 넣지 않고 검토를 시작하면
- **THEN** 실행은 그대로 시작되고 마감일과 담당 엔지니어(시작한 엔지니어) 말고 검토 정보 칸은 모두 비어 있다

#### Scenario: 마감일 없이 시작
- **WHEN** 마감일을 넣지 않고 검토를 시작하면
- **THEN** "제출 마감일을 입력해 주세요." 오류가 나고 실행은 만들어지지 않는다

#### Scenario: 엔지니어가 아닌 담당자
- **WHEN** 견적 담당 사용자를 담당 엔지니어로 넣으면
- **THEN** 담당 엔지니어는 엔지니어만 될 수 있다는 오류가 나고 바뀌지 않는다
