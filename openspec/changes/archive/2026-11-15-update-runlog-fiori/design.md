# Design

## 결정

- **시간 기준 하나.** 걸린 시간은 실행 기록 단계 시각(`run_step_time`)만 쓴다. 흐름 기록의 저장 시각 차이는 체크포인트 저장 시점이라 단계 시간과 기준이 달라 보이지 않고, 바뀐 값·사람 동작·멈춘 자리만 쓴다.
- **`clock_timestamp()`.** `now()`는 트랜잭션 시작 시각이다. 단계 함수가 첫 조회로 트랜잭션을 열고 끝까지 커밋하지 않으면 다음 `_set_step`의 `now()`가 그 시작 시각이 되어 시간이 다음 단계로 밀렸다. 실제 시각을 쓴다.
- **AI 시간.** 단계의 AI 요청 시간 합이라 동시 요청이면 걸린 시간보다 길 수 있다. 칸 머리 ⓘ에 적는다.
- **Fiori 대응.** Object Page(머리글 KPI·앵커 구역), Filter Bar(이름 붙은 고르기·초기화), No Data 안내, progressive disclosure(접는 프롬프트 판·ⓘ).

## 버린 대안

- 흐름 기록 시간도 함께 보이기: 같은 정보가 두 숫자로 남아 버림.
- 예전 실행의 단계 시간 고쳐 쓰기: 원래 시각을 알 수 없어 버림.
