# Design

## 만드는 방식

- 화면마다 목업 `<Page>.body.html`의 `<main>`을 JSX로 옮기고, 목업 JS의 화면 데이터(`R`, `ROWS` 같은 상수)를 `frontend/src/examples/SCR-xx.ts`로 옮긴다.
- 목업 CSS는 `frontend/src/mockup/<Page>.css`에 원본 그대로 두고 `usePageCss`로 그 화면에서만 켠다(다른 실제 화면과 같다).
- 데이터 정리: 사람 이름 → 역할("기술 검토 엔지니어", "견적 담당" …), 지명·고객사 → "예시 사업장", "예시 고객사", 프로젝트명 → "예시 사업 A" 같은 이름.
  금액은 넣지 않고 "영업 권한 필요".
- 띠는 `ExampleBand`(검토 상세 예시 탭과 같은 부품)를 `<main>` 맨 위에 둔다.
- 상태는 React `useState`만 쓴다. `localStorage`·API에 쓰지 않는다(저장하지 않음).

## 순서 (한 화면씩)

SCR-14 입찰 이력 → SCR-15 입찰 상세 → SCR-04 사업 현황 → SCR-05 사업 상세 → SCR-18 표준 문구 → SCR-19 정답지·채점 →
SCR-20 팀 현황 → SCR-21 공지사항 → SCR-22 시스템 공지 → SCR-23 자료실 → SCR-24 설정 → SCR-01 로그인.

## 로그인(SCR-01)

- 앱에는 로그인이 없다. 주소 `#/login`으로만 열고, "로그인"을 누르면 홈으로 간다(사용자는 머리글에서 고른다).
- 로그인은 앱 틀(메뉴·머리글) 밖에서 화면 전체를 쓰므로 예시 띠를 두지 않는다. 목업과 다른 점은 `docs/screens/SCR-01_공유.md`에 적는다.
