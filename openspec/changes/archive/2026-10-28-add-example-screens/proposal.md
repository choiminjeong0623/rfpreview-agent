# Proposal

## Why

목업 v4.57 메뉴의 화면 중 12개(로그인, 사업 현황·상세, 입찰 이력·상세, 표준 문구, 정답지·채점, 팀 현황, 공지사항, 시스템 공지, 자료실, 설정)는
백엔드 기능이 범위 밖이거나 아직 없다. 지금은 "아직 만들지 않은 화면" 자리만 보여서, 시연과 평가 때 목업의 흐름을 따라갈 수 없다.
2026-10-28 결정: 이 화면들은 목업 레이아웃 그대로 **예시 화면**으로 만든다(`docs/screens/_공통규칙.md` 6장, 로드맵 4단계).

## What Changes

- 예시 화면 12개: 목업 레이아웃과 예시 데이터(프런트 고정 데이터, API 호출 없음). 맨 위에 "예시 화면 · 실제 데이터와 연결되지 않음" 띠.
- 화면 안 단추·입력은 화면 안에서만 바뀌고 저장하지 않는다. 다시 열면 처음 상태.
- 금액(입찰 금액·가격 평가)은 "영업 권한 필요"로 가린다(가격 계산은 범위 밖).
- 예시 데이터에는 고객사 원문·실제 고객사명·사람 이름·연락처·단가를 넣지 않는다(역할 이름, "예시 …"로 바꿈).
- 화면마다 짧은 화면 명세(`SCR-xx-이름.md`)와 목업과 다른 점(`SCR-xx_공유.md`).

## Non-Goals

- 로그인·권한, 사업 단위 관리, 입찰 이력 저장, 표준 문구 저장, 정답지 채점기, 게시판, 설정 저장 같은 실제 기능.

## Capabilities

### New Capabilities
없음.

### Modified Capabilities
- `review-workspace`: 예시 화면.

## Impact

- `frontend/src/examples/SCR-xx.ts`(예시 데이터), `frontend/src/views/examples/*.tsx`(화면), `frontend/src/mockup/<Page>.css`, `App.tsx` 주소.
- 백엔드 바뀜 없음.
