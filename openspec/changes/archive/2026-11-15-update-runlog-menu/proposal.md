# Proposal

## Why

실행 기록(SCR-25)은 정답지·채점처럼 시스템이 어떻게 돌았는지 보는 관리 화면인데 아직 지식 관리 아래에 있다. 정답지·채점을 시스템 관리로 옮긴 뒤(update-system-menu) 사용자가 실행 기록도 옮기려고 화면 경로만 바꿨고, 그 경로가 "시스템 관리 관리"로 잘못 들어갔다. 사용자가 메뉴도 옮기고 경로를 바로잡아 달라고 했다(11-15).

## What Changes

- 왼쪽 메뉴에서 실행 기록을 지식 관리에서 시스템 관리(정답지·채점 아래)로 옮긴다. 주소 `#/runlog`는 그대로.
- 현재 위치를 "홈 > 시스템 관리 > 실행 기록"으로 바로잡는다.
- 스펙 "실행 기록 화면"의 메뉴 이름, 화면 문서 메뉴 표를 맞춘다.

## Non-Goals

- 실행 기록 화면 내용·API는 바꾸지 않는다.
