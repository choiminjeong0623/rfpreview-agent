# Proposal

## Why

문서 종류를 정하는 표현("bidding forms", "specification" 등 5줄)이 지금 코드(`classify.py`)에 박혀 있다. 다른 사전(비교 방향, 항목 이름, 위험 표현)은
`data/seed` CSV에서 DB로 적재하고 판정 규칙 화면에서 볼 수 있는데, 문서 종류 규칙만 코드를 열어야 보인다.
2026-10-29 minjeong 승인: 문서 종류 규칙을 다른 사전처럼 CSV → DB로 옮기고, 판정 규칙 화면에서 읽기 전용으로 보여 준다.
RFP 문서 이름은 형식이 대체로 정해져 있어(입찰 서식, 기술 사양서, 시험 사양서 등) 표현 목록으로 관리할 수 있다.

## What Changes

- 새 사전 `data/seed/doc_kind_rules.csv`(순서, 문서 종류, 파일 이름에서 찾는 표현, 첫 장에서 찾는 표현, 메모)와 DB 표 `doc_kind_rule`(마이그레이션 0012).
- 문서 분류는 코드 목록 대신 적재된 사전으로 문서 종류를 정한다. 결과는 지금과 같다(같은 5줄을 옮김).
- 사전 적재 때 문서 종류 코드가 틀리거나 표현이 정규식으로 맞지 않으면 그 줄을 알리고 적재를 멈춘다.
- 규칙 조회 API `GET /api/rules/doc-kinds`: 줄마다 그 종류로 규칙이 분류한 문서 수.
- 판정 규칙 화면에 "문서 종류" 탭(읽기 전용).

## Non-Goals

- 화면에서 규칙 고치기(지금처럼 `data/seed`를 고쳐 다시 적재).
- 주 규격 체계 표현(IEC·IEEE 등) 옮기기.
- 문서 종류 값(6종) 바꾸기.

## Impact

- 명세 `document-intake`(문서 분류 수정), `reference-data`(문서 종류 규칙 적재·조회 추가), `review-workspace`(판정 규칙 화면 수정).
- 마이그레이션 0012, 사전 판이 바뀌어 다음 실행에서 문서를 다시 처리한다(사전 파일이 늘었으므로).
