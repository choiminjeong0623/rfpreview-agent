# Proposal

## Why

2026-10-29 minjeong이 "RFP01 Bidding Forms.docx"를 처음부터 끝까지 돌린 결과 화면에서 두 가지가 깨졌다.

1. 머리글의 비교 제품 고르기가 설비 묶음 14개를 한 줄에 이어 붙여 머리글을 덮었다. 차단기 묶음 하나는 후보가 14개라 표처럼 세로로 눌린 단추가 화면 폭을 넘었다.
   합성 문서(묶음 1~2개)에서는 보이지 않던 문제다.
2. 판정 1,537줄(10줄씩 154쪽)에서 페이지 번호 단추를 154개 모두 그려 표 아래가 화면 밖으로 넘쳤다. 31쪽 뒤와 "다음", "n개씩"을 누를 수 없었다.

## What Changes

- 비교 제품 고르기를 머리글 아래 한 칸으로 옮긴다. 묶음마다 한 줄(묶음 이름 | 후보 단추)이고, 단추가 많으면 줄을 바꾼다.
  묶음이 4개보다 많으면 처음에는 접어 두고 "비교 제품 · 설비 n개 · 지금 제품들" 요약만 보인다. 누르면 펼친다.
- 표 아래 페이지 번호는 페이지가 9쪽보다 많으면 처음·끝 쪽과 지금 쪽 앞뒤 2쪽만 보이고 사이는 "…"로 줄인다. 모든 표가 같은 부품을 쓴다.

## Non-Goals

- 설비 묶음 나누기(같은 문서의 절마다 묶음이 생기는 것)는 바꾸지 않는다. 판정 결과는 그대로다.
- 비교 제품 바꾸기 동작(API, 다시 판정)은 그대로다.
