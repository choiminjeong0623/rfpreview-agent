# Proposal

## Why

검토 목록 요약 줄은 할 일만 센다(내가 처리할 건, 결재 대기, 분석 실패). 그래서 결재가 끝난 검토와 분석 중인 검토는 어느 칸에도 없어, 세 칸을 더해도 아래 "검토 n"과 맞지 않는다(예: 178 + 7 + 0 = 185, 목록 196 — 빠진 11건은 결재 완료). 사용자는 숫자가 틀렸다고 읽는다.

관련: SCR-06 검토 목록, update-list-my-turn.

## What Changes

- 요약 줄 끝에 흐린 칸을 더한다: "결재 완료 n"(결재 승인된 검토), "분석 중 n"(처리 중, 0이면 숨김). 담당 범위·기간과 같은 목록(결재 대기와 같은 범위)으로 센다.
- 할 일 칸과 나뉘어 보이게 구분선 뒤에 두고 중립색으로 보인다.
- 마우스를 올리면 각 칸이 무엇을 세는지 보인다.

## Non-Goals

- "내가 처리할 건" 규칙은 그대로(홈과 같음).
- 백엔드·API 변경 없음.
