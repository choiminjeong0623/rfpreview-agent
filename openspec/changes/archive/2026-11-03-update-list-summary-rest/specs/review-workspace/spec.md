## ADDED Requirements

### Requirement: 검토 목록 요약 줄 결재 완료·분석 중
화면은 검토 목록 요약 줄의 할 일 칸(내가 처리할 건, 결재 대기, 분석 실패) 뒤에 구분해 중립색으로 "결재 완료 n"(결재가 승인된 검토)과 "분석 중 n"(처리 중인 검토, 0이면 숨김)을 보여야 한다(SHALL). 두 칸은 결재 대기와 같은 범위(담당 범위·기간)로 세고, 마우스를 올리면 무엇을 세는지 보인다.

#### Scenario: 요약 줄 결재 완료·분석 중
- **WHEN** 내 검토가 담당자 확인 2건, 결재 대기 1건, 결재 완료 2건, 처리 중 1건인 상태로 검토 목록을 열면
- **THEN** 요약 줄에 "내가 처리할 건 2", "결재 대기 1", "결재 완료 2", "분석 중 1"이 보이고 칸 합이 "검토 6"과 같다
