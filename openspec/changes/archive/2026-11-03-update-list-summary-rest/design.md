# Design

## 결정

- **이름은 업무 말로.** "승인 끝" 대신 결재 흐름에서 쓰는 "결재 완료", 처리 중은 "분석 중"(머리글 "분석 n건"과 같은 말).
- **센 범위는 결재 대기와 같다.** 지금 담당 범위·기간으로 거른 목록(`owned`)에서 단계로 센다. 담당 범위 "내 검토"·기간 전체이고 분석 실패가 0이면 네 칸(+분석 중) 합이 목록 수와 같다.
- **할 일과 구분.** 왼쪽 할 일 칸과 세로선으로 나누고 회색 글자. 누르는 동작은 없다.

## 대안

- "그 밖 n"으로 묶기: 무엇이 빠졌는지 다시 물어야 해 버림.
