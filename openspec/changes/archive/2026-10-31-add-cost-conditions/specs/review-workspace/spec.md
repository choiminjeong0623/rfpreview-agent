## MODIFIED Requirements

### Requirement: 검토 상세 요약 칸과 탭
화면은 처리를 마친 검토 상세의 머리글 아래에 요약 칸 5개(일탈 후보, 질의 후보, 확인 필요 비율과 기준, 보증값 작성, 손실 환산 참고값)와 탭 9개(판정, 문서 읽기 점검, 위험 조건, 손실 환산(참고), 입찰 영향, 상업 조건, 지난 RFP 비교, 제출본, 이력)를 목업 순서대로 보여야 한다(SHALL). API가 없는 탭(지난 RFP 비교)은 예시 띠를 붙인다(SHALL).

#### Scenario: 요약 칸
- **WHEN** 일탈 후보가 있는 검토 상세를 열면
- **THEN** 요약 칸에 일탈 후보 수, 질의 후보 수, 확인 필요 비율과 "기준 20 %", 보증값 작성 수, 손실 환산 참고값이 보인다

#### Scenario: 탭으로 내용 바꾸기
- **WHEN** 검토 상세에서 "이력" 탭을 누르면
- **THEN** 이력 표가 보이고 탭 줄에서 이력 탭이 선택된 것으로 보인다

#### Scenario: 예시 탭
- **WHEN** "지난 RFP 비교" 탭을 누르면
- **THEN** 예시 띠가 보이고, 단추를 눌러도 저장하지 않아 화면을 다시 열면 처음 내용으로 돌아온다

## ADDED Requirements

### Requirement: 상업 조건 탭
화면은 상업 조건 탭에 비용 조건 요약(조항 종류와 위험 표시, 원문과 값, 부담 표시, 원문 위치, 담당, 협조 요청 상태)과 기술 판단에서 생긴 상업 영향(종류, 내용, 판정·손실 환산 연결, 팀 가정 표시)을 목업 v4.57 표 모양으로 보여야 한다(SHALL). 종류 칩(건수)으로 거르고, 줄마다 "후보"임을 보인다. 금액은 계산하지 않는다. 보내기는 협조 요청 현황에서 한다.

#### Scenario: 상업 조건 탭 열기
- **WHEN** 지체상금 줄이 있는 검토 상세에서 "상업 조건" 탭을 누르면
- **THEN** 예시 띠 없이 "지체상금" 줄이 원문 위치·견적 담당·협조 요청 상태와 함께 보이고 머리 표시에 비용 조건 수가 보인다

#### Scenario: 종류 칩으로 거르기
- **WHEN** 상업 조건 탭에서 "하자 보증" 칩을 누르면
- **THEN** 하자 보증 줄만 남고 그 칩이 눌린 상태로 보인다

#### Scenario: 비용 조건이 없는 검토
- **WHEN** 비용 영향 줄이 없는 검토의 상업 조건 탭을 열면
- **THEN** "찾은 비용 조건이 없습니다" 안내가 보이고 내려받기·보내기 단추는 없다

## REMOVED Requirements

### Requirement: 상업 조건 예시 탭
**Reason**: 상업 조건 탭이 실제 데이터를 보인다(`상업 조건 탭`).
**Migration**: 예시 데이터와 화면 안 전달 단추를 지운다. 보내기는 `update-role-handoff-mail`의 협조 요청 현황.
