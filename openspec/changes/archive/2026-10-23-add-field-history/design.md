# Design

## Context

스키마 v1에 fault_catalog, resolution_case, fault_link, proposal_point.point_kind = 'FIELD'가 이미 있다.
FR-15 규칙: 실행할 때는 연결표 조회만(코드), AI가 즉석에서 짝짓지 않음, 문장에는 고장 사전의 원인·조치 외
내용을 넣지 않음, 연결표에 없는 항목은 연결하지 않음.

## Decisions

### 1. 연결 기준: 같은 뜻 표현 + 설비 종류
- 요구 원문(text_raw)에 연결표 항목키의 같은 뜻 표현(item_alias)이 낱말 경계로 있으면 후보다. 값(req_value)이
  없는 문장 요구도 대상이라 값의 item_key 대신 원문을 본다. 영어 복수형(-s, -es)도 같은 뜻으로 본다.
- 요구의 설비 종류는 요구 문장 → 표 이름·로마 숫자 구분 제목 → 속한 절부터 위 절 → 문서 이름 순서로 처음 찾은
  것(GIS, BREAKER, SWITCHGEAR, TRANSFORMER, INSTRUMENT). 정규식은 비교 제품 고르기(selection)의 것을 쓴다.
- 연결표 줄마다 "적용 설비" 목록을 둔다. 고장 사전 제품군 MV_EQUIP(개폐기·차단기) 줄은 GIS·BREAKER·SWITCHGEAR,
  변류기 극성은 INSTRUMENT도 포함, TRANSFORMER 줄은 TRANSFORMER. [제안] 팀이 CSV에서 고친다.
- 대안: 판정의 설비 묶음·비교 제품 제품군으로 잇기 → 값 없는 문장 요구(히터, 계전기)는 판정 대상이 아니고,
  GIS 요구는 제품군이 GIS라 MV_EQUIP 고장과 이어지지 않아 명세서 예시(파일 4 히터)를 못 맞춤. 채택하지 않음.
- 목차가 통째로 요구 한 줄로 뽑힌 경우(점 지시선 + 쪽 번호)는 건너뛴다. (파일 4 27행, FR-02·03 쪽 문제)

### 2. 후보 하나 = 연결표 줄 하나
- 한 실행에서 연결표 줄마다 후보 하나. 대표 요구는 파일 번호·행이 가장 앞선 것, 근거 칸에 같은 요구 수와 파일 번호.
- 묶음 제한 없음(CR-09는 판정·보증값만). 파일 22(묶음 D)의 계전기 요구도 이어진다.
- 대안: 요구마다 후보 → 파일 1·2에서 같은 고장 후보가 수십 건 나와 엔지니어가 거르기 어렵다.

### 3. 근거와 문장
- 현장 이력 후보의 근거는 요구 원문 위치 + 연결표 줄(fault_link_id → 고장 사전 행). 제품 행은 없다.
  0006에서 proposal_point.product_code를 FIELD일 때만 비울 수 있게 한다.
- 문장은 코드 틀: "{항목} 요구와 이어지는 현장 고장 {고장 번호} (제품군 {제품군}). 증상: … 원인: … 조치: …
  해결 사례 N건." 증상·원인·조치·고장 번호·건수를 자리표시자로 두고 채운 뒤 숫자 대조(CR-07).
  AI에는 보내지 않는다 (사전 밖 내용이 끼지 않게).
- 확정자(confirmed_by)는 DB에만 두고 화면·산출물에 내지 않는다. 값은 사람 이름 대신 "팀 확정".

### 4. 의심 사례
- 적재할 때 코드가 표시한다: ① 고장 사전 RMA 불필요인데 사례에 RMA 번호 ② 처리 시간이 사전 기준의 10배 초과.
  800건 중 108건. 해결 사례 수에서 뺀다 (근거 칸에 뺀 수를 적는다).
- 원본 결과값 불일치(RMA 번호 + RESOLVED_*)는 모두 ①에 포함되어 따로 두지 않는다.

### 5. 적재
- data/seed/fault_catalog.csv(필요한 칸만), resolution_cases.csv(필요한 칸만), fault_link.csv. seed-rules가 넣는다.
- 고장 사전 파일이 없으면 세 표를 비우고 알린다 → 기능이 꺼진다(명세서 ⑤ 예외).
- 연결표의 제품군은 고장 사전 제품군이라 product_family 참조를 뗀다. 참조가 있으면 seed-products --replace의
  TRUNCATE … CASCADE가 연결표까지 지운다.
- 연결표에서 뺀 줄을 가리키는 현장 이력 후보는 ON DELETE CASCADE로 함께 지운다.

## Risks / Trade-offs

- 같은 뜻 표현을 넓히면 엉뚱한 요구가 이어진다 ("Space heater"가 변압기 함에도 있음 → 설비 종류로 거름).
- 파일 4의 CT 극성 시험(404행)·부분 방전 시험(398행)은 지금 요구로 뽑히지 않아(절 제목·누락) 이어지지 않는다.
  변류기 극성 줄은 이번 문서 묶음에서 연결 0건. 추출 쪽에서 고칠 일이다.
- 제품군 단위 연결이라 전압 등급 차이(12 kV급 사례 ↔ 115~245 kV 요구)는 엔지니어가 판단한다.
