# Proposal

## Why

실행 기록(SCR-25)은 줄을 누르면 표 안에서 단계별 시간·프롬프트 판·흐름 기록·AI 호출을 펼친다. 내용이 길어 표가 한없이 늘어나고 다른 줄과 섞여 읽기 어렵다. 사용자가 줄을 누르면 상세 화면으로 넘어가 보여 달라고 했다(11-15).
같은 자리의 AI 호출 목록은 AI를 켠 검토에서 "서버 응답이 정해진 모양과 맞지 않아 보내지 않았습니다."만 보였다. 조회가 내보내기용 `run_token`까지 응답에 실어 응답 모양(`AiCall`)의 남는 칸 검사에 걸렸다.

## What Changes

- 실행 기록 줄을 누르거나 Enter를 누르면 실행 기록 상세 화면 `#/runlog/:id`로 간다. 위에 검토 번호·상태·걸린 시간·AI 요청·추정 비용·문서/요구사항/판정, 아래에 단계별 걸린 시간·프롬프트 판·흐름 기록·AI 호출. [← 실행 기록]으로 돌아간다. 목록에서 펼치기는 없앤다.
- AI 호출 조회 응답에서 `run_token`을 뺀다(OpenTelemetry 내보내기는 그대로 씀). 응답 모양은 그대로.

## Non-Goals

- 실행 기록 API(`/api/run-log`)·AI 호출 API 모양은 바꾸지 않는다. 마이그레이션 없음.
