## MODIFIED Requirements

### Requirement: 실행 기록 화면
시스템은 시스템 관리 메뉴의 "실행 기록" 화면에 요약(실행 수, 끝난 실행 평균 걸린 시간, AI 요청 합, 추정 비용 합)과 검토마다 한 줄(검토, 상태, 시작, 걸린 시간, 모델, 요청·재시도, 토큰, 추정 비용, 문서·다시 쓴 문서, 요구사항, 판정, 다시 시도)을 보여야 한다(SHALL). 줄을 누르거나 Enter를 누르면 그 검토의 실행 기록 상세 화면으로 가서 요약(상태, 걸린 시간, AI 요청, 추정 비용, 문서·요구사항·판정)과 단계별 걸린 시간을 보인다. 추정 비용에는 "팀 가정"을 붙인다(CR-06). 기록 전 실행은 "기록 없음"으로 보인다. [제안]

#### Scenario: 실행 기록 보기
- **WHEN** 엔지니어가 실행 기록 화면을 열고 방금 끝난 검토 줄을 누르면
- **THEN** 목록 줄에 검토 번호와 "담당자 확인"이 보이고, 실행 기록 상세 화면으로 넘어가 제목에 검토 번호, 단계별 걸린 시간에 문서 읽기와 판정이 보인다

#### Scenario: 실행 기록 상세에서 돌아가기
- **WHEN** 엔지니어가 실행 기록 상세 화면에서 [← 실행 기록]을 누르면
- **THEN** 실행 기록 목록 화면이 다시 보인다

#### Scenario: 실행 기록도 시스템 관리 아래
- **WHEN** 사용자가 실행 기록 화면 주소를 바로 열면
- **THEN** 시스템 관리 묶음이 펼쳐지고 실행 기록 메뉴가 강조되며 현재 위치에 "시스템 관리"가 한 번 보이고, 지식 관리 묶음에는 실행 기록이 없다

### Requirement: 실행 기록의 흐름 기록
화면은 실행 기록 상세 화면에서 단계별 걸린 시간 아래에 흐름 기록(단계 이름, 걸린 시간, 바뀐 값, 사람 동작, 멈춘 자리)을 보여야 한다(SHALL). 흐름 기록이 없는 검토는 "흐름 기록 없음"을 보인다. 흐름 기록은 보기만 하고 바꾸는 단추는 없다. [제안 11-02, C2]

#### Scenario: 흐름 기록 펼치기
- **WHEN** 엔지니어가 실행 기록 화면에서 담당자 확인까지 처리한 검토 줄을 눌러 상세 화면을 열면
- **THEN** 흐름 기록에 판정 단계의 "판정 0 → n"과 "담당자 확인에서 멈춤"이 보인다
