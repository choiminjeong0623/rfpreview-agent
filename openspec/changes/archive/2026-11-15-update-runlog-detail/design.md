# Design

## 결정

- **상세 화면 데이터.** 새 API 없이 `/api/run-log` 목록에서 그 검토 줄을 찾는다. 목록이 최근 실행만 주므로 오래된 검토는 "이 검토의 실행 기록이 없습니다."를 보인다. 시연·관리 화면이라 이 정도로 충분하다.
- **펼친 내용 재사용.** 단계별 시간·프롬프트 판·흐름 기록·AI 호출 부품(`Steps`·`Prompts`·`Flow`·`AiCalls`)을 그대로 상세 화면에 옮긴다.
- **AI 호출 응답.** `run_token`은 OpenTelemetry trace id를 만드는 데만 쓴다. 화면 응답(`AiCalls`)에 칸을 더하는 대신 `summary`에서 뺀다(응답 모양·화면 타입 그대로).

## 버린 대안

- 펼치기와 상세 화면을 함께 두기: 같은 내용이 두 곳에 생겨 버림.
- `AiCall`에 `run_token` 칸 추가: 화면에 쓰지 않는 값이라 버림.
