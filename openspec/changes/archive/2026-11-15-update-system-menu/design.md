# Design

## 결정

- **묶음 자리:** 지식 관리와 팀 공유 사이. 아이콘 `admin_panel_settings`, 묶음 키 `sys`.
- **주소 유지:** `#/eval`을 바꾸지 않는다. 홈·판정 규칙 등에서 `href('/eval')`로 가는 링크와 북마크가 그대로 맞다. 메뉴 강조·묶음 펼침은 `groupOf`가 메뉴 표에서 찾으므로 표만 고치면 된다.

## 버린 대안

- 주소를 `#/system/eval`로 바꾸고 예전 주소를 넘겨주기: 사용자가 주소 변경을 최소로 원했고 얻는 것이 없다.
- 실행 기록도 함께 옮기기: 요청 범위 밖이라 하지 않는다.
