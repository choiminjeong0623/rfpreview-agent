## MODIFIED Requirements

### Requirement: 앱 틀과 화면 주소
화면은 목업과 같은 왼쪽 메뉴(홈, RFP 관리, 지식 관리, 시스템 관리, 팀 공유, 설정)와 머리글(메뉴 접기, 현재 위치, 검색, 알림, 사용자)을 모든 화면에 보여 줘야 한다(SHALL). 정답지·채점은 시스템 관리 묶음 아래에 두고 화면 주소는 그대로 둬야 한다(SHALL). 화면마다 주소가 있어 주소로 바로 열거나 새로 고쳐도 같은 화면과 메뉴 강조가 보여야 한다(SHALL). 메뉴 접기 상태는 브라우저에 기억해야 한다(SHALL).

#### Scenario: 메뉴로 화면 이동
- **WHEN** 엔지니어가 RFP 검토 화면에서 지식 관리 > 제품 관리를 누르면
- **THEN** 주소가 제품 관리 화면 주소로 바뀌고 제품 관리 메뉴가 강조되며 현재 위치에 홈과 제품 관리가 보인다

#### Scenario: 정답지·채점은 시스템 관리 아래
- **WHEN** 사용자가 정답지·채점 화면 주소를 바로 열면
- **THEN** 시스템 관리 묶음이 펼쳐지고 정답지·채점 메뉴가 강조되며 현재 위치에 시스템 관리가 보이고, 지식 관리 묶음에는 정답지·채점이 없다

#### Scenario: 메뉴 접기
- **WHEN** 사용자가 메뉴 접기를 누르고 화면을 새로 고치면
- **THEN** 메뉴는 아이콘만 남은 접힌 상태로 보인다
