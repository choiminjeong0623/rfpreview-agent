# Design

## 결정

- **API 그대로.** `api.aiUsage(days)`가 `GET /ai-usage?days=`를 부른다. 기능 이름은 응답의 `feature_name`을 그대로 쓴다(화면에 표를 두지 않는다).
- **기간을 바꾸면 다시 부른다.** 7·30·90일 고르기는 `days`로 서버에 묻고, 기능 칩은 받은 줄을 화면에서 거른다. 기간을 바꾸면 칩은 전체로.
- **합계는 응답 값.** 호출·비용 합은 응답의 `total_calls`·`total_cost_krw`를 쓴다(화면에서 다시 더하지 않는다, CR-01). 칩으로 걸렀을 때는 표 아래에 거른 줄의 호출 합만 보인다.
- **팀 가정 표시(CR-06).** 비용 옆 꼬리표 "팀 가정"과 1$ = 1,500원 안내. 줄의 비용이 null이면 "단가 모름".
- **빈 상태는 중립색.** AI 끔이나 쓰지 않은 기간은 사용자 잘못이 아니므로 `dimv`(회색) 문장.
- **자리.** 머리 줄·제목 아래, 실행 요약 칸 위에 상자 하나. 실행 표와 섞지 않는다.

## 대안

- 기능별 합계 막대그래프: 기능이 7개뿐이고 날짜별 줄이 필요해 표로 충분해 버림.
