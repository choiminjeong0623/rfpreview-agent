# Design

## 결정

- **사진 짝은 화면 코드에 둔다** (`frontend/src/components/productPhotos.ts`). 사진은 화면에 보이는 그림일 뿐 판정·보증값 같은 계산에
  쓰지 않으므로 DB·API를 바꾸지 않는다. 대안(제품표 CSV에 사진 칸 추가 + 마이그레이션 + API 칸)은 제품표 적재·API 타입·팀원
  `rfp-db setup`까지 바꿔야 해서 테스트 중인 main에 부담이 크다.
- **카탈로그 번호로 고른다.** 제품표 122줄은 카탈로그 7개(source_doc의 `CAT-Cxxxxx-xx`)로 묶이고, 공식 사이트도 계열 사진만 둔다.
  GIS 두 카탈로그(C81001-08, C81021-04)는 같은 GIS 대표 사진을 쓴다.
- **파일은 공식 사이트에서 받은 그대로** 둔다. 변압기 사진만 1080px PNG(약 1 MB)라 720px WEBP로 줄였다(그림 내용은 같음).
- **출처를 사진 바로 아래에** 적고 공식 페이지로 연결한다(CR-02 취지). "대표 사진 · 이 모델만의 사진은 아님"을 함께 적어 오해를 막는다.

## 위험

- 공식 사이트 개편으로 출처 링크가 바뀔 수 있다. 사진 파일은 저장소에 있으므로 화면은 그대로 보이고, 링크만 고치면 된다.
- 사진 사용 허락은 사람이 받은 것(2026-10-31, minjeong)이고 문서로 남은 허락서는 없다. 허락 범위가 바뀌면 사진 파일과 짝을 지운다.
