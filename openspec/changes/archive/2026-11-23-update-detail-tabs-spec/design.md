# Design: update-detail-tabs-spec

## 결정

- **화면을 기준으로 스펙을 고친다.** 강점 제안 탭은 이미 여러 e2e(`bid-tab`·`loss-tab`·`review`)가 주 탭으로 보고 있고, 사용자에게 보이는 모습도 이쪽이다. 스펙을 예전 5개로 되돌리면 화면과 시험 여러 개를 함께 바꿔야 한다.
- **예전 손실 환산 주소는 강점 제안을 연다.** `tabs.ts`에 이미 있는 동작(`loss` → `bid`)을 요구사항 문장에 적는다.

## 버린 대안

- 화면을 스펙(탭 5개)에 맞추기: 강점 제안을 더 보기로 내리면 채택·버림 동작을 찾기 어려워지고, 이미 통과하는 시험을 여러 개 바꿔야 한다.

## 위험

- 없음. 스펙 문장과 시험 하나만 바뀐다.
