## MODIFIED Requirements

### Requirement: 검토 상세 요약 칸과 탭
화면은 처리를 마친 검토 상세의 제목 줄 아래에 정보 3묶음과 탭 줄을 목업 v4.96 순서대로 보여야 한다(SHALL). "검토"는 제출 마감·D-day, 상신 권장일(마감 2일 전), 문서 수·묶음·규격 체계, 담당·결재자, "사업"은 사업명·고객사·국가·고객 입찰 번호·영업, "판정 진행"은 꼭 볼 것(일탈·질의·확인 필요 합과 각 수), 준수 수, 작성할 칸(빈칸·전체), 손실 환산(조항이 있을 때)이다. 탭은 판정·강점 제안·위험 조건·문서 읽기 점검·상업 조건·이력 6개와 "더 보기"(지난 RFP 비교·제출본)이고, 판정 탭 옆에 꼭 볼 것 수를 보인다. 강점 제안 탭(예전 입찰 영향)은 제안 포인트를 위에, 손실 환산을 그 아래 한 칸으로 보이며, 예전 손실 환산 탭 주소는 강점 제안 탭을 연다. 예시 띠는 없다. 확인 필요 비율과 뺀 직접 작성할 칸 수는 결재 상신 창에만 보인다. [결정]

#### Scenario: 요약 칸
- **WHEN** 일탈 후보가 있는 검토 상세를 열면
- **THEN** 정보 묶음 검토·사업·판정 진행이 보이고, 판정 진행에 꼭 볼 것·준수·작성할 칸이 보이며 예전 요약 칸(확인 필요 비율 칸)은 없다

#### Scenario: 꼭 볼 것
- **WHEN** 일탈 후보 2·질의 후보 2·확인 필요 8·준수 45줄인 검토 상세를 열면
- **THEN** 판정 진행에 "꼭 볼 것 12줄"과 "일탈 2 · 질의 2 · 확인 8", "준수 45줄"이 보이고 판정 탭 이름 옆 수가 12다

#### Scenario: 사업 묶음
- **WHEN** 사업이 연결된 검토 상세를 열면
- **THEN** 사업 묶음에 고객 입찰 번호와 영업 담당 이름이 보인다

#### Scenario: 상신 권장일
- **WHEN** 제출 마감이 6일 남은 검토 상세를 열면
- **THEN** 검토 묶음의 상신 권장에 마감 2일 전 날짜가 보인다

#### Scenario: 더 보기 탭
- **WHEN** "더 보기"에서 지난 RFP 비교를 고르면
- **THEN** 지난 RFP 비교 탭 내용이 보이고 탭 줄 끝에 "지난 RFP 비교"가 선택된 것으로 붙는다

#### Scenario: 직접 작성할 칸 표시
- **WHEN** 직접 작성할 칸이 3개인 검토에서 결재 상신 창을 열면
- **THEN** 확인 비율 줄에 "직접 작성할 칸 3개는 뺌"이 보인다

#### Scenario: 탭으로 내용 바꾸기
- **WHEN** 검토 상세를 열고 "이력" 탭을 누르면
- **THEN** 탭 줄에 판정·강점 제안·위험 조건·문서 읽기 점검·상업 조건·이력 6개가 이 순서로 보이고, 이력 표가 보이며 이력 탭이 선택된 것으로 보인다

#### Scenario: 예시 탭
- **WHEN** 마지막 예시 탭이던 "지난 RFP 비교" 탭을 열면
- **THEN** 예시 띠가 보이지 않는다
