# Proposal: 검토 상세 탭 스펙을 화면에 맞춤 (update-detail-tabs-spec)

## Why

검토 상세 화면의 탭은 판정·강점 제안·위험 조건·문서 읽기 점검·상업 조건·이력 6개이고, "더 보기"에는 지난 RFP 비교·제출본만 있다(`frontend/src/views/detail/tabs.ts`). 손실 환산은 따로 된 탭이 아니라 강점 제안 탭 안의 한 칸이다.

그런데 확정 스펙(`review-workspace` "검토 상세 요약 칸과 탭")은 아직 탭 5개와 "더 보기"(손실 환산 (참고)·입찰 영향·지난 RFP 비교·제출본)로 적혀 있다. 2026-11-16 E2E를 CI에 넣을 때 이 차이를 찾아 시험 "탭으로 내용 바꾸기"를 `test.fixme`로 멈춰 두었다.

화면 쪽(강점 제안을 주 탭으로)이 지금 쓰이는 모습이고 되돌리기 쉬운 일이라, 스펙을 화면에 맞추기로 정했다.

## What Changes

1. `review-workspace` "검토 상세 요약 칸과 탭" 요구사항의 탭 목록을 6개 + 더 보기(지난 RFP 비교·제출본)로 고치고, 강점 제안 탭 안에 손실 환산이 있음을 적는다.
2. 시나리오 "더 보기 탭"을 지난 RFP 비교로(이미 있는 시험 `detail-header.spec.ts` "더 보기 탭"과 같음), "탭으로 내용 바꾸기"에 탭 6개 순서를 더한다.
3. 멈춰 둔 E2E "탭으로 내용 바꾸기"를 다시 켜고 탭 6개를 본다.

## Non-Goals

- 화면 코드 바꾸기. 탭 구성은 그대로다.
- "입찰 영향 탭"·"손실 환산 탭" 요구사항의 이름 바꾸기. 내용(제안 포인트·손실 환산)은 강점 제안 탭 안에서 그대로 보이므로 이번에는 손대지 않는다.

## Capabilities

### Modified Capabilities

- `review-workspace`: "검토 상세 요약 칸과 탭"의 탭 목록과 시나리오 두 개.
