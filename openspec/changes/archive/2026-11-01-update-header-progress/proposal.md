# Proposal

## Why

목업 v4.96(v4.60부터)은 모든 화면 머리글에 "분석 n건 · p %" 단추를 두어, 어느 화면에 있든 처리 중인 검토가 얼마나 왔는지 보이고 끝나면 알려 준다.
지금은 처리 상태 화면(SCR-02)·검토 목록·홈에서만 진행을 볼 수 있어, 다른 화면으로 가면 분석이 끝났는지 알 수 없다.
프런트 4단계 첫 화면(`docs/screens/_v4.96_결정.md` 4장 1번, minjeong 11-01 13:33 "여기서 시작합니다").

관련: 화면 명세 `docs/screens/SCR-00-앱틀.md` "v4.96 바뀐 점" 4장, 수용 기준 1~3. FR-01~06 처리 진행(`update-processing-progress`).

## What Changes

- 머리글 분석 진행 단추: 처리 중 검토가 있으면 둥근 진행 고리와 "분석 n건 · p %"(평균). 하나라도 멈춤 안내 기준을 넘으면 주황.
- 작은 창: 검토마다 검토 번호·이름, 단계 문장(세부 줄 수), 진행 막대, 지난 시간, 멈춤 안내, [진행 보기](처리 상태 화면).
- 끝남 안내: 머리글에 보이던 검토가 끝나면 "분석이 끝났습니다", 실패하면 "분석이 멈췄습니다" 알림을 공통 알림 쌓기로 띄우고 검토로 가는 링크를 붙인다.
- 공통 알림(`useToast`)에 링크 하나를 붙일 수 있게 한다.

## Non-Goals

- 새 API. `GET /runs`의 `stage`·`step`·`step_detail`·`started_at`·`step_updated_at`으로 만든다.
- 목업의 "AI 응답 대기 중 (재시도 1/3)" 문장. 재시도 횟수를 실행 목록 응답이 주지 않는다.
- 목업 "방금 끝남" 묶음의 "꼭 볼 것 n줄". 끝남 알림에는 검토 이름만 보인다.
