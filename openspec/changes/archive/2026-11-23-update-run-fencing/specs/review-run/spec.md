## MODIFIED Requirements

### Requirement: 실행 소유권
시스템은 작업을 넣을 때마다 새 실행 토큰을 내고, 처리 흐름은 진행을 기록할 때마다 토큰이 아직 자기 것인지 확인해 아니면 결과를 쓰지 않고 멈춰야 한다(SHALL, NFR-12). 처리 흐름이 결과를 저장(커밋)할 때는 같은 트랜잭션 안에서 검토를 잠그고 토큰을 다시 확인해, 자기 토큰이 아니면 그 저장을 되돌리고 멈춘다. 한 검토에 도는 실행은 언제나 하나다. [제안 v3]

#### Scenario: 취소 직후 다시 시도
- **WHEN** 처리 중인 검토를 취소하고 바로 다시 시도하면
- **THEN** 옛 실행은 다음 진행 기록 때 멈추고 결과를 쓰지 않으며, 새 실행 하나만 결과를 쓴다

#### Scenario: 단계 저장 직전에 밀려남
- **WHEN** 옛 실행이 토큰을 확인한 뒤 단계 결과를 저장하기 전에 같은 검토를 다시 넣으면
- **THEN** 옛 실행이 그 단계에서 쓴 결과는 하나도 저장되지 않고 옛 실행은 멈추며, 새 실행 하나만 결과를 쓴다
