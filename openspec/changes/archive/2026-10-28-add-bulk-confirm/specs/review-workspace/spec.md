## ADDED Requirements

### Requirement: 판정 탭 한꺼번에 확정
검토 상세 판정 탭은 줄 고르기 칸과, 고른 줄이 있으면 "n줄 선택 · 제안대로 확정" 띠를, 고른 줄이 없고 확정하지 않은 준수 판정이 있으면 "준수 n줄 모두 확정" 띠를 보여야 한다(SHALL). 담당자 확인 단계가 아니면 두 띠를 보이지 않는다.

#### Scenario: 고른 줄 확정
- **WHEN** 엔지니어가 판정 2줄을 고르고 "제안대로 확정"을 누르면
- **THEN** 두 줄이 확정됨으로 바뀌고 "판정 2줄을 제안대로 확정했습니다." 알림이 보인다

#### Scenario: 준수 모두 확정
- **WHEN** 확정하지 않은 준수 판정이 있는 검토에서 "준수 n줄 모두 확정"을 누르면
- **THEN** 띠가 사라지고 준수 판정은 모두 확정됨이다
