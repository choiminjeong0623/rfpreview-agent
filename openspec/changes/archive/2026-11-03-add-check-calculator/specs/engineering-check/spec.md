## ADDED Requirements

### Requirement: 검산 계산 확인
시스템은 단시간 전류(kA)·주파수(Hz)·최대 순간 전류(kA)를 받아 분석 검산과 같은 규칙(50 Hz × 2.5, 60 Hz × 2.6, 계산값·정수 반올림·50 Hz 규격 표준값을 같다고 봄)으로 배수, 계산값, 같다고 보는 값, 결과(통과·위반)를 돌려줘야 한다(SHALL). 주파수가 50·60이 아니면 확인 필요로 답한다. 이 계산은 저장하지 않고 판정을 바꾸지 않는다(MUST NOT).

#### Scenario: 검산 계산 확인
- **WHEN** 단시간 전류 50 kA, 50 Hz, 최대 순간 전류 100 kA로 검산 계산을 물으면
- **THEN** 배수 2.5, 계산값 125 kA, 결과 위반이 돌아오고, 최대 순간 전류를 125 kA로 물으면 통과다

#### Scenario: 배수 없는 주파수
- **WHEN** 주파수 55 Hz로 검산 계산을 물으면
- **THEN** 결과는 확인 필요이고 계산값은 비어 있다
