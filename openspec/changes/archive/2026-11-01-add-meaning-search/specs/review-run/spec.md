## ADDED Requirements

### Requirement: 뜻 찾기 벡터
시스템은 분석에서 위험 조건 다음에 뜻 찾기에 쓸 글(문장 요구사항, 판정 줄 요구 원문, 항목키가 빈 표 항목 이름, 위험 표현·항목 이름 사전 표현)의 문장 벡터를 언어 모델에서 받아 글마다 저장하고, 같은 글은 다시 묻지 않아야 한다(SHALL). 언어 모델이 없으면 "뜻 찾기 안 함", 재시도 뒤에도 실패하면 "뜻 찾기 건너뜀"으로 남기고 분석은 계속해야 한다(SHALL). 벡터로는 판정·위험 조건을 만들지 않는다(MUST NOT, CR-01). [제안 11-01]

#### Scenario: 같은 글은 다시 묻지 않음
- **WHEN** 같은 문서로 검토를 두 번 돌리면
- **THEN** 두 번째 검토에서는 벡터를 묻지 않고 저장된 벡터로 같은 후보가 나온다

#### Scenario: 언어 모델 없음
- **WHEN** 언어 모델 없이 검토를 돌리면
- **THEN** 분석은 담당자 확인 단계까지 가고 뜻 찾기 상태는 "안 함", 후보는 없다

#### Scenario: 벡터 요청 실패
- **WHEN** 벡터 요청이 재시도 뒤에도 실패하면
- **THEN** 분석은 담당자 확인 단계까지 가고 뜻 찾기 상태는 "건너뜀"이다
