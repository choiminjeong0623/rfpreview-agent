# Design

## 결정

- **공통 훅 `usePage(list, size)`.** 지금 쪽 줄과 `Pager`를 함께 돌려준다. 목록이 쪽 크기보다 짧으면 쪽 번호 줄을 그리지 않는다. 목록이 줄어 지금 쪽이 없어지면(확인·닫기 뒤 다시 불러옴) 마지막 쪽으로 맞춘다.
- **쪽 크기 기본 10, 고르기 10·20·50.** "긴 목록 페이지 번호" 요구대로 한 페이지 개수 고르기를 항상 보인다. 판정 탭과 같다.
- **이력 탭의 "시스템 · 판정 n줄 생성" 줄도 한 줄로 센다.** 맨 아래(마지막 쪽 끝)에 둔다.
- **줄을 펼친 상태는 쪽을 넘겨도 줄 번호(risk_id)로 유지.** 다른 쪽에 있으면 보이지 않을 뿐이다.

## 대안

- 더 보기 단추로 10줄씩 늘리기: 판정 탭·협조 요청과 모양이 달라 버림.
