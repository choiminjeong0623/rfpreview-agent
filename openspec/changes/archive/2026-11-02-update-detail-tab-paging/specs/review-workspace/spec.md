## ADDED Requirements

### Requirement: 검토 상세 탭 쪽 나누기
화면은 검토 상세의 위험 조건, 문서 읽기 점검, 상업 조건(비용 조건 표와 상업 영향 표 따로), 이력 탭의 목록이 10줄보다 많으면 한 쪽에 10줄(10·20·50줄 중 고름)씩 보이고 아래에 쪽 번호 줄을 두어야 한다(SHALL). 10줄 이하면 쪽 번호 줄을 두지 않는다. 탭 머리 숫자는 지금 쪽이 아니라 목록 전체로 센다. 상업 조건 탭에서 조항 종류를 바꾸면 1쪽으로 돌아간다.

#### Scenario: 상세 탭 쪽 나누기
- **WHEN** 문서 읽기 점검이 15건인 검토 상세의 문서 읽기 점검 탭을 열면
- **THEN** 점검 줄 10개와 "1–10 / 전체 15건" 쪽 번호 줄이 보이고 머리에는 "확인 안 함 15건"이 보이며, 2쪽을 누르면 점검 줄 5개가 보인다

#### Scenario: 짧은 목록은 쪽 번호 없음
- **WHEN** 이력이 10줄 이하인 검토 상세의 이력 탭을 열면
- **THEN** 이력 줄이 모두 보이고 쪽 번호 줄은 없다
