## ADDED Requirements

### Requirement: TBE 준수표 화면
시스템은 검토 상세 머리의 "TBE 준수표" 단추로 TBE 준수표 화면을 열고, 판정 기준·넣을 줄·항목 언어 선택, 요약(넣는 줄, 준수, 일탈, 질의, 확인 필요, 그중 후보, 위치 없어 뺀 줄), 미리보기 표, "엑셀 내려받기"를 보여야 한다(SHALL). 판정 기준 "제출본 v1"은 승인된 실행에서만 고를 수 있다. 제출본 탭의 "이 판정으로 TBE 준수표 받기"도 이 화면을 연다.

#### Scenario: 넣을 줄 바꾸기
- **WHEN** 엔지니어가 TBE 준수표 화면에서 "확정한 줄만"을 고르면
- **THEN** 미리보기와 넣는 줄 수가 확정한 줄만으로 바뀌고 파일 이름이 "…_확정만.xlsx"가 된다

#### Scenario: 엑셀 내려받기
- **WHEN** "엑셀 내려받기"를 누르면
- **THEN** .xlsx 파일이 내려받아지고 "…를 내려받았습니다 (n줄)." 알림이 보인다
