## MODIFIED Requirements

### Requirement: AI 오류 처리
시스템은 AI 연결 오류, 시간 초과, 서버 오류에 정해진 횟수만 재시도하고, 그래도 실패하면 실행을 멈추고 "처리 실패 — 다시 시도"를 알려야 한다(SHALL, CR-12). 답의 형식이 틀리면 같은 질문을 다시 묻지 않는다. 키·권한·모델 설정 오류는 다시 묻지 않고 바로 멈추고 "AI 키 또는 모델 설정 오류 — 설정 확인"을 알려야 한다(SHALL). [제안 11-01: 오류 종류별 처리]

#### Scenario: AI 키 없음
- **WHEN** 언어 모델 키 없이 검토를 실행하면
- **THEN** AI 보조 단계는 건너뛰고 코드 규칙 결과로 엔지니어 검토(ENGINEER_REVIEW) 단계까지 간다

#### Scenario: 계속 실패
- **WHEN** AI 호출이 재시도 횟수를 넘겨 실패하면
- **THEN** 실행은 FAILED가 되고 실패한 단계와 "처리 실패 — 다시 시도"가 보인다

#### Scenario: 형식이 틀린 답은 다시 묻지 않음
- **WHEN** 언어 모델이 검사에 맞지 않는 답을 내면
- **THEN** 같은 질문은 한 번만 보내고 재시도 수는 0이다

#### Scenario: 키 오류는 바로 멈춤
- **WHEN** 언어 모델이 키 오류(401)를 돌려주면
- **THEN** 요청 1번 뒤 실행은 FAILED가 되고 "AI 키 또는 모델 설정 오류 — 설정 확인"이 보인다

### Requirement: AI 묶음 답의 줄 번호
시스템은 AI에 여러 줄을 묶어 물을 때(문장 구분·유형 붙이기·문장 초안) 답마다 묻는 글의 줄 번호를 받아 번호로 줄에 맞춰야 한다(SHALL). 번호가 빠지거나 겹치거나 범위를 벗어나면 형식 오류로 보고 같은 질문을 다시 묻지 않고, 문장 구분·유형 붙이기는 묶음을 바로 반으로 나눠 묻는다. 답의 순서가 섞여도 결과는 같다(CR-11). [제안 11-01]

#### Scenario: 순서가 섞인 답
- **WHEN** 언어 모델이 줄 번호를 붙인 답을 거꾸로 된 순서로 내면
- **THEN** 각 줄에는 자기 번호의 답이 붙고, 결과는 바른 순서로 낸 답과 같다

#### Scenario: 번호가 겹친 답
- **WHEN** 40줄 묶음에서 언어 모델이 한 번호를 빠뜨리고 다른 번호를 두 번 내 개수는 40으로 맞으면
- **THEN** 그 답은 받지 않고 같은 질문을 다시 묻지 않고 묶음을 나눠 물어, 모든 줄이 자기 번호의 답을 받는다
