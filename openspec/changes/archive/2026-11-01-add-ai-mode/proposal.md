# AI 사용 방식 설정: Gemini · 사내 모델 · AI 끄기 (C조 C5)

## 왜

- 외부 언어 모델로 RFP 문장을 보내도 되는지(Q6, NFR-07)는 아직 답이 없다. 지금은 키가 있으면 무조건 Gemini로 보낸다.
- 실제 회사는 외부 전송을 막거나 사내 모델을 쓰라고 할 수 있다. 데이터 활용 적정성(보안)·AI 기술 활용성(기술 선정) 평가에서 "외부 전송을 끌 수 있고 사내 모델로 바꿀 수 있다"를 보여야 한다.

## 무엇

- 설정 `RFP_AI_MODE` 하나로 고른다.
  - `gemini`(기본): 지금처럼 Gemini. 키가 없으면 규칙만.
  - `local`: 사내 서버의 OpenAI 호환 주소(`RFP_LOCAL_LLM_URL`, 모델 `RFP_LOCAL_LLM_MODEL`, 선택 `RFP_LOCAL_LLM_KEY`)로만 보낸다. 문장 벡터는 `RFP_LOCAL_EMBED_MODEL`이 있을 때만(없으면 뜻 찾기 건너뜀).
  - `off`: 어디에도 보내지 않고 코드 규칙만. Gemini 키가 있어도 보내지 않는다.
- `/api/health`가 지금 방식(GEMINI·LOCAL·OFF), 모델 이름, 외부 전송 여부를 돌려준다(키·주소 값은 주지 않음).
- 검토 등록 화면과 실행 기록 화면에 "AI: Gemini (외부 전송)" 같은 한 줄을 보인다.
- 사내 모델의 오류도 B6 규칙(연결·시간 초과·서버 오류만 재시도, 400·401·403·404는 설정 오류로 바로 멈춤)을 따른다.

## 하지 않음

- 사내 모델 서버 자체(vLLM·Ollama 등) 설치·운영.
- 고객사명·연락처 자동 가림(NFR-06 별도).
- 화면에서 방식 바꾸기(설정 파일·환경 변수만, 운영자 몫).

관련: 명세서 NFR-07 "AI 사용 방식 설정 [C5]", 기획서 4장 데이터 취급.
