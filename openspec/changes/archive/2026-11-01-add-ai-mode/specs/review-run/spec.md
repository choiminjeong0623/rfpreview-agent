## ADDED Requirements

### Requirement: AI 사용 방식 설정
시스템은 설정 하나로 AI 사용 방식을 Gemini(외부), 사내 모델(OpenAI 호환 주소), AI 끄기 가운데서 골라야 한다(SHALL). AI 끄기이면 키가 있어도 어떤 언어 모델에도 요청을 보내지 않고 코드 규칙만으로 처리해야 한다(MUST). 사내 모델이면 정한 주소로만 보내고, 벡터 모델이 정해지지 않았으면 뜻 찾기를 건너뛰어야 한다(SHALL). 모델이 바뀌면 처리 판이 달라져 같은 파일도 새로 분석한다(NFR-02). [제안 11-01, C5]

#### Scenario: AI 끄기
- **WHEN** Gemini 키가 있고 방식이 AI 끄기인 상태에서 검토를 돌리면
- **THEN** 언어 모델 요청은 0건이고 검토는 규칙만으로 담당자 확인 단계까지 가며 실행 기록의 모델은 비어 있다

#### Scenario: 사내 모델로 보냄
- **WHEN** 방식이 사내 모델이고 주소와 모델이 정해진 상태에서 검토를 돌리면
- **THEN** 언어 모델 요청은 모두 그 주소로 가고 실행 기록의 모델은 사내 모델 이름이다

#### Scenario: 사내 모델 설정 오류
- **WHEN** 사내 모델 주소가 키 오류(401)나 모델 없음(404)으로 답하면
- **THEN** 다시 묻지 않고 "AI 키 또는 모델 설정 오류 — 설정 확인"으로 멈춘다

#### Scenario: 사내 벡터 모델 없음
- **WHEN** 방식이 사내 모델이고 벡터 모델이 정해지지 않은 상태에서 검토를 돌리면
- **THEN** 뜻 찾기 상태는 "건너뜀"이고 분석은 담당자 확인 단계까지 간다
