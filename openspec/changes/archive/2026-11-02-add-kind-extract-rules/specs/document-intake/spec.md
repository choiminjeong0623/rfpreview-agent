## MODIFIED Requirements

### Requirement: 문서 종류별 처리기
시스템은 문서 종류마다 처리기를 하나 두고, 문서를 처리할 때 그 종류의 처리기를 코드로 골라야 한다(SHALL). 처리기는 AI 질문에 넣을 문서 종류 설명, 처리 뒤 점검 기준, 공통 추출 규칙에 더할 종류별 추출 규칙을 정한다. 문서마다 쓴 처리기를 남긴다. [제안 11-01, C1] [종류별 추출 규칙: 제안 11-02]

#### Scenario: 입찰 서식은 입찰 서식 처리기
- **WHEN** 파일 이름이 입찰 서식 규칙에 맞는 문서를 처리하면
- **THEN** 문서에 입찰 서식 처리기가 남고 AI 문장 구분 질문에 입찰 서식 설명이 들어간다

#### Scenario: 종류 모름은 일반 처리기
- **WHEN** 문서 종류를 정하지 못한 문서를 처리하면
- **THEN** 일반 처리기를 쓰고 AI 질문에 문서 종류 설명이 없다
