# Spec Delta

## Purpose

변압기 손실이 입찰 평가 가격을 바꾸는 지점을 계산으로 보여 준다. 손실이 적으면 평가에서 유리하다는 강점의 근거가 된다 (FR-13).

## ADDED Requirements

### Requirement: 손실 환산 가산액
시스템은 RFP 손실 환산 조항의 단가($/kW)와 제품 손실값으로 손실 종류별 가산액과 합계(Σ 단가 × 손실값)를 코드로 계산하고, 계산식과 원문 위치를 함께 보여 줘야 한다(SHALL). 손실값이 팀 가정이면 "팀 가정"을 표시해야 한다(SHALL, CR-06). 손실값을 바꾸면 다시 계산한다.

#### Scenario: 사례 5
- **WHEN** 단가 4,500 / 3,200 / 1,300 $/kW와 손실값 60 / 300 / 8 kW(팀 가정)로 계산하면
- **THEN** 270,000 + 960,000 + 10,400 = 1,240,400 $이고 "팀 가정"이 표시된다

### Requirement: 계산하지 않는 경우
시스템은 손실값이 없거나 단가 단위가 $/kW가 아니면 계산하지 않고 "확인 필요"로 두어야 한다(SHALL).

#### Scenario: 손실값 없음
- **WHEN** 비교 제품에 손실값이 없으면
- **THEN** 합계는 비어 있고 확인 필요이다
