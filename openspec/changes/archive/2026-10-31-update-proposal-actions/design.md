# Design

## 결정

- 알림은 포인트 줄 안(단추 자리 아래)에 `role="status"`로 둔다. 화면 아래 토스트는 탭을 다시 불러오면 사라지고, 여러 줄을 연달아 누르면 어느 줄 알림인지 알기 어렵다.
- 다시 불러온 뒤에도 알림이 남도록 상태를 탭(BidTab)이 포인트 번호로 기억한다.
- 전달 대상 문구는 화면이 포인트 종류로 고른다: 손실 환산(LOSS) → 영업·견적, 나머지 → 영업. 백엔드 `POINT_ROLES`와 같은 표다.
- 단추 모양은 목업 공통 단추(`.bp` 채운 단추, `.bo` 테두리 단추)를 쓴다.

## 대안

- 화면 아래 토스트: 위 이유로 뺌.
- 응답에 전달 대상을 담기: API 변경이 필요해 뺌. 표가 두 곳에 있게 되므로 문구가 다르면 백엔드 표를 기준으로 고친다.

## 위험

- 백엔드 `POINT_ROLES`가 바뀌면 화면 문구도 고쳐야 한다.
