# Proposal

## Why

입찰 영향 탭의 제안 포인트 "채택"·"버림"이 작은 글자 링크라 잘 보이지 않고, 눌러도 상태 라벨만 조용히 바뀌어 눌렸는지, 누구에게 전달되는지 알 수 없다.
2026-10-31 나송주 구역 주말 검토에서 minjeong이 "채택/버림 단추를 명확하게, 누르면 알림이 나오게" 요청했다.

관련: FR-10(채택 / 버림 / 수정), FR-11(채택한 포인트 전달), AR-08, `review-workspace` "입찰 영향 탭".

## What Changes

- "채택"은 채운 단추, "버림"은 테두리 단추로 바꾼다.
- 채택하면 그 포인트 아래에 "채택했습니다. 영업 담당에게 협조 요청으로 전달합니다."(손실 환산 포인트는 "영업·견적 담당") 알림을 보인다.
- 버리면 "버렸습니다. 사유: …" 알림을 보인다.
- 채택한 줄은 초록 바탕, 버린 줄은 흐리게 보인다.

## Non-Goals

- 채택 취소, 문장 고치기, API 변경.
