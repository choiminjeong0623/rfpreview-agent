# 협조 요청 메일에 부서 관점 확인 질문 (C조 C4)

## 왜

- 지금 협조 요청 메일은 요구사항 원문과 위치만 준다. 받는 부서(견적·품질·영업)는 "그래서 내가 무엇을 확인해야 하나"를 다시 읽어 찾아야 한다.
- AI 기술 활용성 평가의 "여러 에이전트·역할별 에이전트"에 닿는다. 부서마다 관점이 다른 문장 쓰기 역할을 AI에 맡기고, 숫자·판단은 코드가 쥔다(CR-01·CR-07).

## 무엇

- 메일을 보낼 때(판정 확정 뒤 자동, [보내기]·[다시 보내기]) 부서별 한 통마다 AI에 한 번 물어, 요청마다 그 부서 관점의 "확인할 점" 한 문장을 받는다.
- 검사: 줄 번호 맞춤(A2), 비지 않음, 160자 이하, 숫자 없음, 경쟁 비교 없음, 한글 포함. 틀린 줄은 부서별 코드 기본 문장. AI 없음·실패(형식·연결·설정)면 모두 코드 문장으로 보내고 메일은 멈추지 않는다.
- 본문·엑셀에 "확인할 점 (AI 작성)" 또는 "(기본 문장)". 요청에 질문과 쓴 이(AI·CODE)를 저장하고 협조 요청 화면 상세에 보인다. 다시 만들어진 요청도 이어 씀.
- 마이그레이션 0029.

## 하지 않음

- 메일 전체를 AI가 쓰기(요구사항·위치·기한은 코드 그대로).
- 보내기 전 사람이 고치는 초안 화면(판정 확정이 곧 보내기라는 10-31 결정 유지). 질문은 원문을 대신하지 않는 참고 문장이다.

관련: 명세서 FR-11 ④ "부서 관점 확인 질문 [C4]".
