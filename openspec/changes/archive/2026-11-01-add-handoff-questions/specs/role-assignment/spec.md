## ADDED Requirements

### Requirement: 협조 요청 확인 질문
시스템은 협조 요청 메일을 보낼 때 요청마다 받는 부서 관점의 확인할 점 한 문장을 언어 모델로 써서 본문과 엑셀에 "AI 작성" 표시와 함께 넣고 요청에 저장해야 한다(SHALL). 질문에 숫자가 있거나, 비었거나, 160자를 넘거나, 경쟁 제품 비교가 있으면 그 줄은 부서별 코드 기본 문장으로 바꿔야 한다(MUST, CR-07). 언어 모델이 없거나 실패해도 메일은 코드 문장으로 보내야 한다(SHALL). 질문은 요구사항 원문을 대신하지 않는다. [제안 11-01, C4]

#### Scenario: 부서 관점 질문
- **WHEN** 견적 담당 요청 2건이 있는 검토에서 엔지니어가 판정을 확정해 메일이 나가면
- **THEN** 메일 본문과 엑셀의 두 요청에 견적 관점 확인할 점이 "AI 작성"으로 들어가고, 요청에 질문과 쓴 이 AI가 저장된다

#### Scenario: 숫자가 든 질문
- **WHEN** 언어 모델이 한 요청의 질문에 숫자를 쓰면
- **THEN** 그 요청만 부서 기본 문장("기본 문장")으로 바뀌고 다른 요청의 질문은 그대로다

#### Scenario: 언어 모델 없음
- **WHEN** 언어 모델 없이 협조 요청을 보내면
- **THEN** 메일은 나가고 모든 요청의 확인할 점은 부서 기본 문장, 쓴 이는 CODE다

#### Scenario: 질문 형식 오류
- **WHEN** 언어 모델 답의 줄 번호가 요청 수와 맞지 않으면
- **THEN** 다시 묻지 않고 그 메일의 모든 요청을 기본 문장으로 보낸다

#### Scenario: 다시 만들어진 요청
- **WHEN** 메일을 보낸 뒤 다른 판정을 확정해 협조 요청 목록이 다시 만들어지면
- **THEN** 이미 보낸 요청의 확인할 점과 쓴 이가 그대로 남는다
