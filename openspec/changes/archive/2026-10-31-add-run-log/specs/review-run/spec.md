## ADDED Requirements

### Requirement: 실행 기록 저장
시스템은 검토 처리마다 언어 모델 요청 수(재시도 포함), 재시도 수, 입력·출력·생각 토큰, 이전 처리 결과를 다시 쓴 문서 수, 단계마다 시작·끝 시각을 저장해야 한다(SHALL). 처리가 실패해도 그때까지의 값을 저장하고, 다시 시도하면 사용량은 더하고 단계 시각은 시도마다 따로 남긴다. 판정·추출 결과는 바뀌지 않는다(CR-11). [제안]

#### Scenario: 실행 기록 저장
- **WHEN** 언어 모델과 함께 문서 하나로 검토를 끝까지 처리하면
- **THEN** 요청 수는 실제 요청 수, 재시도 0, 토큰은 요청마다 받은 토큰의 합이고, 문서 읽기부터 할 일 전달까지 단계마다 걸린 시간이 남는다

#### Scenario: 같은 파일을 다시 처리
- **WHEN** 같은 파일로 검토를 두 번 처리하면
- **THEN** 두 번째 실행의 다시 쓴 문서 수는 1이고 요청 수는 첫 번째보다 적다

#### Scenario: AI 재시도 기록
- **WHEN** 언어 모델이 계속 실패해 처리가 멈추면
- **THEN** 요청 3, 재시도 2와 실패 단계가 남고, 멈춘 단계의 끝 시각도 남는다

### Requirement: 실행 기록 응답
시스템은 실행 기록 API로 검토마다 검토 번호와 이름, 상태, 시작·끝 시각, 걸린 시간, 모델, 사전 판, 요청·재시도 수, 토큰, 추정 비용, 문서 수와 다시 쓴 문서 수, 요구사항·판정 수, 다시 시도 횟수, 단계별 걸린 시간을 최근 실행부터 줘야 한다(SHALL). 추정 비용은 모델 단가(팀 가정, 1$ = 1,500원)로 계산하고 팀 가정 표시를 붙인다(CR-06). 단가표에 없는 모델은 비용을 비우고, 언어 모델 없이 돈 실행은 0원이다. [제안] [확인 필요: 모델 단가]

#### Scenario: 단가로 어림한 비용
- **WHEN** gemini-3.8-flash로 입력 73,556 · 출력 28,775 · 생각 77,778 토큰을 쓴 실행의 비용을 계산하면
- **THEN** 약 680원(650~720원)이다

#### Scenario: 언어 모델 없이 돈 실행
- **WHEN** 언어 모델 키 없이 처리한 실행을 실행 기록에서 보면
- **THEN** 요청 0, 비용 0원이고 팀 가정 표시가 없다
