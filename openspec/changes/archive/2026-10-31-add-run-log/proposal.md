# Proposal

## Why

검토마다 시스템이 어떻게 돌았는지(걸린 시간, AI 모델, 호출·재시도 횟수, 토큰, 비용, 이전 결과 재사용)를 볼 곳이 없었다.
단계별 시간은 덮어써져 남지 않았고 AI 호출 수는 로그에만 있었다. 2026-10-31 주말 검토에서 "검토 등록마다 시스템 값을 저장하고
관리하는 화면"을 요청했고, 발표의 개선 전·후 비교(AI 기술 활용성 "테스트를 통한 개선")와 재사용·재시도 제한(CR-11·12)을
숫자로 보이는 근거로 쓴다. 보류 메모 `backlog/실행기록_화면_보류.md`, 통합 개발 목록 2장 3번.

관련: NFR-05, NFR-09(새로), CR-06, CR-12, `review-run`, `review-workspace`.

## What Changes

- 실행마다 AI 요청 수·재시도 수·입력·출력·생각 토큰, 다시 쓴 문서 수를 저장한다. 다시 시도하면 쌓인다.
- 단계마다 시작·끝 시각을 저장한다(다시 시도는 따로).
- 실행 기록 API: 검토마다 한 줄과 단계별 걸린 시간, 모델 단가(팀 가정)로 어림한 비용.
- 지식 관리 > "실행 기록" 화면(SCR-25).
- 마이그레이션 0019.

## Non-Goals

- 처리 뒤 사람 동작(확정·수정 때 문장 다시 쓰기, 비교 제품 바꾸기)의 AI 사용량. 처리 중 사용량만 센다.
- 실제 청구 금액 대조, 모델별 단가 화면에서 고치기.
- 기록 지우기·내보내기.
