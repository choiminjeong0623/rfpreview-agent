## ADDED Requirements

### Requirement: 요약 문장은 코드가 쓴다
시스템은 검토 요약과 홈 요약 문장을 정해진 틀에 숫자·이름·날짜를 채워 만들어야 한다(SHALL). 언어 모델을 부르지 않고, 같은 데이터면 같은 문장을 돌려준다. 응답은 문장마다 글자·링크·강조 조각 목록과 만든 시각, 쓴 주체 "CODE"를 담는다. [결정 Q1]

#### Scenario: 같은 데이터면 같은 문장
- **WHEN** 데이터가 바뀌지 않은 검토의 요약을 두 번 부르면
- **THEN** 두 응답의 문장 조각이 같고, 쓴 주체는 CODE다

#### Scenario: AI를 부르지 않음
- **WHEN** 언어 모델 호출이 실패하도록 바꾼 채 요약을 부르면
- **THEN** 요약 문장이 그대로 나온다

### Requirement: 검토 요약
시스템은 `GET /runs/{id}/summary`로 검토 요약을 최대 4문장 돌려줘야 한다(SHALL). 반려·승인 단계 안내, 꼭 볼 판정 수(일탈·질의·확인 필요, 판정 탭 수와 같음)와 상신 권장일(마감 2일 전), 먼저 볼 일탈 후보 두 줄(판정 상세 링크), 마지막 개정의 줄 수, 데이터시트 빈 작성 칸 수를 이 순서로 쓴다. 처리 중이면 아직 요약할 판정이 없다는 한 문장이다. 없는 검토는 404.

#### Scenario: 꼭 볼 판정과 상신 권장일
- **WHEN** 마감이 11-10이고 일탈 후보 2건·질의 후보 1건·확인 필요 3건인 검토의 요약을 부르면
- **THEN** "꼭 볼 것 6줄은 일탈 후보 2건, 질의 후보 1건, 확인 필요 3건입니다. 상신 권장일은 11-08입니다."가 나오고 11-08은 강조 조각이다

#### Scenario: 먼저 볼 일탈 후보 링크
- **WHEN** 일탈 후보가 3건인 검토의 요약을 부르면
- **THEN** 두 줄이 판정 상세(`/reviews/{id}/judgments/{jid}`) 링크로 나오고 "외 1건"이 붙는다

#### Scenario: 개정과 빈 작성 칸
- **WHEN** 문서를 더해 다시 판정했고 데이터시트 빈 작성 칸이 있는 검토의 요약을 부르면
- **THEN** 개정 줄 수 문장에 "바뀐 줄 보기"(`?rev=1`) 링크가, 빈 칸 문장에 "데이터시트 채우기" 링크가 있다

### Requirement: 홈 요약
시스템은 `GET /home/summary?user_id=`로 홈 요약을 돌려줘야 한다(SHALL). 첫 문장의 내 차례 검토 수는 홈 "내가 처리할 건"과 같은 규칙·같은 목록(최근 200건)으로 센다. 먼저 할 검토(마감 빠른 순)와 할 일, 상신 권장일·제출 마감, 분석이 멈춘 내 검토, 결재 중이거나 협조 회신을 기다리는 내 검토를 쓴다. 견적·품질·영업 사용자는 회신하지 않은 자기 부서 협조 요청 수를 쓴다. [결정 Q1]

#### Scenario: 내 차례 수가 홈 칸과 같음
- **WHEN** 엔지니어가 판정 확인 단계 검토 2건과 실패한 검토 1건을 가진 채 홈 요약을 부르면
- **THEN** 첫 문장이 "내 차례인 검토는 3건입니다."로 시작하고 마감이 가장 빠른 검토가 링크로 나온다

#### Scenario: 부서 사용자
- **WHEN** 품질 담당이 회신하지 않은 품질 협조 요청이 있는 채 홈 요약을 부르면
- **THEN** 내 차례 검토가 없다는 문장과 회신하지 않은 품질 요청 수, 협조 요청 화면 링크가 나온다

### Requirement: 요약 상자
화면은 검토 상세 제목 줄 아래와 홈 나의 업무 아래에 요약 상자를 보여야 한다(SHALL). 상자에는 "요약"과 "코드가 씀" 꼬리표, 요약 시각, [다시 요약], 문장(링크는 그 화면으로 이동)이 있다. 요약을 부르지 못하면 상자를 숨기지 않고 "요약을 만들지 못했습니다"와 [다시 요약]을 보인다. 검토가 처리 중이면 검토 상세에는 상자를 두지 않는다. [결정 Q1]

#### Scenario: 검토 상세 요약 상자
- **WHEN** 담당자 확인 단계 검토 상세를 열면
- **THEN** 제목 줄 아래에 "요약" · "코드가 씀" 상자와 꼭 볼 것 문장이 보이고, 일탈 후보 링크를 누르면 그 판정 상세로 간다

#### Scenario: 홈 요약 상자
- **WHEN** 엔지니어가 홈을 열면
- **THEN** 나의 업무 아래 요약 상자 첫 문장의 수가 "내가 처리할 건" 칸의 수와 같다

#### Scenario: 요약 실패
- **WHEN** 요약 API가 실패하면
- **THEN** 상자에 "요약을 만들지 못했습니다"가 보이고 [다시 요약]을 누르면 다시 부른다
