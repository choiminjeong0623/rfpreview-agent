# Proposal

## Why

2026-10-29 minjeong이 실제 RFP(Bidding Forms)를 돌렸을 때, 문서가 문서 목록(document_catalog)에 없으면 묶음 C로 빠져
판정이 0건이 되는데 화면에서는 그 이유를 알 수 없었다. 검토 상세 머리글에는 "문서 n개" 글자만 있고,
어느 문서가 어떤 종류·묶음으로 분류됐는지, 판정 대상인지, AI가 종류를 정했는지 보이지 않는다.
목업 v4.57 검토 상세 머리글은 "문서 n개"를 눌러 문서 목록을 열고 "묶음 A·B"를 함께 보여 준다.
값은 이미 `GET /api/runs/{id}/documents`(FR-01 분류 결과)에 있다.

## What Changes

- 검토 상세 머리글에 이번 검토에서 판정에 쓰는 묶음을 "묶음 A·B"처럼 보인다. 판정 대상 문서가 없으면 "판정 문서 없음"으로 눈에 띄게 보인다.
- "문서 n개"를 단추로 바꾸고, 누르면 문서 표 창이 열린다. 칸: 파일 번호, 파일 이름, 문서 종류, 분류 방법(규칙·AI·사람), 묶음, 판정 대상, 요구사항 수, 확인 필요.
- 묶음 C·D이거나 글자를 읽지 못해 판정하지 않는 문서는 "판정 안 함"과 이유(문서 목록에 없음, 판정 범위 밖 묶음, 글자 읽기 실패)를 눈에 띄게 보인다.

## Non-Goals

- 묶음·문서 종류를 화면에서 고치기(다음 단계).
- 문서 추가(Addendum) 창. 목업의 "문서 추가"는 실행 단위라 이번 범위 밖이다(SCR-08_공유.md).
- API 응답 칸은 바꾸지 않는다.

## Impact

- 명세 `review-workspace`: 요구사항 "검토 상세 문서 표" 추가.
- 화면: `ReviewDetail` 머리글, 새 `DocumentsDialog`. 관련 FR-01, CR-09.
