# Proposal

## Why

검토 목록 요약 줄에서 누를 수 있는 칸은 "결재 대기"뿐이고, 누르면 단계 거름 칸만 바꿔 주소에 남지 않는다. 그래서 브라우저 뒤로 가기를 눌러도 전체 목록으로 돌아오지 않고, 다시 누르거나 "모두 보기"로 풀 방법도 없다. 내가 처리할 건·분석 실패·결재 완료는 눌러도 아무 일이 없다.

관련: SCR-06 검토 목록, update-list-my-turn, update-list-summary-rest, 사업 현황 요약 칸 거르기(update-home-projects).

## What Changes

- 요약 줄 칸(내가 처리할 건, 결재 대기, 분석 실패, 결재 완료, 분석 중)을 모두 누를 수 있게 하고, 누르면 아래 목록을 그 칸의 검토만으로 거른다.
- 거른 조건은 화면 주소에 남긴다(`#/reviews?sum=…`). 브라우저 뒤로 가기를 누르면 전체 목록으로 돌아오고, 검토를 열었다가 뒤로 오면 거른 목록이 그대로다.
- 거르는 동안 목록 위에 "결재 대기 11건만 보는 중"과 [모두 보기]를 보이고, 누른 칸은 눌린 상태로 보인다. 같은 칸을 다시 누르거나 [모두 보기]를 누르면 전체로 돌아온다.
- 칸 숫자와 거른 목록 수는 같은 규칙으로 센다.

## Non-Goals

- 백엔드·API 변경 없음.
