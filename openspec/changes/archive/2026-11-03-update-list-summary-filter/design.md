# Design

## 결정

- **주소에 남긴다.** `useHashPath()`로 `?sum=mine|approval|failed|approved|processing`을 읽는다. 칸을 누르면 `navigate('/reviews?sum=…')`(방문 기록 남김), 다시 누르거나 [모두 보기]면 `navigate('/reviews')`. 뒤로 가기는 브라우저가 해 준다. 담당 범위·찾기 상태는 화면 상태로 그대로 둔다.
- **칸과 같은 규칙.** 내가 처리할 건 = 전체 목록에 `myTurn(user)`(홈과 같음), 나머지 = 담당 범위로 거른 목록(`owned`)의 단계. 칸이 기간을 보지 않으므로 거른 목록도 기간을 보지 않는다. 찾기(검색어·있는 항목)는 함께 적용한다.
- **단계 거름 칸은 바꾸지 않는다.** 예전에는 결재 대기를 누르면 단계 칸이 "결재 대기"로 바뀌었지만, 이제 요약 칸 거름은 따로이고 단계 칸과 함께 걸린다.
- **띠 모양.** 사업 현황 "…건만 보는 중 · 모두 보기"와 같은 띠(`.sumbar`, 토큰 색).

## 대안

- 화면 상태로만 두기: 뒤로 가기·새로고침에 거름이 사라져 버림.
