# Design

## 결정

- **값 먼저, 원문은 펼쳐 보기.** 판단에 쓰는 것은 종류·값·위치다. 원문은 확인할 때만 필요해 한 줄로 줄이고 줄을 눌러 펼친다. 위험 조건 탭이 위치를 눌러 원문 줄을 펼치는 방식과 같다.
- **AI 요약은 쓰지 않는다.** 값(기간·비율)은 코드가 뽑은 것이 있고, AI 문장 속 숫자는 근거 대조가 필요하다(CR-07). 규칙 결과만으로 짧게 보인다.
- **고정 칸.** `table-layout: fixed`와 `colgroup`(종류 150px · 내용 나머지 · 위치 240px · 상태 120px)을 두 표에 같이 쓴다.
- **위치 줄임.** 파일 이름 대신 문서 종류 이름(입찰 양식 등, 없으면 파일 n)을 앞에 두고 `title`에 전체 위치를 둔다.
- **상업 영향 묶기.** 종류·제품·가산액·팀 가정·내용이 같으면 한 줄, 위치는 첫 위치 + "외 n곳".

## 대안

- 원문을 옆 창(패널)으로: 한 탭 안에 창이 하나 더 생겨 판정 상세와 겹쳐 보여 버림.
- 원문 칸을 아예 없앰: 값이 없는 조건(책임 한도 없음 등)은 무엇인지 알 수 없어 버림.
