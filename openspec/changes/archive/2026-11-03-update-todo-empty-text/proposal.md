# Proposal

## Why

협조 요청 화면에서 부서 탭·상태(미발송·회신 대기·24시간 넘게 회신 없음·회신 완료)로 걸러 0건이면 요청 항목에 "조건에 맞는 요청이 없습니다."와 [조건 지우기] 단추가 함께 보인다. 조건은 바로 위 검색 영역 [초기화]와 조건 칩으로 이미 풀 수 있어 단추가 겹치고, 빈 결과 칸이 단추 때문에 무거워 보인다.

관련: SCR-13 협조 요청, update-todo-search.

## What Changes

- 맞는 요청이 없으면 요청 항목에 "조건에 맞는 요청이 없습니다." 문장만 보인다. [조건 지우기] 단추는 없앤다.
- 조건 풀기는 검색 영역 [초기화]와 조건 칩(×)으로 한다(그대로).

## Non-Goals

- 요청이 하나도 없는 부서의 빈 안내 문장은 그대로.
