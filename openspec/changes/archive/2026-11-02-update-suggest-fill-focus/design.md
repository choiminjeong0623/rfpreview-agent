# Design

## 결정

- **옮기고, 커서 두고, 선택.** 채운 뒤 다음 그리기 때 표현 칸을 `scrollIntoView({ block: 'center' })`, `focus()`, `select()`. 선택해 두면 사람이 바로 줄일 부분만 고칠 수 있다.
- **강조.** 제안 줄(`.rk-f`)에 1.5초 동안 강조 클래스를 붙인다. 움직임 줄이기 설정이면 색만 바꾼다.
- **알림은 동작 결과(update-action-toast-place).** 무엇을 했고 다음에 무엇을 해야 하는지 한 문장.

## 대안

- 제안 칸을 후보 목록 위로 옮기기: 직접 찾은 표현을 넣는 칸이기도 해서 순서를 바꾸면 "사람이 찾은 특이 요구" 흐름이 끊겨 버림.
- 후보 줄마다 바로 [제안] 보내기: 100자 문장이 그대로 사전 후보가 되어 규칙 담당이 다시 줄여야 해 버림.
