# PDF 문서 읽기

## 왜

- 실제 입찰 꾸러미에는 PDF가 많다(입찰 안내서 ITB, 발주처가 PDF로만 주는 사양서). 지금은 docx만 받아 PDF는 엔지니어가 손으로 옮기거나 빼야 한다.
- 문서 처리 단계(구조·추출·값·판정)는 "단락과 표 행" 모양만 있으면 된다. PDF를 같은 모양으로 읽으면 뒤 단계는 그대로 쓴다.

## 무엇

- **글자가 든 PDF 읽기**: 쪽마다 표를 찾아 표 행으로, 표 밖 글자 줄은 줄 간격으로 단락을 묶어 단락으로 바꾼다. 줄 번호는 문서 처음부터 이어 센다. 원문 위치는 docx와 같은 모양(파일 번호 + 절/표 + 행)이다(CR-03).
- 글자가 없는(스캔한) PDF는 지금의 이미지 문서처럼 판독 불가로 두고 이후 단계를 건너뛴다(OCR은 다음 change `add-ocr`).
- **받는 곳**: 검토 등록·문서 추가 올리기, 서버에 둔 RFP 목록, 분석 전 분류 추천이 `.pdf`도 받는다.
- 분류(묶음·종류·언어·규격 체계)·처리 판·재사용(내용 해시)은 docx와 같다.

## 하지 않음

- OCR(스캔한 쪽·그림 속 글자) — `add-ocr`에서.
- PDF 그림 위치 기록, PDF로 내보내기, 암호 걸린 PDF(판독 불가로 둠).

관련: 명세서 FR-01 ②, 기획서 6장 문서 접수·변환.
