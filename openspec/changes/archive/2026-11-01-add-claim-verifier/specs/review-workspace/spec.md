## ADDED Requirements

### Requirement: AI 검증 표시
화면은 위험 조건 탭에서 검증이 확인 필요인 설명 옆에 "AI 검증: 확인 필요"를, 실행 기록 화면 검토 줄에 검증 확인 필요 수를(0이면 보이지 않음) 보여야 한다(SHALL). [제안 11-01]

#### Scenario: 검증 확인 필요 보기
- **WHEN** 설명 하나가 검증에서 확인 필요인 검토의 위험 조건 탭과 실행 기록 화면을 열면
- **THEN** 그 위험 조건 줄에 "AI 검증: 확인 필요"가, 실행 기록 줄에 "검증 확인 필요 1"이 보인다
