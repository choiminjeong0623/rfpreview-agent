## ADDED Requirements

### Requirement: 실행 기록의 흐름 기록
화면은 실행 기록 화면에서 줄을 펼치면 단계별 걸린 시간 아래에 흐름 기록(단계 이름, 걸린 시간, 바뀐 값, 사람 동작, 멈춘 자리)을 보여야 한다(SHALL). 흐름 기록이 없는 검토는 "흐름 기록 없음"을 보인다. 흐름 기록은 보기만 하고 바꾸는 단추는 없다. [제안 11-02, C2]

#### Scenario: 흐름 기록 펼치기
- **WHEN** 엔지니어가 실행 기록 화면에서 담당자 확인까지 처리한 검토 줄을 누르면
- **THEN** 흐름 기록에 판정 단계의 "판정 0 → n"과 "담당자 확인에서 멈춤"이 보인다
