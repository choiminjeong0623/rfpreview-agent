## ADDED Requirements

### Requirement: 흐름 기록 응답
시스템은 검토 하나의 저장된 흐름 기록을 단계 순서대로 돌려주어야 한다(SHALL). 단계마다 단계 이름, 끝난 시각, 걸린 시간, 바뀐 값(건수의 전과 후), 그 단계에서 받은 사람 동작을 내고, 마지막에 흐름이 멈춘 자리(사람 단계 이름, 처리 중간이면 다음 단계, 끝)를 낸다. 흐름 기록을 불러도 흐름과 검토 단계는 바뀌지 않는다(읽기 전용). 흐름 기록이 없는 검토는 빈 목록과 기록 없음을 낸다. [제안 11-02, C2]

#### Scenario: 담당자 확인까지 처리한 검토
- **WHEN** 담당자 확인에서 멈춘 검토의 흐름 기록을 부르면
- **THEN** 문서 처리부터 담당자 배정까지 단계가 순서대로 오고 판정 단계에 판정 수가 0에서 그 검토의 판정 수로 바뀐 값이 있으며, 멈춘 자리는 담당자 확인이고 검토 단계는 그대로다

#### Scenario: 상신한 검토
- **WHEN** 결재를 상신한 검토의 흐름 기록을 부르면
- **THEN** 담당자 확인 단계에 사람 동작 "상신"이 남고 멈춘 자리는 승인 대기다

#### Scenario: 흐름 기록이 없는 검토
- **WHEN** 흐름 기록이 없는 검토의 흐름 기록을 부르면
- **THEN** 단계 목록이 비어 있고 기록 없음이다
