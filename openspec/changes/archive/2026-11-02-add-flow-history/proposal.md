# 흐름 기록 보기 (C조 C2 이어서)

## 왜

- C2(update-graph-stops)로 검토 흐름의 상태가 단계마다 DB에 저장된다(LangGraph checkpoint). 그런데 지금은 그 기록을 다시 시도할 때만 쓰고, 사람이 볼 방법이 없다.
- "어느 단계에서 무엇이 바뀌었나, 사람이 언제 무엇을 했나"를 보이면 사람이 개입하는 AI 흐름(Human-in-the-loop)이 실제로 어떻게 돌았는지 설명할 수 있다(평가: AI 기술 활용성).

## 무엇

- **흐름 기록 응답**: 검토 하나의 저장된 흐름을 순서대로 돌려준다. 단계마다 단계 이름, 끝난 시각, 걸린 시간, 바뀐 값(예: 판정 수 0 → 42, 문서 수), 그 단계에서 받은 사람 동작(상신·승인·반려·상신 취소·다시 확인·문서 추가). 마지막에 흐름이 멈춘 자리(담당자 확인·승인 대기·반려됨, 처리 중간, 끝).
- 읽기 전용: 흐름을 바꾸거나 되돌리지 않는다. 흐름 기록이 없는 예전 검토는 "흐름 기록 없음".
- **실행 기록 화면**: 줄을 펼치면 지금의 단계별 걸린 시간 아래에 흐름 기록을 보인다.

## 하지 않음

- 특정 단계로 되돌리기(C2 후보 (f), 사람 확정 규칙을 먼저 정해야 해서 따로).
- 흐름 상태 전체(파일 경로·분류)를 그대로 보이기. 건수와 사람 동작만 보인다.
