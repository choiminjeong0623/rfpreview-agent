# Proposal

## Why

제안 문장이 "GIS-145-40는 325 kV로 …"처럼 나온다. 코드 문장 틀과 언어 모델 문장 모두 자리표시자({p}) 뒤에 조사를 하나로 적어 두는데, 채우는 값(제품 코드·숫자)의 끝 글자를 모르기 때문이다.
"0"(영)으로 끝나는 코드는 "은"이 맞다. 2026-10-31 나송주 구역 주말 검토(시험 13번)에서 찾았다.

관련: FR-14, CR-07(자리표시자를 코드가 채움), `proposal-points`.

## What Changes

- 자리표시자 바로 뒤의 한쪽 조사(은/는, 이/가, 을/를, (으)로, 과/와)를 채운 값의 끝 글자에 맞춰 코드가 고른다.
- 제안 문장, 일탈·질의 문장 등 자리표시자를 채우는 모든 문장에 같이 적용된다.
- 이미 저장된 문장은 그대로 두고, 새로 쓰거나 값이 바뀌어 다시 쓰는 문장부터 적용된다.

## Non-Goals

- 자리표시자가 아닌 곳의 맞춤법 고치기.
