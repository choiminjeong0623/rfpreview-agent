# 사람 확정 답 재사용 (지난 확정 힌트)

## 왜

- 10-27 현업 멘토링: "사람이 고친 검토 결과를 쌓아 다음엔 사람이 안 봐도 되게".
- 효율 개선 제안(10-31) 2번 "사람이 확인한 답 재사용". 같은 고객·같은 표준 문구가 반복되는데, 지금은 다음 검토가 지난 사람 판정을 전혀 읽지 않는다.
- 11-01 minjeong: "효율 개선의 나머지와 사전 추가 제안까지만".

## 무엇

- 판정마다 같은 요구 원문·항목·요구값·비교 제품의 판정을 **다른 검토에서 사람이 확정·수정**했으면, 가장 최근 것을 "지난 확정"으로 함께 낸다(판정 값, 검토 번호, 사람, 날짜, 사유, 지금과 같은지).
- 판정 탭: 줄에 "지난 확정" 꼬리표(다르면 주황), 상세 패널에 지난 판정과 사유, 칩 "지난 확정과 다름 n"으로 거르기.
- 판정 값은 바꾸지 않는다(CR-01·08). 힌트는 후보를 확정하는 사람의 참고일 뿐.

## 하지 않음

- 유형 붙이기(AI 비용 90 %) 재사용: 사람이 유형을 확정하는 곳이 없다. 정답지 줄을 쓰면 K13 채점을 오염시킨다.
- 지난 확정대로 자동 확정: 사람 검토를 건너뛰지 않는다(SCR-19 안내와 같음).

관련: 명세서 FR-10 ④⑥, 기획서 부록 B, 기획서 2-2 K5.
