## ADDED Requirements

### Requirement: 공통 목록 표의 순번
시스템은 공통 목록 표 부품으로 그린 표의 맨 왼쪽에 "순번" 칸을 보여야 한다(SHALL). 번호는 쪽을 넘겨도 이어지고(둘째 쪽 첫 줄 = 쪽 크기 + 1), 거르기를 바꾸면 거른 결과의 1부터 다시 센다. 표 부품은 로딩 중·빈 목록·오류 상태를 공통 규칙대로 보인다. [결정]

#### Scenario: 쪽을 넘겨도 순번이 이어짐
- **WHEN** 부품 견본 화면에서 12줄짜리 표를 10줄씩 보다가 2쪽으로 넘기면
- **THEN** 첫 줄의 순번이 11이다

#### Scenario: 빈 목록
- **WHEN** 줄이 없는 표를 보면
- **THEN** 표 안에 그 표의 빈 목록 문장이 한 줄 보인다

### Requirement: 알림 쌓기
시스템은 화면 알림이 동시에 여러 개면 화면 오른쪽 위에 위에서 아래로 쌓아 모두 보여야 한다(SHALL). 성공·안내 알림은 4초 뒤 사라지고, 오류 알림은 닫기 전까지 남는다. 같은 문장의 알림이 이미 보이면 하나만 보인다. [결정]

#### Scenario: 알림 두 개
- **WHEN** 부품 견본 화면에서 알림 두 개를 잇달아 띄우면
- **THEN** 두 알림이 모두 보이고 먼저 띄운 것이 위에 있다

#### Scenario: 오류 알림은 남음
- **WHEN** 오류 알림을 띄우고 5초가 지나면
- **THEN** 오류 알림은 남아 있고, 닫기를 누르면 사라진다

### Requirement: 잠긴 단추의 이유
시스템은 권한이나 단계 때문에 누를 수 없는 공통 단추를 숨기지 않고 잠근 채 이유를 보여야 한다(SHALL). 이유는 마우스를 올리면 보이고 화면 읽기 도구로도 읽힌다. [결정]

#### Scenario: 잠긴 단추에 이유
- **WHEN** 부품 견본 화면의 잠긴 단추를 보면
- **THEN** 단추는 눌리지 않고 "승인자만 결정할 수 있습니다" 이유가 단추 설명으로 붙어 있다

### Requirement: 공통 창 닫기
시스템은 공통 창 부품으로 연 창을 Esc, 창 바깥 누르기, 닫기 단추로 닫아야 한다(SHALL). 창이 열리면 첫 입력 칸(없으면 창)에 초점이 가고, 닫히면 창을 연 단추로 초점이 돌아간다. [결정]

#### Scenario: Esc로 창 닫기
- **WHEN** 부품 견본 화면에서 창을 열고 Esc를 누르면
- **THEN** 창이 닫히고 창을 연 단추에 초점이 있다
