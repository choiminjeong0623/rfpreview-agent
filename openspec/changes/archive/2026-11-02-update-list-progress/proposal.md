# Proposal

## Why

검토를 등록하면 검토 목록 그 줄은 "처리 중" 칩과 이름 옆 "○○ 중 n%" 꼬리표만 보여, 목업 v4.96의 목록 줄 진행 막대(단계 칩 아래 막대와 "3/7 요구사항 문장 찾기 · 7 %")와 다르다. 얼마나 남았는지, 멈췄는지가 줄에서 바로 보이지 않는다.

관련: SCR-06 검토 목록, 목업 v4.96 "목록 줄 진행 막대"(v4.60), `review-workspace` "처리 중 목록 새로고침".

## What Changes

- 처리 중인 줄의 단계 칸에 칩 아래 진행 막대와 "n/11 지금 단계 · p %"를 보인다. 진행률·단계 문장은 머리글 분석 진행과 같은 계산(`components/progress`).
- 10분 넘게 진행이 없으면 막대와 글자를 주황으로(머리글 멈춤 기준과 같음).
- 이름 옆 꼬리표는 단계 이름만("요구사항 추출 중"), 백분율은 막대 쪽으로 옮긴다.
- 화면만. API 변경 없음.
