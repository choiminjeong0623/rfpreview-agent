# Design

## 결정

- **단계 순번은 처리 단계 11개 기준.** 목업은 7단계지만 실제 흐름은 `documents`부터 `assign`까지 11단계다(`components/progress` STEPS, 시작 전 `created` 제외). 문서 읽기 단계는 세부 일(예: "AI로 유형 붙이는 중")을 보인다. 줄 수는 목록이 좁아 뺀다(머리글 창과 처리 상태 화면에서 본다).
- **막대·멈춤은 머리글과 같은 부품 모양.** `.anbar`(3px로 낮춤), 멈춤 기준 `STALL_MS`(10분).
- **멈춤 판단 시각은 다시 불러올 때마다.** 렌더 중 `Date.now()`를 부르지 않고, 5초마다 목록을 다시 부를 때 시각을 함께 갱신한다.
