# Proposal

## Why

엔지니어가 결재를 올린 뒤 "내가 올린 검토가 지금 결재 대기인지, 반려됐는지, 승인됐는지"를 한 번에 볼 곳이 없다.
검토 목록에는 단계 거름과 요약 줄 "결재 대기 n"이 있지만, 요약 줄은 숫자만 보이고 누를 수 없으며,
목록 응답(`RunListItem`)에 결재자·상신한 사람 칸이 없어 "내가 올린 결재"만 골라 볼 수 없다.
반려되면 엔지니어가 다시 고쳐야 하므로 이것은 주 사용자(입찰 기술 검토 엔지니어 [결정], 기획서 3-1)의 일이다.

2026-10-31 minjeong 결정: 결재 건만 보는 기능은 새 메뉴("결재함")가 아니라 **검토 목록 안 결재 보기**로 만든다.
주 사용자 원칙에 맞춰 엔지니어 쪽(내가 올린 결재)만 만들고, 결재자 전용 보기는 만들지 않는다.

관련: FR-10(확인·승인 흐름), `update-approval-flow`(결재자 고르기·상신 취소), CR-08(확정은 사람).

## What Changes

- 실행 목록 응답에 가장 최근 상신의 결재 정보(결재자, 상신한 사람, 상신 시각, 결정, 결정 시각)를 더한다. 취소한 상신은 넣지 않는다.
- 검토 목록 담당 범위에 "내가 올린 결재" 보기를 더한다. 머리글에서 고른 사용자가 상신한 검토만, 결재 대기·반려·승인으로 나눠 보여 준다.
- 이 보기의 줄에 결재자, 상신 후 날 수, 결정과 결정 시각을 보여 준다.
- 요약 줄 "결재 대기 n"을 누르면 단계 거름이 결재 대기로 걸린다. 홈의 "결재 대기" 칸에서 검토 목록 결재 보기로 가는 링크를 둔다.

## Non-Goals

- 새 메뉴·새 화면 주소("결재함"). 왼쪽 메뉴는 목업 v4.57 그대로 둔다.
- 결재자 전용 "내가 결재할 건" 보기, 결재 요청 다시 알림, 열람 시각(`update-approval-flow` Non-Goal 그대로).
- 결재 결정 방식 변경. 결재는 지금처럼 결재 대기 상세(SCR-12)에서 한다.

## Capabilities

### New Capabilities
없음.

### Modified Capabilities
- `review-run`: 실행 목록 응답의 결재 정보.
- `review-workspace`: 검토 목록 "내가 올린 결재" 보기, 요약 줄 결재 대기 거름.

## Impact

- 백엔드: `pipeline/queries.py` `run_list`, `api/schemas.py` `RunListItem`. DB 변경 없음(`approval` 표의 기존 칸).
- 프런트: `views/ReviewList.tsx`, `views/Home.tsx`(링크만), `openapi.json`·`src/api.gen.ts` 다시 만들기.
- 문서: `docs/screens/SCR-06-검토목록.md`, `SCR-06_공유.md`.
- 담당: 최민정(결재 구역). `Home.tsx`는 박경빈 님 파일이라 링크 한 줄만 고치고 알린다.
