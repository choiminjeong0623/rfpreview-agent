# Proposal

## Why

검토 등록 3단계에서 [등록하고 분석 시작]을 누르면 단추만 "등록하는 중…"으로 잠긴다. 수백 쪽 RFP 여러 개(수십 MB)를 올리면 파일을 보내고 서버가 문서를 확인해 검토를 만들 때까지 수십 초가 걸리는데, 그동안 얼마나 올라갔는지·멈췄는지 알 수 없다.

관련: SCR-07 검토 등록, add-document-confirm, reject-unjudged-registration.

## What Changes

- 등록을 누르면 아래 줄 위에 진행 막대와 설명을 보인다.
  - 내 컴퓨터에서 올리는 파일: 실제로 보낸 크기로 "파일 올리는 중 · 12.3 / 45.6 MB · 27 %".
  - 다 올라갔거나 서버에 둔 RFP를 고른 경우: 끝을 모르는 움직이는 막대와 "문서를 확인하고 검토를 만드는 중…".
- 실패하면 막대를 지우고 지금처럼 오류 문장을 보인다. 끝나면 지금처럼 등록 완료 화면.

## Non-Goals

- 분석 진행(처리 중 화면·머리글 진행)은 그대로.
- 백엔드·API 변경 없음(같은 `POST /api/runs`, 보내는 방법만 진행을 받을 수 있게).
