# 설계

- `tasks.type_unclassified(llm, texts, on_progress, contexts=None)`: contexts는 줄마다 문자열 또는 None. 묻는 글 줄은 `n. [문맥] 문장`, 문맥이 없으면 `n. 문장`(예전과 같은 모양).
- 문맥 만들기(`document.py`): `절 <번호> <제목>`, `표 <이름>`, `구분 <part_title>`을 " · "로 잇고 120자에서 자른다. 줄바꿈은 없앤다.
- PROMPT_VERSION p3. 처리 키 `model/p3`가 바뀌어 같은 파일도 다시 분석한다(CR-11: 같은 판이면 같은 결과).
- 토큰: 줄마다 문맥이 최대 120자 늘어난다. 같은 절·표의 줄이 이어지므로 묶음 머리에 한 번만 쓰는 안도 있었지만, 40줄 묶음에 여러 표가 섞이고 번호 답과 맞추기 쉬워 줄마다 붙였다.
