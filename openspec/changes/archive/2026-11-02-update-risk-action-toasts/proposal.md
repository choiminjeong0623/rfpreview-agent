# Proposal

## Why

위험 조건 탭에서 "위험으로 확정", "문제 없음 → 닫기", "위험 표현 사전에 추가 제안"을 눌러도 줄의 상태 칩만 조용히 바뀐다. 눌렀는지, 무엇이 바뀌는지(질의 후보, 결재 확인 사유, 규칙 담당 확인) 알 수 없어 엔지니어가 다시 누르거나 다른 화면을 찾아본다.

관련: SCR-08-3, `review-workspace` "위험 조건 탭", FR-06·FR-10, add-rule-suggestion.

## What Changes

- 세 동작이 끝나면 화면 공통 알림(오른쪽 위, 4초)에 무엇을 했고 그다음 무엇이 바뀌는지 한 문장으로 보인다.
  - 위험으로 확정: “표현”: 위험으로 확정했습니다. 질의 후보와 결재 확인 사유에 남습니다.
  - 문제 없음으로 닫기: “표현”: 문제 없음으로 닫았습니다. 이 조건에서 만든 질의 후보는 목록에서 빠집니다.
  - 사전 추가 제안: “표현”: 위험 표현 사전에 추가를 제안했습니다. 규칙 담당이 판정 규칙 화면에서 반영하면 다음 검토부터 잡힙니다. [판정 규칙 보기]
- 위험 조건 탭 안 문장 저장 알림도 같은 공통 알림을 쓴다.

## Non-Goals

- 확정·닫기 되돌리기는 하지 않는다(되돌리는 API가 없음).
- 백엔드·API 변경 없음.
