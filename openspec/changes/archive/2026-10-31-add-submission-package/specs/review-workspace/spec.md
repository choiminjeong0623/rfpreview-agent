## MODIFIED Requirements

### Requirement: 제출본 탭
시스템은 제출본 탭에 승인된 실행의 제출본을 버전(v1), 확정 시각(승인 시각), 결재자, 판정 줄 수, 일탈·질의 후보 수, 첨부, 상태("현재 제출본")로 보여야 한다(SHALL). 승인된 실행에는 "인계 패키지 내려받기"와 엔지니어용 "영업에 넘기기"를 두고, 마지막으로 넘긴 시각·받는 주소 또는 "주소 없음"·"발송 실패"를 보인다(`add-submission-package`). 승인 전이면 제출본이 없다는 안내를 보인다. 승인된 실행은 판정을 고칠 수 없으므로 승인 시점의 판정이 제출본이다. 머리 단추는 승인된 실행에서 "제출본 v1 확정"으로 보인다.

#### Scenario: 승인된 실행의 제출본
- **WHEN** 승인자가 승인한 실행의 제출본 탭을 열면
- **THEN** v1 줄에 결재자 이름, 판정 줄 수, 일탈·질의 후보 수와 "현재 제출본"이 보이고, 머리 단추는 "제출본 v1 확정"이다

#### Scenario: 승인 전 제출본 없음
- **WHEN** 담당자 확인 단계인 실행의 제출본 탭을 열면
- **THEN** "아직 확정된 제출본이 없습니다"로 시작하는 안내가 보인다

#### Scenario: 인계 패키지 영업에 넘기기
- **WHEN** 엔지니어가 승인된 실행의 제출본 탭에서 "영업에 넘기기"를 누르면
- **THEN** "영업 담당(주소)에게 인계 패키지를 보냈습니다" 알림이 보이고 탭에 넘긴 시각이 보인다

### Requirement: 데이터시트 채우기 화면
시스템은 검토 상세 머리의 "데이터시트 채우기" 단추로 데이터시트 화면을 열고, 데이터시트 고르기, 요약(제출할 칸, 채움 · 확정, 채움 · 후보, 확인 필요), 채움 막대, 보기 거르기(전체 / 후보 / 확인 필요 / 확정), 표, "엑셀 내려받기"를 보여야 한다(SHALL). 후보 줄의 "확정"은 담당자 확인 단계의 엔지니어만 누를 수 있고, 누르면 그 칸이 확정으로 바뀐다. "영업에 넘기기"는 엔지니어에게만 열리고, 후보 칸이 남아 있으면 "후보 n칸을 먼저 확정" 안내와 함께 막는다. 넘기면 "영업 담당에게 넘겼습니다. 확인 필요 n칸은 비운 채로 넘어갑니다." 알림이 보이고, 넘긴 표는 단추가 "다시 넘기기"로 바뀌며 넘긴 시각을 보인다(`add-submission-package`).

#### Scenario: 칸 확정
- **WHEN** 엔지니어가 후보 줄의 "확정"을 누르면
- **THEN** 그 줄 상태가 확정이 되고 "칸 n … 값을 확정했습니다." 알림이 보이며 채움 · 확정 수가 1 늘어난다

#### Scenario: 확인 필요만 보기
- **WHEN** 보기에서 "확인 필요"를 고르면
- **THEN** 채운 값이 빈 줄만 보인다

#### Scenario: 데이터시트 영업에 넘기기
- **WHEN** 엔지니어가 후보 칸이 없는 데이터시트에서 "영업에 넘기기"를 누르면
- **THEN** "영업 담당에게 넘겼습니다" 알림이 보이고 단추가 "다시 넘기기"로 바뀐다

#### Scenario: 후보가 남아 넘기기 막힘
- **WHEN** 후보 칸이 남은 데이터시트를 열면
- **THEN** "영업에 넘기기"가 막혀 있고 "후보 n칸을 먼저 확정" 안내가 보인다
