## ADDED Requirements

### Requirement: 데이터시트 채우기 화면
시스템은 검토 상세 머리의 "데이터시트 채우기" 단추로 데이터시트 화면을 열고, 데이터시트 고르기, 요약(제출할 칸, 채움 · 확정, 채움 · 후보, 확인 필요), 채움 막대, 보기 거르기(전체 / 후보 / 확인 필요 / 확정), 표, "엑셀 내려받기"를 보여야 한다(SHALL). 후보 줄의 "확정"은 담당자 확인 단계의 엔지니어만 누를 수 있고, 누르면 그 칸이 확정으로 바뀐다. "영업에 넘기기"는 잠근다.

#### Scenario: 칸 확정
- **WHEN** 엔지니어가 후보 줄의 "확정"을 누르면
- **THEN** 그 줄 상태가 확정이 되고 "칸 n … 값을 확정했습니다." 알림이 보이며 채움 · 확정 수가 1 늘어난다

#### Scenario: 확인 필요만 보기
- **WHEN** 보기에서 "확인 필요"를 고르면
- **THEN** 채운 값이 빈 줄만 보인다
