# Proposal

## Why

목업 v4.96 검토 상세는 머리글을 "제목 줄 → 정보 3묶음(검토·사업·판정 진행)"으로 다시 짜고, 탭을 5개 + "더 보기"로 줄이고, 화면 아래에 늘 보이는 행동 줄(확정 안 한 판정·준수 모두 확정·빈 작성 칸·결재 상신)을 붙였다.
지금 화면은 v4.57 모양(머리글 한 줄, 요약 칸 5개, 탭 9개, 판정 탭 위 내보내기 단추)이라 "무엇부터 볼지"와 "상신까지 남은 일"이 한눈에 보이지 않는다.
프런트 4단계 2번(`docs/screens/_v4.96_결정.md` 4장, minjeong 11-01 13:33 "여기서 시작합니다").

관련: 화면 명세 `docs/screens/SCR-08-검토상세.md` "v4.96 바뀐 점", `_공통규칙.md` 3장 상신 권장일(Q3).

## What Changes

- 제목 줄: "사업명 · 검토명" + 단계 배지, "기술 검토 RV-…", 오른쪽 단추 결과 새로 고침·문서 추가·**내보내기 ▾**(일탈 목록 초안 (Word)·질의서 초안 (Word)·TBE 준수표·데이터시트 채우기)·검토 도우미·검토 정보 고치기.
- 정보 3묶음: 검토(제출 마감·상신 권장·문서·묶음·규격 체계·담당·결재), 사업(사업명·고객사·국가·고객 입찰 번호·영업), 판정 진행(꼭 볼 것·준수 [묶어서 확정]·작성할 칸·손실 환산, 막대).
- 요약 칸 5개를 없앤다. 확인 필요 비율은 결재 상신 창에만 둔다(SCR-08-10).
- 탭 줄: 판정·위험 조건·문서 읽기 점검·상업 조건·이력, "더 보기 ▾"(손실 환산 (참고)·입찰 영향·지난 RFP 비교·제출본). 탭 이름 옆 수(꼭 볼 것, 확인 안 한 위험 조건, 확인 안 한 읽기 점검, 안 보낸 상업 조건 요청).
- 아래 행동 줄: 담당자 확인 단계에서 확정 안 한 판정 수, "준수 n줄은 모두 확정", 빈 작성 칸 + 데이터시트 채우기, 결재 상신. 다른 단계는 단계 안내 한 줄(승인됨이면 잠긴 "제출본 v1 확정").
- 판정 탭 위의 "준수 n줄 모두 확정" 띠와 내보내기 단추를 머리글·아래 줄로 옮긴다.

## Non-Goals

- 요약 상자(`add-screen-summary`), 개정 표시·개정 안내 띠(`add-revision-notice`): 결정 문서 4장 7·9번.
- 판정 탭 안의 "꼭 볼 것" 칩과 판정 상세 화면: 4장 3번(`add-judgment-view`)과 판정 탭 차례. 지금은 "꼭 볼 것"을 누르면 판정 탭(판정 순서로 정렬)을 연다.
- 새 API. 지금 응답(`judgment-counts`, `datasheets`, `losses`, `risks`, `read-checks`, `cost-conditions`, `businesses/{id}`)으로 만든다.
