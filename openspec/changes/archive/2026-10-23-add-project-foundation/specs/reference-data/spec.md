# Spec Delta

## Purpose

모든 검토 기능이 읽는 기준 데이터(스키마, 규칙 사전, 제품표, 고정 코드표)를 누구나 같은 상태로 준비하게 한다.

## ADDED Requirements

### Requirement: 스키마 마이그레이션은 번호 순서로 한 번씩만 적용된다
시스템은 `db/migrations`의 SQL 파일을 파일 이름 순서대로 적용하고, 적용한 파일을 기록해 다시 적용하지 않아야 한다(SHALL). 한 파일이 실패하면 그 파일의 변경은 모두 되돌려야 한다(SHALL).

#### Scenario: 빈 DB에 처음 적용
- **WHEN** 빈 DB에 마이그레이션을 실행하면
- **THEN** 0001_schema_v1, 0002_reference_codes 순으로 적용되고 둘 다 기록된다

#### Scenario: 두 번째 실행
- **WHEN** 이미 적용된 DB에 다시 실행하면
- **THEN** 적용되는 파일이 없다

### Requirement: 고정 코드표가 명세서와 같다
시스템은 요구사항 유형 7종(명세서 2-2)과 승인 기준 AR-01·02·03·06·07·08을 마이그레이션으로 갖고 있어야 한다(SHALL). AR-03의 기준값은 0.20이다 [제안].

#### Scenario: 유형 7종
- **WHEN** 마이그레이션을 마친 뒤 유형 표를 조회하면
- **THEN** TECH_PERF, RISK, STANDARD_CERT, COST, TEST, MAKER_QUAL, SITE_ENV 7개가 있고 COST의 전달 역할은 견적 담당이다

### Requirement: 규칙 사전 적재는 반복해도 결과가 같다
시스템은 규칙 사전 4종을 DB에 적재하고, 같은 파일로 여러 번 적재해도 같은 내용이 되어야 한다(SHALL, CR-11).

#### Scenario: 두 번 적재
- **WHEN** 같은 사전 파일로 두 번 적재하면
- **THEN** 두 번 모두 비교 방향 규칙 39줄, 표준 항목 26개가 된다

#### Scenario: 시간 조건이 붙은 비교 방향
- **WHEN** 비교 방향 사전의 TS-115-GIS 16번 "≥ (+시간)" 줄을 적재하면
- **THEN** 방향은 GE, 시간 조건 규칙 적용은 켜짐으로 저장된다

#### Scenario: 회사 고정값
- **WHEN** 연결표의 "(회사 고정값) LS ELECTRIC" 줄을 적재하면
- **THEN** 회사 고정값 manufacturer = "LS ELECTRIC"이 생기고 manufacturer 항목은 그 고정값에 연결된다

### Requirement: 코드로 바꿀 수 없는 사전 값은 적재를 멈춘다
시스템은 비교 방향이나 위험 표현 종류가 정해진 코드표에 없으면 추측하지 않고 어느 줄인지 알리며 적재를 멈춰야 한다(SHALL, CR-04).

#### Scenario: 모르는 비교 방향
- **WHEN** 비교 방향이 "약간 큼"인 줄이 있으면
- **THEN** 그 줄의 위치와 함께 오류를 내고 아무것도 적재하지 않는다

### Requirement: 제품표 적재
시스템은 제품표 파일들을 순서대로 적재하고 같은 제품 코드는 뒤 파일의 값으로 덮어써야 한다(SHALL). 손실값 파일이 있으면 같은 코드의 손실 칸을 채우고 팀 가정 여부를 함께 저장해야 한다(SHALL, CR-06).

#### Scenario: 뒤 파일이 이긴다
- **WHEN** 입력용 제품표와 TRF v2 제품표에 모두 TRF-HV가 있으면
- **THEN** TRF-HV는 TRF v2의 제품 이름으로 저장된다

#### Scenario: 손실값과 팀 가정
- **WHEN** 손실값 파일에 TRF-HV 무부하 60, 부하 300, 보조 8 kW가 팀 가정(Y)으로 있으면
- **THEN** TRF-HV의 손실 칸이 60 / 300 / 8로 채워지고 손실 팀 가정이 켜진다

#### Scenario: 제품표에 없는 손실값
- **WHEN** 손실값 파일에 제품표에 없는 코드가 있으면
- **THEN** 그 줄은 넣지 않고 건너뛴 목록에 남긴다

#### Scenario: 설계 사례 카드
- **WHEN** 설명이 "[설계 사례 카드"로 시작하는 GIS-145-P7을 적재하면
- **THEN** 설계 사례 카드로 표시되어 기본 비교 제품에서 빠질 수 있다
