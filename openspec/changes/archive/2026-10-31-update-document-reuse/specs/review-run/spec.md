## MODIFIED Requirements

### Requirement: 긴 문서는 절 단위로 처리
시스템은 문서를 통째로 AI에 넣지 않고 절 단위로 처리하며, 처리한 절의 결과를 저장해 재사용해야 한다(SHALL, NFR-05). 저장된 결과는 처리 판과 파일 내용이 모두 같을 때만 다시 써야 하며, 파일 이름이나 파일 번호가 같아도 내용이 다르면 새로 처리해야 한다(SHALL, CR-11).

#### Scenario: 가장 긴 문서
- **WHEN** 파일 2를 처리하면
- **THEN** 처리가 끝나고 AI 호출 입력은 모두 절 단위이다

#### Scenario: 이름이 같고 내용이 다른 파일
- **WHEN** 파일 목록의 같은 이름으로 내용이 다른 두 파일을 차례로 검토하고, 두 번째 파일로 한 번 더 검토하면
- **THEN** 두 파일은 같은 파일 번호이지만 두 번째 파일은 새로 처리되고, 세 번째 검토는 두 번째 처리 결과를 다시 쓴다
