# 검토 도우미 (읽기 전용 에이전트)

## 왜

- 실제 입찰 양식 한 건이 요구사항 4,515줄이라 표 거르기만으로 필요한 조항을 찾기 어렵다.
- 10-29 강사님 피드백 "의심 부분 먼저", "근거 보기가 포인트". 효율 개선 제안 4번.
- 11-01 minjeong "효율 개선의 나머지와 사전 추가 제안까지".

## 무엇

- 검토 상세 머리글의 "검토 도우미"에서 엔지니어가 자연어로 묻는다.
- AI는 읽기 도구 세 가지만 쓴다: 요구사항 글자 찾기(유형 거름), 판정 찾기(판정 값·글자), 요구사항 한 줄 보기. 최대 3번 찾고 답 문장을 쓴다.
- 코드가 답을 검증한다. 문장마다 근거 번호가 이번 질문에서 도구가 돌려준 줄이어야 하고, 문장의 숫자는 근거 원문에 있어야 한다. 어긋난 문장은 뺀다.
- 답 문장마다 근거 줄(원문·원문 위치), 찾은 경로, 뺀 문장 수를 보인다.
- AI 키가 없거나 AI가 답하지 못하면 질문 글자로 찾은 요구사항 줄만 보인다.

## 하지 않음

- 값 바꾸기·판정·확정하는 도구: 주지 않는다(CR-01·08).
- 질문·답 저장, 대화 이어가기: 질문마다 따로 답한다.
- 여러 검토를 넘나드는 질문: 지금 검토 하나만.

관련: 명세서 FR-17, 기획서 4-1·4-2·부록 B.
