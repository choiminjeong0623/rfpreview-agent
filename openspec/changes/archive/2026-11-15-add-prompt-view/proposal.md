# Proposal

## Why

AI 역할 8개의 프롬프트 판(`PROMPTS`)과 판별 평가 점수는 코드·실행 기록·평가 기록에 흩어져 있어, 지금 어떤 판을 쓰는지, 언제 판을 올렸는지, 그 판이 평가에서 몇 점이었는지를 화면에서 볼 수 없다. 프롬프트 평가 기록 API(`GET /api/prompt-evals`)는 있지만 화면이 없다. 현업 에이전트 관리 도구에는 보통 "프롬프트 관리"(판·배포 기록)가 관측·평가 화면과 함께 있다. 사용자가 시스템 관리 메뉴에 프롬프트 관리 화면을 두고, 편집·배포는 Langfuse 연동을 다음 단계로 설계해 두자고 했다(11-15).

관련: FR-18·NFR-13(add-prompt-eval), FR-21(add-ai-call-trace), SCR-25 실행 기록.

## What Changes

- 시스템 관리 메뉴에 "프롬프트 관리"(SCR-26, `#/prompts`)를 더한다. 보기만 한다.
- 역할마다 지금 판, 판 기록(처음·마지막으로 쓴 때, 검토 실행 수, AI 호출 수), 판별 가장 최근 평가의 주 지표(반복 최솟값)를 보인다.
- 조회 API `GET /api/prompts` 하나. 새 표·마이그레이션 없음(실행 기록·AI 호출 기록·평가 기록에서 모음).
- 프롬프트 글은 지금처럼 코드에서만 고친다. 편집·배포를 Langfuse로 넘기는 설계는 ADR-010에 적는다.

## Non-Goals

- 화면에서 프롬프트 글을 고치거나 판을 배포·되돌리기.
- Langfuse 연동 구현.
