# Proposal

## Why

실제 입찰 양식 "Bidding Forms"를 처음부터 끝까지 돌렸더니(2026-10-29, 키 사용) 확인 필요 비율이 99 %였고, 승인 기준 AR-03이 언제나 걸렸다.
원인은 데이터시트의 보증값 빈칸 1,537칸이다. 입찰자가 원래 써 넣어야 하는 칸인데, 제품표와 연결된 항목은 14개뿐이다. 나머지는 지어내지 않는다는 규칙(CR-04)에 따라 빈칸 "확인 필요"(이유 NOT_MAPPED)로 남고, 이것이 모두 확인 필요 비율에 들어간다.
그래서 정말 의심스러운 줄이 "원래 써야 하는 칸"에 묻히고, AR-03은 아무것도 걸러 내지 못한다. 강사님 피드백 "의심 부분 먼저, 결재자는 중요한 것만"과도 반대 방향이다.
팀 회의 문서의 안 1(Claude 추천)을 minjeong이 2026-11-01에 승인했다.

관련: 명세서 AR-03(11-01 고침), FR-08(보증값), CR-04, `review-approval` "멈춤 지점", `review-workspace` "검토 상세 요약 칸과 탭".

## What Changes

- 확인 필요 비율(AR-03)에서 제품표에 연결되지 않은 보증값 빈칸(NOT_MAPPED)을 분자·분모 모두에서 뺀다.
- 그 칸 수를 "직접 작성할 칸"으로 따로 센다. 승인 화면 응답의 확인 필요 비율에 칸 하나를 더한다.
- 검토 상세 요약 칸: 확인 필요 비율 아래에 "직접 작성할 칸 n개 뺌", 보증값 작성 칸 아래에 "직접 작성할 칸 n". 결재 상신 창·결재 대기 화면의 AR-03 줄에도 뺀 칸 수를 적는다.
- 제품을 못 고른 칸, 연결은 됐는데 제품표 값이 없는 칸, 판정이 "확인 필요"인 줄은 지금처럼 센다.

## Non-Goals

- 판정·보증값 후보 결과 바꾸기. 바뀌는 것은 AR-03 계산과 화면 표시뿐이다.
- 직접 작성할 칸이 남아 있으면 상신 막기. 엔지니어가 데이터시트 화면에서 채우는 일이고, 상신을 막으면 결재 흐름이 멈춘다 [제안].
- 제품표 연결 항목 늘리기(BIL, 정격 가스압 등). 제품표 자료가 없다.
- 판정 탭 새 거름. "작성 필요" 판정 칩이 이미 있다.
