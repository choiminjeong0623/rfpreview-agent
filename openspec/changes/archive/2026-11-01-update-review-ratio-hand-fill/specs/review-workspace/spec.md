## MODIFIED Requirements

### Requirement: 검토 상세 요약 칸과 탭
화면은 처리를 마친 검토 상세의 머리글 아래에 요약 칸 5개(일탈 후보, 질의 후보, 확인 필요 비율과 기준, 보증값 작성, 손실 환산 참고값)와 탭 9개(판정, 문서 읽기 점검, 위험 조건, 손실 환산(참고), 입찰 영향, 상업 조건, 지난 RFP 비교, 제출본, 이력)를 목업 순서대로 보여야 한다(SHALL). 탭은 모두 실제 데이터를 보이고 예시 띠를 붙이지 않는다. 직접 작성할 칸이 있으면 확인 필요 비율 칸에 그 칸을 뺐다는 것과 개수를, 보증값 작성 칸에 직접 작성할 칸 수를 보인다(SHALL).

#### Scenario: 요약 칸
- **WHEN** 일탈 후보가 있는 검토 상세를 열면
- **THEN** 요약 칸에 일탈 후보 수, 질의 후보 수, 확인 필요 비율과 "기준 20 %", 보증값 작성 수, 손실 환산 참고값이 보인다

#### Scenario: 직접 작성할 칸 표시
- **WHEN** 직접 작성할 칸이 3개인 검토 상세를 열면
- **THEN** 확인 필요 비율 칸에 "직접 작성할 칸 3개 뺌", 보증값 작성 칸에 "직접 작성할 칸 3"이 보인다

#### Scenario: 탭으로 내용 바꾸기
- **WHEN** 검토 상세에서 "이력" 탭을 누르면
- **THEN** 이력 표가 보이고 탭 줄에서 이력 탭이 선택된 것으로 보인다

#### Scenario: 예시 탭
- **WHEN** 마지막 예시 탭이던 "지난 RFP 비교" 탭을 누르면
- **THEN** 예시 띠가 보이지 않는다
