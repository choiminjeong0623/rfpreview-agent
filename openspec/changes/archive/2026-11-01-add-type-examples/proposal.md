# 사람이 고친 유형을 AI 유형 질문의 예시로 (C조 C3, RAG)

## 왜

- AI 유형 붙이기(규칙에 안 걸린 줄)는 정답지 100줄에서 57~66 % 정도다. 같은 회사의 엔지니어가 한 번 고친 판단을 다음 문서에서 AI가 참고하면 좋아진다.
- 지금은 사람이 유형을 고칠 방법이 없다(`decided_by` HUMAN 칸만 있음). 그래서 사람 확정 예시가 쌓이지 않는다.
- AI 기술 활용성 평가의 "RAG"와 "사람 검토 축적"에 닿는다. 정답지 줄을 예시로 쓰면 K13 채점이 오염되므로 뺀다.

## 무엇

- **유형 고치기**: 엔지니어·승인자가 판정 상세 창과 협조 요청 상세 창에서 요구사항의 주 유형을 고른다(사유 선택). 주 유형 태그를 사람(HUMAN)으로 바꾸고 이력에 남기며, 담당 전달 목록을 다시 만든다(유형이 바뀌면 담당 부서가 바뀜).
- **확정 예시 넣기**: 규칙에 안 걸린 줄을 AI에 물을 때, 다른 문서의 사람 유형 줄 가운데 문장 벡터 코사인 0.80 이상인 것을 줄마다 최대 2개 "사람이 고른 예"로 줄 끝에 붙인다. 정답지(유형·요구사항)에 든 문장, 같은 문서의 줄은 예시가 되지 않는다.
- 쓴 예시 수를 실행의 처리 상태에 남겨 실행 기록에서 "유형 예시 n줄"로 본다.
- 벡터는 B3 저장소(text_vector)를 다시 쓴다. 벡터를 못 받으면 예시 없이 묻는다(분석 계속).

## 하지 않음

- 예시로 유형을 바로 정하기(유형은 AI 답과 규칙, CR-01).
- 보조 유형 고치기, 요구사항 목록 전체 화면.
- K13 전후 채점(로컬 정답지·사람 고침이 쌓인 뒤).

관련: 명세서 FR-04 ④ "사람 유형 고치기와 확정 예시 [C3]".
