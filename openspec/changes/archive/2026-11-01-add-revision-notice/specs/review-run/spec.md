## ADDED Requirements

### Requirement: 문서 추가 개정 결과
시스템은 검토에 문서를 더해 다시 판정하면 개정 결과(개정 번호, 더한 파일 이름, 다시 판정한 시각, 판정 값이 바뀐 줄 수, 새로 생긴 줄 수, 사라진 줄 수)를 남기고 실행 요약·실행 목록에 내야 한다(SHALL). 같은 줄은 요구값·비교 제품·비교 규칙이 같은 판정이다. 판정 줄마다 마지막 개정에서 바뀜·추가 여부를 내고, 바뀌거나 추가된 줄만 거를 수 있어야 한다(SHALL). 문서를 더하지 않은 검토와 비교 제품을 바꿔 다시 판정한 결과는 개정이 아니다. [제안] 값이 바뀐 같은 항목은 사라짐 1·추가 1로 센다.

#### Scenario: 개정 결과 줄 수
- **WHEN** 담당자 확인 단계 검토에 addendum_gis.docx를 더해 다시 분석이 끝나면
- **THEN** 실행 요약과 실행 목록에 개정 1, 파일 이름 addendum_gis.docx, 새로 생긴 줄 수가 보이고, 새로 생긴 줄 수는 늘어난 판정 줄 수와 사라진 줄 수의 합과 같다

#### Scenario: 바뀐 줄만 보기
- **WHEN** 처음 분석과 판정 값이 다른 같은 줄이 하나 생긴 상태로 바뀐 줄만 거르면
- **THEN** 그 줄은 "바뀜"이고 새 줄은 "추가"이며, 거른 목록에는 바뀜·추가 줄만 있다

#### Scenario: 문서를 더하지 않은 검토
- **WHEN** 문서를 더하지 않고 분석을 마친 검토를 보면
- **THEN** 개정 결과가 없고 판정 줄에 개정 표시가 없으며 바뀐 줄만 거르면 0줄이다
