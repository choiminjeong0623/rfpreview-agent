# Design

## 결정

- **말풍선은 원문만.** 고치는 단추를 말풍선에 두면 마우스를 옮기는 순간 사라져 누를 수 없고 키보드·터치로 쓸 수 없다. 원문 위치·문장만 보이고 고치기는 판정 상세 화면.
- **늦게 띄우기.** 0.4초 머문 뒤 띄우고 마우스를 떼면 바로 지운다. 표를 훑을 때 깜빡이지 않게.
- **원문 문장.** 줄마다 요구사항을 미리 받지 않고, 말풍선을 띄울 때 그 요구사항만 받아(`GET /requirements/{id}`) 판정 id로 기억해 둔다. 표 줄이면 표 이름·항목·요구값 한 줄.
- **자리.** 줄의 화면 위치 기준 아래(공간이 없으면 위), 폭 최대 520px, `position: fixed`.
- **키보드.** 줄에 `tabIndex=0`, 초점이면 말풍선, Enter면 판정 상세.
- **보증값 입력 이동.** 판정 상세 화면 보증값 칸에 패널과 같은 입력(값·근거·[입력]), 같은 API(`warranty_candidate EDIT`).

## 대안

- 패널을 처음엔 닫고 아이콘으로 열기: 같은 기능이 두 곳에 남아 버림.
- 마우스 올리면 패널 전체를 말풍선으로: 내용이 길어 표를 가리고 단추를 누를 수 없어 버림.
