## ADDED Requirements

### Requirement: 판정 정답지 고르기와 구간 표시
화면은 정답지·채점 화면 정답지 탭에서 유형·요구사항 정답지와 따로 판정 정답지 목록(이름, 대상 문서, 줄 수, 만든 이)을 보이고 하나를 골라(처음엔 고르지 않음) 채점하게 해야 한다(SHALL). 판정 정답지로 채점하면 채점 결과에 K5-정답지·K6-정답지가 보인다. 채점 결과의 비율 지표에는 값 아래 "95 % 구간 a–b %"를 보인다(구간이 없으면 보이지 않음). [제안 11-23]

#### Scenario: 판정 정답지로 채점
- **WHEN** Claude 초안 판정 정답지가 있는 상태에서 정답지 탭에서 그 정답지를 고르고 "지금 채점하기"를 누르면
- **THEN** 정답지에 "AI 초안 · 검수 전"이 보이고, 채점 결과 탭에 K5-정답지 값과 "95 % 구간"이 보인다
