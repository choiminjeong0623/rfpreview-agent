## MODIFIED Requirements

### Requirement: 비용 상한
시스템은 평가를 시작하기 전에 문항 글자 수와 반복 횟수로 토큰과 비용(팀 가정 단가)을 어림하고, 상한(기본 500원)을 넘으면 확인 옵션 없이는 시작하지 않아야 한다(SHALL). 평가 중에도 실제로 쓴 토큰으로 비용을 재어, 멈출 값을 넘으면 아직 묻지 않은 문항과 남은 반복은 묻지 않고 멈춰야 한다(SHALL). 멈출 값은 확인 옵션 없이 시작했으면 상한, 확인 옵션으로 시작했으면 상한과 어림 비용 두 배 가운데 큰 값이다. 멈춘 평가는 실패로 남기고 이유(멈춘 값·쓴 비용·묻지 않은 문항 수)를 적으며 기준선 비교·기준선·운영으로 올리기에 쓰지 않는다. 단가를 모르는 모델은 실행 중 상한을 적용하지 않는다. [제안]

#### Scenario: 상한을 넘는 평가
- **WHEN** 어림 비용이 상한을 넘는 평가를 확인 옵션 없이 시작하면
- **THEN** AI를 부르지 않고 어림 비용과 상한을 알린다

#### Scenario: 평가 중 상한을 넘음
- **WHEN** 어림 비용은 상한 아래였지만 실제 답이 길어 묻는 도중 쓴 비용이 상한을 넘으면
- **THEN** 남은 문항은 묻지 않고 평가는 실패로 남으며 이유에 "비용 상한"과 묻지 않은 문항 수가 있고 기준선과 비교하지 않는다
