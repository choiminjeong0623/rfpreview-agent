## ADDED Requirements

### Requirement: 역할별 AI 호출 지표
시스템은 검토의 AI 호출 기록을 AI 역할마다 묶어 요청 수, 시도 수(재시도 포함), 응답 시간 중앙값(p50)과 95번째 값(p95), 실패율(성공이 아닌 시도 비율), 코드 검사로 버린 비율(성공한 시도 중), 재시도 뒤 성공 수(첫 시도가 실패한 요청 중 나중 시도가 성공한 수)를 계산해 실행 기록 상세에 보여야 한다(SHALL). 백분위는 가까운 순위 방식으로 코드가 계산하고, 같은 기록이면 같은 값이다. 호출 기록이 없으면 표를 보이지 않는다. [제안]

#### Scenario: 역할별 지표
- **WHEN** 한 검토의 유형 역할 호출이 첫 시도 시간 초과 뒤 재시도 성공 1건과 바로 성공 3건(100·200·300·400 ms)이고 위험 설명 역할 호출 1건이 성공했지만 코드 검사로 버려지면
- **THEN** 유형 역할은 요청 4·시도 5·실패율 20 %·재시도 뒤 성공 1, 위험 설명 역할은 버린 비율 100 %로 보인다

#### Scenario: 호출 기록 없음
- **WHEN** AI를 쓰지 않은 검토의 실행 기록 상세를 열면
- **THEN** 역할별 표 없이 "호출 기록 없음"만 보인다
