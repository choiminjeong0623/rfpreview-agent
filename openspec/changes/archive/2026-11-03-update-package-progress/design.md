# Design

## 결정

- **상자 안 진행 표시.** 판정 탭 내려받기(ExportOverlay)는 화면 전체를 덮지만, 인계 패키지는 사업 상세 창 안에서도 쓰므로 그 상자 안에 막대를 둔다. 막대 모양은 공통 `.anbar`(머리글·검토 목록 진행과 같음).
- **어림 진행.** 0.12초마다 조금씩 올려 90 %에서 멈춘다(ExportOverlay와 같은 방식). 단계 문장은 퍼센트 구간(0·30·60·80)으로 고른다. 실제 진행이 아니므로 "어림한 진행" 안내를 붙인다.
- **받은 뒤.** 100 %를 잠깐 보이고(0.35초) 막대를 지운 뒤 파일을 저장하고 동작 결과 알림.

## 대안

- 서버가 단계마다 진행을 알려 주기(SSE·작업 번호 조회): 백엔드 변경이 커서 이번에는 버림.
