# Proposal

## Why

제출본 탭과 사업 상세 인계 패키지 창의 [인계 패키지 내려받기]는 누르면 단추 글자만 "만드는 중…"으로 바뀌고 회색으로 잠긴다. 판정이 수천 줄인 검토(예: 판정 4,523줄, 첨부 96개)는 일탈 목록·질의서 Word, TBE·데이터시트 엑셀을 모두 만들어 묶느라 수 초~수십 초가 걸리는데, 그동안 무엇을 하는지, 멈췄는지 알 수 없다.

관련: SCR-08-8 제출본, SCR-05 사업 상세, add-submission-package, update-home-projects.

## What Changes

- [인계 패키지 내려받기]를 누르면 인계 패키지 상자 안에 진행 막대·퍼센트·지금 하는 일을 보인다: "일탈 목록·질의서 Word 만드는 중" → "TBE 준수표 엑셀 만드는 중" → "데이터시트 엑셀 만드는 중" → "zip으로 묶는 중".
- 서버가 단계별 진행을 알려 주지 않으므로 막대는 걸린 시간으로 어림해 90 %에서 기다리고, 받으면 100 %가 된 뒤 내려받는다. "어림한 진행입니다. 다 만들면 바로 내려받습니다." 안내를 함께 보인다.
- 끝나면 지금처럼 "…zip 를 내려받았습니다."(동작 결과 알림), 실패하면 오류 문장.

## Non-Goals

- 서버 진행률 API는 만들지 않는다(백엔드 변경 없음).
- [영업에 넘기기]는 지금처럼 엔지니어만 보인다.
