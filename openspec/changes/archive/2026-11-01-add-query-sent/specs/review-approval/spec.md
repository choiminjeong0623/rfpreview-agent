## ADDED Requirements

### Requirement: 질의 보냄 표시
시스템은 담당자 확인 단계에서 검토 엔지니어가 질의 후보 판정(반려하지 않은 현재 판정)에 "질의 보냄"을 표시하고 되돌릴 수 있게 하고, 표시한 시각·사람을 판정 응답에 내며 이력에 남겨야 한다(SHALL). 표시는 판정 결과·확인 상태를 바꾸지 않는다. 질의 후보가 아니거나 엔지니어가 아니면 거절한다. 문서를 더해 다시 분석해도 같은 줄이 질의 후보면 표시를 옮긴다. 고객 회신 내용은 저장하지 않는다.

#### Scenario: 질의 보냄과 되돌리기
- **WHEN** 엔지니어가 질의 후보 판정에 질의 보냄을 표시했다가 되돌리면
- **THEN** 표시하면 시각과 표시한 사람이 남고 판정 결과·목록은 그대로이며, 되돌리면 둘 다 비고, 이력에 질의 보냄·되돌리기가 차례로 남는다

#### Scenario: 질의 후보·엔지니어만
- **WHEN** 질의 후보가 아닌 판정에 표시하거나 승인자가 질의 후보 판정에 표시하면
- **THEN** 앞은 409, 뒤는 403으로 거절한다

#### Scenario: 문서 추가 뒤에도 남음
- **WHEN** 질의 보냄을 표시한 검토에 문서를 더해 다시 분석하면
- **THEN** 같은 줄의 새 판정에 같은 질의 보냄 시각이 남는다
