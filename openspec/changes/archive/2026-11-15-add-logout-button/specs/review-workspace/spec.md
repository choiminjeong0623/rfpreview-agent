## MODIFIED Requirements

### Requirement: 머리글 사용자 고르기
로그인이 없으므로 화면은 머리글 사용자 칩에서 사용자를 바꾸게 하고, 고른 사용자의 이름과 역할을 머리글에 보여 주며, 모든 화면의 권한을 그 역할로 정해야 한다(SHALL). 고른 사용자는 브라우저에 기억해야 한다(SHALL). 사용자 칩 겹창에는 로그아웃을 두어, 누르면 기억한 사용자를 지우고 예시 로그인 화면으로 가야 한다(SHALL).

#### Scenario: 사용자 바꾸기
- **WHEN** 엔지니어로 보던 사용자가 사용자 칩에서 기본 승인자를 고르면
- **THEN** 머리글에 기본 승인자와 승인자 역할이 보이고 새로 고쳐도 유지된다

#### Scenario: 로그아웃
- **WHEN** 기본 승인자를 고른 사용자가 사용자 칩에서 로그아웃을 누르면
- **THEN** 로그인 화면으로 가고, 로그인해 홈으로 돌아오면 머리글에 기본 승인자가 아닌 첫 사용자가 보인다
