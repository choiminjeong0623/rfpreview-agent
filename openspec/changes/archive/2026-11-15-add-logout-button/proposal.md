# Proposal

## Why

머리글 사용자 칩에는 사용자 바꾸기만 있고 로그아웃이 없다. 시연에서 다른 사람이 쓰기 전에 고른 사용자를 지우고 첫 화면(예시 로그인 화면)으로 돌아갈 길이 필요하다. 사용자가 로그아웃 단추를 넣어 달라고 했다(11-15).

관련: SCR-00 앱 틀(머리글 사용자), SCR-01 로그인(예시).

## What Changes

- 사용자 바꾸기 겹창 머리에 [로그아웃]을 둔다. 누르면 브라우저에 기억한 사용자를 지우고 예시 로그인 화면(`#/login`)으로 간다.
- 로그인 화면에서 로그인하면 지금처럼 홈으로 가고, 사용자는 첫 사용자로 보인다.

## Non-Goals

- 실제 인증·세션·서버 로그아웃 API는 만들지 않는다(로그인은 범위 밖).
