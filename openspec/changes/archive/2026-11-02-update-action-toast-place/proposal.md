# Proposal

## Why

사용자가 누른 동작의 결과 알림(위험으로 확정, 판정 확정, 문장 저장, 메일 보냄 등)이 화면마다 다른 곳에 뜬다. 공통 알림은 오른쪽 위에 쌓이고, 협조 요청·판정 탭·데이터시트·채점·분석 실패 화면은 각자 만든 알림을 아래 가운데에 띄운다. 오른쪽 위는 단추를 누른 자리(화면 아래쪽 줄)에서 멀어 시선을 옮겨야 보이고, 머리글·비교 제품 칸을 가린다.

관련: SCR-00 7장, `review-workspace` "알림 쌓기", add-ui-foundation, update-risk-action-toasts.

## What Changes

- 알림을 두 가지로 나눈다.
  - **동작 결과**(사용자가 방금 누른 것의 결과): 화면 아래 가운데에 하나만, 4초 뒤 사라짐. 새 결과가 오면 바꿔 끼운다. 검토 상세 아래 행동 줄이 있으면 그 위에 띄운다.
  - **시스템 알림·오류**(분석 끝남·멈춤, 저장 실패 등): 지금처럼 오른쪽 위에 쌓는다.
- 공통 부품에 동작 결과 알림을 더하고, 화면마다 따로 만든 아래 알림(협조 요청, 판정 탭, 데이터시트, 채점, 분석 실패)을 이 부품으로 바꾼다. 그 화면들이 같은 알림에 띄우던 오류 문장은 오류 알림(오른쪽 위)으로 옮긴다.

## Non-Goals

- 알림 문구는 바꾸지 않는다.
- 백엔드·API 변경 없음.
