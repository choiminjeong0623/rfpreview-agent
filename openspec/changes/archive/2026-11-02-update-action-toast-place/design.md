# Design

## 결정

- **부품 API.** `useToast()`에 `done(text, link?)`를 더한다. `show(text, kind, link)`는 그대로(오른쪽 위 쌓기). 동작 결과는 `done`, 시스템·오류는 `show`.
- **하나만 보임.** 여러 줄을 빠르게 처리할 때 쌓이지 않게 마지막 결과만 보인다. 타이머는 새 결과마다 다시 건다.
- **모양.** 목업 아래 알림(`.toast`·`.htoast`·`.stt`)과 같은 어두운 바탕·흰 글자·초록 아이콘, 토큰 색만. 링크는 밑줄 흰 글자.
- **행동 줄 피하기.** 검토 상세 아래 행동 줄(`.ftb`, sticky)이 있으면 `body:has(.ftb)`로 그 높이만큼 올린다.
- **오류는 오른쪽 위.** 오류는 닫을 때까지 남아야 해서 사라지는 아래 알림에 두지 않는다.

## 대안

- 모든 알림을 아래 가운데로: 분석 끝남처럼 여러 개가 쌓이는 시스템 알림이 서로 가려져 버림.
- 누른 단추 옆에 말풍선: 줄이 다시 그려지면 자리가 사라져 버림.
