# Proposal

## Why

판정·보증값은 묶음 A·B 문서만 만든다(CR-09). 그런데 등록 화면에서 묶음 C 문서만 올려도 검토가 시작돼,
약 10분 동안 AI로 추출·유형·위험 조건을 돌린 뒤에야 판정 0건인 검토가 나온다. 2026-10-31 주말 검토에서
"10분 기다릴 필요 없이 등록할 때 바로 걸러야 하지 않나"는 지적이 나왔고, 통합 개발 목록 2장 1번에서
"완전히 막기"(경고 후 그래도 시작은 두지 않음)로 정했다.

관련: FR-01 ⑤, CR-09, `document-intake` "분석 전 분류 추천"·"사람이 정한 문서 분류", change `add-document-confirm`.

## What Changes

- 검토 시작 요청에서 문서마다 실제로 쓸 묶음(사람이 정한 묶음, 없으면 규칙 결과)과 읽을 수 있는지를 코드로 보고, 판정 대상 문서가 하나도 없으면 검토를 만들지 않고 거절한다.
- 등록 화면 1단계는 분류 추천이 모두 왔는데 판정 대상이 하나도 없으면 안내를 띄우고 "다음"을 막는다.

## Non-Goals

- 묶음 C 문서로 위험 조건만 보는 검토(필요한 사례가 아직 없음). 필요해지면 "그래도 시작" 선택을 따로 만든다.
- 문서 목록(document_catalog)이나 추천 규칙 바꾸기.
