# Proposal

## Why

앱 틀(`update-app-shell`), 검토 정보(`add-review-info`), 결재 흐름(`update-approval-flow`)으로 머리글과 결재 화면은 목업 v4.57과 같아졌지만,
검토 상세의 본문은 아직 예전 탭 화면(요구사항·적합성 판정·보증값 등 10개 탭)이다. 목업은 검토 상세를 **요약 칸 5개 + 탭 9개**로 나누고,
판정 탭에서 "판정 칩으로 거르기 → 줄을 눌러 오른쪽에서 원문·근거 보기 → 확정하거나 사유와 함께 바꾸기"를 한 화면에서 한다.
엔지니어가 수백 줄을 확인하는 핵심 작업이라 목업과 같은 흐름이 시연(최종평가 "끊기지 않는 한 흐름")에서 직접 보인다.

갭 목록(2026-10-28) 3절, 로드맵 2단계 3번 "화면 연결". 관련: FR-07(판정), FR-08(보증값), FR-09(일탈·질의 목록), FR-10(확인·이력),
FR-12(검산), FR-13(손실 환산), FR-14(제안 포인트), FR-06(위험 조건), FR-11(내 할 일), CR-02(원문 위치), CR-08(후보).

## What Changes

- 검토 상세를 목업처럼 **요약 칸**(일탈 후보, 질의 후보, 확인 필요 비율, 작성 필요, 손실 환산 참고값)과 **탭 9개**(판정, 문서 읽기 점검, 위험 조건, 손실 환산(참고), 입찰 영향, 상업 조건, 지난 RFP 비교, 제출본, 이력)로 바꾼다. API가 없는 탭(상업 조건, 지난 RFP 비교, 제출본)은 예시 띠를 붙인 예시 화면이다.
- **판정 탭**: 판정 칩(전체·일탈 후보·질의 후보·확인 필요·작성 필요·준수, 건수), 확정 안 한 줄만, 검색(항목명·영문·원문 위치), 유형 거르기, 판정 순서(일탈 → 질의 → 확인 필요 → 작성 필요 → 준수), 페이지 나누기. 줄을 누르면 오른쪽 패널에 원문, 판정 근거, 판정 출처(시스템 제안·담당자 확정), 일탈·질의 목록 문장, 판정 바꾸기(사유 필수)를 보인다.
- 판정 목록 API에 거르기(유형, 검색어, 확정 안 한 것만)와 판정 순서 정렬을 더하고, 판정 칩 건수를 한 번에 주는 API를 더한다. 판정 줄에 주 유형 이름을 넣는다.
- 판정 탭 머리의 "일탈 목록 초안"·"질의서 초안" 창과 "결재 상신" 단추를 목업 자리로 옮긴다.
- 위험 조건, 손실 환산, 입찰 영향(제안 포인트·현장 이력·공학 검산), 이력 탭, 처리 상태·분석 실패 화면, 홈과 협조 요청(내 할 일)을 목업 레이아웃으로 바꾼다. 화면마다 화면 명세(`docs/screens/SCR-xx`)를 먼저 쓰고 이 change의 Scenario로 옮긴다.

## Non-Goals

- 판정 여러 줄 한꺼번에 확정(목업 "준수 45줄 모두 확정", "제안대로 확정"): 로드맵 7번 change에서 API와 함께 한다.
- 판정 상세의 번역, 질의 보냄 상태, 지난 검토 수정 기록(지난 수정) 표시: API 없음.
- TBE 준수표·데이터시트 내려받기(로드맵 5번), 제출본(판 번호·잠금).
- 문서 추가(실행 단위라 다시 실행), 상신 권장일.

## Capabilities

### New Capabilities
없음.

### Modified Capabilities
- `review-workspace`: 검토 상세 화면 구성(요약 칸·탭), 판정 탭(거르기·순서·상세 패널), 그 밖의 탭과 화면의 Requirement를 더한다.
- `review-run`: 판정 목록 거르기·정렬과 판정 칩 건수 API.

## Impact

- API: `GET /api/runs/{id}/judgments`에 `type_code`, `q`, `unconfirmed`, `order=priority` 추가(없으면 지금과 같음). `GET /api/runs/{id}/judgment-counts` 추가. 판정 줄에 `type_code`, `type_name` 칸 추가.
- 프런트: `views/` 검토 상세 탭 화면들, `components/`, `src/mockup/*.css`. 예전 탭 화면(Findings, Compliance, Outputs)은 쓰이지 않게 되면 지운다.
- DB 바뀌지 않음.
