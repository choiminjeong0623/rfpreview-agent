# Proposal

## Why

제품표 화면의 "엑셀 가져오기"·"내보내기" 단추는 목업 v4.57에 있지만 앱에서는 잠겨 있다.
엔지니어가 제품표를 견적·설계와 나누거나 오프라인에서 보려면 지금은 DB나 CSV를 직접 열어야 한다.
계획 문서(10-31) 3장 "제품표 엑셀 가져오기·내보내기". minjeong이 11-01 3장 진행을 지시했다.
가져오기는 판정 기준 전체를 바꾸는 일이라 이번에는 내보내기만 만든다(결정 카드 추천안).

관련: 명세서 8장 product_master, `reference-data` "제품표 조회", `review-workspace` "제품표 화면". CR-04·06·11.

## What Changes

- 새 API `GET /products/export?family=&q=&cards=`: 목록과 같은 거르기로 제품 칸 전체를 엑셀 한 장(xlsx)으로 낸다. 파일 이름 `제품표_<제품군|전체>.xlsx`, 머리 `X-Row-Count`.
- 엑셀: 제목 줄(거르기 조건·제품 수), 안내 줄, 칸 머리(한국어 이름과 단위), 제품 줄. 빈 칸은 빈 셀, 팀 가정 제품은 "팀 가정" 칸(제품 전체·비교값·손실값)과 옅은 파랑 줄. 내보낸 시각은 넣지 않는다.
- 제품표 화면 "내보내기" 단추를 연다. 누르면 지금 거르기대로 내려받고 "제품표_GIS.xlsx 를 내려받았습니다."를 보인다.

## Non-Goals

- 엑셀 가져오기(제품표 바꾸기). 단추는 그대로 잠근다. 지금처럼 CSV + `rfp-db seed-products --replace`.
- 단위 환산(CR-10), 제품 고치기.
