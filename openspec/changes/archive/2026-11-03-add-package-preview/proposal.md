# Proposal

## Why

목업 v4.96에는 영업에 넘기기 전에 인계 패키지 내용을 한눈에 보는 "영업 인계 패키지" 창(숫자 칸, 결재 줄, 표지·TBE 준수표·일탈·질의·견적 조건·영업 할 일 탭)이 있지만, 실제 시스템은 제출본 탭과 사업 상세 인계 패키지 창에서 zip 내려받기·영업에 넘기기 단추만 보인다. 영업에 무엇이 넘어가는지 파일을 열어 보기 전에는 알 수 없다.

관련: SCR-08-8 제출본, SCR-05 사업 상세, add-submission-package, update-home-projects, `_v4.96_결정.md`(데이터시트에서 여는 창은 만들지 않음, 패키지는 제출본 탭·사업 상세에서).

## What Changes

- 인계 패키지 상자(제출본 탭·사업 상세 창 공통)에 [미리 보기]를 더해 "영업 인계 패키지" 창을 연다.
  - 머리: 검토 번호·이름, 사업명·고객사, 제출 마감 D-day, "결재 승인" 상태, [인계 패키지 내려받기](지금 zip 그대로)
  - 숫자 칸 6개: 준수, 일탈, 질의, 확인 필요, 팀 가정, 견적 조건
  - 결재 줄: 결재자 · 승인 시각 · 설비 묶음 이름
  - 안내: "엔지니어가 확정하고 결재가 끝난 결과입니다. 금액은 비워 두었습니다. 영업·견적 담당이 채웁니다."
  - 탭 5개: 표지(설비 묶음마다 준수·일탈·질의·확인 필요 수와 확인 필요 줄 몇 개), TBE 준수표, 일탈·질의, 견적 조건, 영업 할 일(영업 담당 협조 요청). 탭 이름 옆에 건수
  - 아래: "zip 한 파일(일탈·질의 Word, TBE·데이터시트 엑셀)로 내려받습니다." · [닫기] · [인계 패키지 내려받기]
- 보기만 한다. 고치는 단추는 없다.

## Non-Goals

- 목업의 "시트 5개짜리 엑셀 한 파일" 내려받기는 만들지 않는다(백엔드 새 내려받기가 필요, zip 그대로).
- 데이터시트·판정 상세에서 이 창을 열지 않는다(`_v4.96_결정.md`).
- 백엔드·API 변경 없음.
