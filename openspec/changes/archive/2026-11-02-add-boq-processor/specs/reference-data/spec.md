## MODIFIED Requirements

### Requirement: 문서 종류 규칙 사전 적재
시스템은 문서 종류 규칙 사전(순서, 문서 종류, 파일 이름에서 찾는 표현, 첫 장에서 찾는 표현, 메모)을 다른 규칙 사전과 함께 DB에 적재해야 하며, 같은 파일로 여러 번 적재해도 같은 내용이 되어야 한다(SHALL, CR-11). 문서 종류가 코드표(7종, 물량표 포함)에 없거나 표현이 정규식으로 읽히지 않으면 그 줄을 알리고 적재를 멈춰야 한다(SHALL, CR-04). [물량표: 제안 11-02]

#### Scenario: 문서 종류 규칙 두 번 적재
- **WHEN** 같은 사전 파일로 두 번 적재하면
- **THEN** 두 번 모두 문서 종류 규칙 6줄이 순서대로 있다

#### Scenario: 모르는 문서 종류
- **WHEN** 문서 종류가 "가격표"인 줄이 있으면
- **THEN** 그 줄의 위치와 함께 오류를 내고 아무것도 적재하지 않는다
