# 단계부터 다시 처리 (C조 C2 이어서, 되돌리기)

## 왜

- 규칙 사전을 고치거나(판정 규칙·위험 표현), 제품표가 바뀐 뒤에 이미 분석한 검토를 다시 보고 싶을 때가 있다. 지금은 검토를 새로 등록하거나 문서를 더해야(처음부터) 한다.
- C2로 흐름이 단계마다 저장되므로 "그 단계부터 다시"를 흐름 안의 사람 동작으로 둘 수 있다.
- 다시 돌릴 때 사람이 확정·수정한 판정을 잃으면 안 된다(CR-08, FR-10). 판정·위험 조건 단계는 이미 같은 줄의 사람 확인을 늘 이어받는다(add-document-addendum).

## 무엇

- **단계부터 다시 처리**: 담당자 확인 단계(상신 전)에서 엔지니어가 처리 단계 하나(문서 읽기·같은 문서 찾기·위험 조건 찾기·제품 비교 판정·뜻으로 찾기·공학 규칙 검산·보증값 후보·손실 환산·일탈·질의 목록·제안 포인트·담당자 전달)와 사유를 고르면, 흐름이 그 단계부터 다시 돌고 담당자 확인에서 다시 멈춘다.
- 사람 작업은 지우지 않는다: 판정 단계가 같은 줄의 확정·수정·반려를, 위험 조건 단계가 같은 열쇠의 확인을 이어받는다(문서 추가와 같은 규칙).
- 상신·승인 대기·반려됨·처리 중·실패에서는 거절(409). 흐름 기록이 없는 예전 검토도 거절. 엔지니어만(403).
- 이력에 "단계부터 다시 처리(단계, 사유)", 흐름 기록에 사람 동작 "되돌려 다시 처리".
- 화면: 검토 상세 "이력" 탭 위에 단계 고르기·사유·[다시 처리] (엔지니어, 담당자 확인 단계일 때만).

## 하지 않음

- 저장된 예전 상태로 잘라 되돌리기(time travel로 기록 지우기). 흐름은 앞으로만 이어 가고 기록은 남는다.
- 상신 뒤 단계로 되돌리기(상신 취소가 있다).
- 다시 처리 전 결과를 따로 보관해 비교하기(문서 추가의 개정 안내는 쓰지 않음).
