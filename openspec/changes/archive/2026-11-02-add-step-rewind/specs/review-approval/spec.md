## ADDED Requirements

### Requirement: 단계부터 다시 처리
시스템은 담당자 확인 단계의 검토에 엔지니어가 처리 단계 하나와 사유를 주면 검토를 처리 중으로 바꾸고 흐름을 그 단계부터 다시 돌려 담당자 확인에서 다시 멈춰야 한다(SHALL). 같은 줄의 사람 확정·수정·반려와 위험 조건 확인은 이어받는다(CR-08). 담당자 확인이 아닌 단계, 흐름 기록이 없는 검토, 처리 단계가 아닌 이름, 빈 사유는 거절하고, 엔지니어가 아니면 거절한다. 사유와 단계는 이력에 남긴다. [제안 11-02, C2]

#### Scenario: 판정부터 다시 처리
- **WHEN** 엔지니어가 판정 한 줄을 수정한 검토에 "제품 비교 판정"부터 다시 처리를 사유와 함께 요청하면
- **THEN** 처리가 끝나 담당자 확인에서 다시 멈추고, 수정한 줄의 판정 값과 수정 표시가 그대로이며, 이력에 단계와 사유가 남고 흐름 기록의 담당자 확인 단계에 "되돌려 다시 처리"가 남는다

#### Scenario: 상신한 검토는 못 되돌림
- **WHEN** 결재를 상신한 검토에 단계부터 다시 처리를 요청하면
- **THEN** 409로 거절되고 검토 단계와 흐름은 그대로다

#### Scenario: 승인자는 못 되돌림
- **WHEN** 승인자가 담당자 확인 단계의 검토에 단계부터 다시 처리를 요청하면
- **THEN** 403으로 거절된다
