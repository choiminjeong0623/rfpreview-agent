# 화면 명세: SCR-08-11 일탈 목록·질의서 초안

- 연결 요구사항: FR-09·10, `review-workspace` 목록 초안 내려받기와 문장 고치기, `bid-outputs` 목록 초안 Word 파일
- 기준 목업: `Spec2Win_목업_v4.57.html#Detail` 판정 머리 "일탈 목록 초안"·"질의서 초안"(exDev·exQ: 로딩 화면 → .docx → 알림), 패널·판정 상세 창의 문장 칸
- 구현 방식: 실제 (`update-review-screens` 묶음 6)
- 사용 API: `GET /runs/{id}/outputs/export?list_kind=DEVIATION|QUERY`(Word), `GET /runs/{id}/outputs`, `POST /runs/{id}/actions` output_item CONFIRM·EDIT·REJECT
- 예정 API: 없음

## 화면 구성

| 영역 | 보이는 항목 | API 칸 | 비고 |
|---|---|---|---|
| 진행 화면 (`.ldo`) | 로고, 진행 막대와 %, 단계 문장(후보 n건 모으는 중 → 원문 위치와 문장 붙이는 중 → Word 문서 만드는 중) | 요약 칸 일탈·질의 수 | 응답이 올 때까지 90 %에서 멈춤 |
| 알림 (`.ltoast`) | "<파일 이름>를 만들었습니다." | Content-Disposition | 3초 |
| Word 파일 | 제목, 검토 번호·이름, 후보 안내, 목록 이름, 표(No. · 원문 위치 · 문장 · 상태) | `run_outputs` | 뺀 항목 없음 |
| 문장 칸 (`OutputEditor`) | 목록 종류 + 상태 배지, AI 초안 표시, 문장, 숫자 확인 필요, 팀 가정, 문장 확정 · 목록에서 빼기, 고치면 사유 + 문장 저장 | `text_draft`, `status`, `drafted_by`, `number_check`, `is_assumed` | 판정 패널(#draft), 판정 상세 창(#mdDraft), 위험 조건 줄 펼침 |

## 사용자 동작 → 시스템 반응

| 동작 | 누가 | 호출 API | 성공 시 | 실패 시 |
|---|---|---|---|---|
| 일탈 목록 초안 / 질의서 초안 | 모두 | `GET /outputs/export` | 파일 내려받기 + 알림 | 알림 "만들지 못했습니다: …" |
| 문장 확정 | 엔지니어(담당자 확인) | output_item CONFIRM | 배지 "확정" | 오류 문장 |
| 문장 고치고 사유 → 문장 저장 | 엔지니어(담당자 확인) | output_item EDIT + 사유 | 고친 문장, 배지 "확정", 숫자 대조 다시(CR-07) | 사유가 비면 저장 단추가 눌리지 않음 |
| 목록에서 빼기 → 사유 → 빼기 | 엔지니어(담당자 확인) | output_item REJECT + 사유 | 배지 "뺌", Word 파일에서 빠짐 | 사유가 비면 단추가 눌리지 않음 |

## 수용 기준 (Given / When / Then)

- **Given** 일탈 후보가 있는 검토, **When** "일탈 목록 초안"을 누르면, **Then** 진행 화면 → "일탈 목록 초안_<검토 번호>.docx" 내려받기 → 알림. (일탈 목록 초안 내려받기)
- **Given** 질의 문장이 있는 판정, **When** 패널에서 문장을 고치면, **Then** 사유가 비면 저장이 안 되고, 사유를 적어 저장하면 고친 문장이 남는다. (사유 적어 문장 고치기)
- **Given** 일탈 목록 항목 하나를 뺌, **When** Word 파일을 받으면, **Then** 뺀 항목은 없다. (일탈 목록 초안 Word 파일)
