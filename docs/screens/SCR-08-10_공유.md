# SCR-08-10 결재 상신 창: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 결재 상신 단추가 판정 탭 머리에 있음 | 같음 (`update-review-screens` 묶음 1에서 목업 자리로 옮김) | — |
| 2 | 상신 의견은 확인할 항목이 남아 있을 때만 필수 | 항상 필수 | 승인된 스펙(`update-approval-flow` "결재 상신": 결재자나 상신 의견이 없으면 상신하지 않는다) |
| 3 | 의견 없이 누르면 빨간 칸과 안내가 뜸 | 결재자·의견이 차기 전에는 단추가 눌리지 않음 | 스펙 Scenario "결재 상신 창" |
| 4 | 결재자 이름 아래 "기술 검토 팀장" | "승인자" | 사용자 직함 칸이 없다. 역할 이름을 쓴다 |
| 5 | 참조 3명, 첨부 3개, 발에 "참조 n명 · 첨부 n개" | 없음 | `update-approval-flow` Non-Goal (여러 단계 결재선·참조·첨부) |
| 6 | 상신 전 확인 5줄 (일탈, 질의, 확인 필요, 문서 읽기 점검, 상업 조건) | 승인 기준 6줄 (AR-01 일탈, AR-02 포괄 조항, AR-03 확인 필요 비율, AR-06 값 불일치·질의, AR-07 목록 누락, AR-08 제안 포인트) + 문서 읽기 점검 줄 | 값 종류는 API를 따른다(공통 규칙 2장). 문서 읽기 점검은 SCR-08-2에서 붙였다. 상업 조건은 API가 없다 |
| 7 | 각 줄의 "판정 보기" 이동 | 없음 | 1번과 같이 판정 탭을 바꿀 때 붙인다 |
| 8 | 요약 "115 kV 비교 제품" | 없음 | 비교 제품은 설비마다 따로 있다 |
| 9 | 상신 뒤 "결재 문서 만드는 중 → 보내는 중" 진행 화면 | 바로 결재 대기 화면 | 전자결재 연계가 범위 밖이라 기다릴 단계가 없다 |
