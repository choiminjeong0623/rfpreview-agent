# SCR-25 실행 기록: 목업과 다르게 만든 것 (공유)

목업 v4.57에 없는 화면이다(`add-run-log`, 2026-10-31 주말 검토 요청, 통합 개발 목록 2장 3번).
목업의 공통 틀(제목 줄, 요약 칸, 표, 상태 꼬리표)만 따른다.

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | (없음) 메뉴 | 시스템 관리 > "실행 기록" (정답지·채점 아래) | 시스템이 어떻게 돌았는지 보는 화면이라 검토 업무 메뉴(RFP 관리)와 나눴다. 처음에는 지식 관리 아래였고, 정답지·채점과 함께 시스템 관리 묶음으로 옮겼다(update-system-menu, update-runlog-menu) |
| 2 | (없음) 요약 칸 | 실행 수, 끝난 실행 평균 시간, AI 호출 합, 추정 비용 합 | 발표에서 한 줄로 말할 숫자 |
| 3 | (없음) 표 | 검토마다 한 줄: 검토, 상태, 시작, 걸린 시간, 모델, AI 호출(재시도), 토큰, 추정 비용, 문서(다시 씀), 요구사항, 판정, 다시 시도. 줄을 누르거나 Enter를 누르면 실행 기록 상세 화면(`#/runlog/:id`)으로 간다(update-runlog-detail) | 저장한 값만 보인다. 비용은 "추정 · 팀 가정" (CR-06) |
| 4 | (없음) 머리 줄 | "AI: Gemini … · 문장을 외부 AI로 보냅니다" / "AI: 사내 모델 … · 외부로 보내지 않습니다" / "AI 꺼짐 · … 코드 규칙만" (add-ai-mode). 검토 등록에는 보이지 않음(update-register-ai-line) | 외부 전송 여부(NFR-07, Q6)를 쓰는 사람이 바로 알게. 방식은 운영자 설정 `RFP_AI_MODE`로만 바꾼다 |
| 6 | (없음) AI 사용량 상자 | 제목 아래: 기간(7일·30일 기본·90일), 호출 합·추정 비용 합("팀 가정", 모르면 "단가 모름"), 날짜·기능·모델·호출·토큰(입력/출력/생각)·추정 비용 표(날짜 최신순), 기능 칩 거르기, "실제 청구 금액은 Google 결제 화면에서 확인합니다." 기록이 없으면 회색 "이 기간에 AI를 쓴 기록이 없습니다" (update-run-log-ai-usage, `GET /api/ai-usage?days=`) | 검토 도우미·협조 요청 확인할 점·비교 제품 바꾸기·확정 뒤 다시 쓰기처럼 분석 밖 AI 비용도 한곳에서 본다. 기능 이름·합계는 응답 그대로 |
| 5 | (없음) 실행 기록 상세 | Fiori 객체 화면 구성(update-runlog-fiori). 위: [← 실행 기록]·제목 "실행 기록 · 검토 번호"·[검토 상세 보기], 머리글 KPI(상태·걸린 시간·가장 오래 걸린 단계와 전체 %·AI 요청·추정 비용·문서·요구사항·판정). 구역 이동: 단계별 처리 · AI 호출 · 프롬프트 판. "단계별 처리" 한 표: 단계·걸린 시간 막대·그중 AI 시간(ⓘ 동시 요청이라 더 길 수 있음)·바뀐 것(판정 0 → n), 가장 오래 걸린 줄 강조, 사람 동작 줄과 멈춘 자리("담당자 확인에서 멈춤")는 표 아래, 다시 시도는 회차 고르기. "AI 호출": 단계 ▾·역할 ▾·느린 순·[초기화]·m / n건, 결과 없으면 "조건에 맞는 AI 호출이 없습니다", 단계 없는 호출은 "분석 밖 (협조 요청·도우미 등)". "프롬프트 판": 접힌 역할·판 표 | 한 사실은 한 곳(단계 시간 하나), 병목을 머리에, 필요할 때 자세히. 보기만 한다 |
| 7 | (없음) Langfuse로 보낸 기록 | 실행 기록 상세 "AI 호출" 숫자 줄 아래: "Langfuse로 보냄 · 시각 · Langfuse에서 보기 ↗"(이번 작업 trace, 새 창), 보내지 못했으면 회색 "Langfuse로 보내지 못함: 이유". 보낸 적·실패한 적이 없으면 줄 없음 | `add-langfuse-trace-push`. 기록을 켰을 때(`RFP_LANGFUSE_RECORD`)만. 비용·지연 대시보드는 Langfuse 기본 화면. 보내지 못한 것은 사용자 잘못이 아니라 중립색 |
