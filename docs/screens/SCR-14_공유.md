# SCR-14 입찰 이력: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 실제 지명·고객사 이름 (예: 지역 이름 + 설비, 실제처럼 보이는 회사 이름) | "예시 사업장 A · 설비", "예시 고객사 A" | 예시 데이터에 고객사·지명을 넣지 않는 규칙. 설비 이름, 국가, 제품 코드, 번호는 목업 그대로 |
| 2 | 맨 위에 띠 없음 | "예시 화면 · 실제 데이터와 연결되지 않음" 띠 | 입찰 결과 API가 없다 (예시 화면 규칙) |
| 3 | 내보내기 알림 "입찰이력_2026-10-24.xlsx를 만들었습니다. 금액은 영업 권한이 없어 빠졌습니다." | 로딩 화면은 같고 알림은 "예시 화면이라 파일은 만들지 않았습니다…" | 예시 화면은 파일을 만들거나 저장하지 않는다 |
| 4 | 검토 번호가 검토 상세로 감 | 검토 목록으로 감 | 예시 검토 번호(RV-2026-028 등)는 실제 검토가 아니다 |
| 5 | 주소 `#BD-…`·`#제품코드`로 검색·제품 필터를 미리 채움 | 없음 | 앱 주소는 경로만 쓴다. 입찰 상세(SCR-15)는 `#/bids/BD-…`로 연다 |
| 6 | (입찰 상세 메모) "평가 가격 n위" | "가격 평가 (순위는 영업 권한 필요)" | 가격 평가는 가린다 |
