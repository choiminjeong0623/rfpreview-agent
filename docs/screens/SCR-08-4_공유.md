# SCR-08-4 손실 환산 탭: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | "견적 담당에 협조 요청" 단추가 눌림 | 비활성 + 툴팁 | 직접 협조 요청을 보내는 API가 없다. 손실 환산 제안 포인트를 채택하면 견적 담당에게 자동으로 간다(FR-11). 협조 요청 화면(SCR-13) 묶음에서 다시 본다 |
| 2 | 손실값을 칠 때마다 바로 다시 계산 | 칸을 나가거나 Enter를 누를 때 저장하고 다시 계산 | 계산은 백엔드가 한다(CR-01). 글자마다 저장하지 않는다 |
| 3 | 안내의 "Vol.2 8238~8241행" | "<파일 이름> · <표> · <행>" | 원문 위치 형식 (`_공통규칙.md` 3장) |
| 4 | 표 위에 제품 줄 없음 | "비교 제품 X · 팀 가정" 줄 | 어떤 제품 손실값인지, 팀 가정인지 보여야 한다 (CR-06) |
| 5 | 머리 "손실값은 팀 가정" 고정 | 팀 가정일 때만 | `is_assumed`를 따른다 |
| 6 | 계산 못 한 이유 없음 | 표 아래 한 줄 (비교 제품 없음 등) | 빈 값은 "확인 필요"로 이유를 보인다 (CR-04) |
