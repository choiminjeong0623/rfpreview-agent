# SCR-23 자료실: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 올린 사람 이름 | 역할 이름 (기술 검토 엔지니어 A~D, 설계 담당 D, 결재자) | 사람 이름을 넣지 않는 규칙. 칸이 좁아 두 줄로 보일 수 있다 |
| 2 | 올리기 예시 파일 설명의 지명 | "예시 사업장 E·J" | 지명을 넣지 않는 규칙 |
| 3 | 올리기 알림 "… 를 올렸습니다." | 뒤에 "(예시 화면이라 저장하지 않습니다)" | 예시 화면은 저장하지 않는다 |
| 4 | 내려받기 | 목업처럼 "받음"으로만 바뀌고, 툴팁 "예시 화면이라 실제 파일은 없습니다" | 파일이 없다 |
| 5 | "내가 올린 파일"은 로그인한 사람 기준 | 예시 데이터의 기술 검토 엔지니어 A 기준 | 머리글에서 고른 사용자와 연결하지 않는다 |
| 6 | 맨 위에 띠 없음 | 예시 띠 | 자료실 API가 없다 |
