# 화면 명세: SCR-15 입찰 상세

- 연결 요구사항: 없음 (입찰 결과·고객 평가는 범위 밖. 금액·가격 평가는 영업 권한 필요)
- 기준 목업: `Spec2Win_목업_v4.57.html#BidView`
- 구현 방식: 예시 화면 (`add-example-screens`). 데이터는 `frontend/src/examples/SCR-14.ts`(입찰 줄)와 `SCR-15.ts`(상세), 화면은 `frontend/src/views/examples/BidView.tsx`, CSS는 목업 BidView CSS 그대로
- 주소: `#/bids/<입찰 번호>`. 없는 번호면 목업처럼 기본 입찰(BD-2025-024)을 연다
- 사용 API: 없음

## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 예시 띠 | 예시 화면 · 실제 데이터와 연결되지 않음 | — | |
| 제목(`.fh`) | 입찰 이름, 이전 입찰 · 다음 입찰 | 제출일 내림차순 | 끝이면 흐리게 |
| 평가 칸(`.bvk`) | 결과, 기술 평가, 가격 평가, 낙찰사, 금액 | `ev` | 가격 평가·금액은 자물쇠 "영업 권한" |
| 결과·평가 탭 | 결과 사유(사유 꼬리표, 메모, 입력자), 일탈·질의와 고객 반응 표, 고객 평가 의견(원문·번역) | `why`, `memo`, `rows`, `deb` | 의견이 없으면 "영업 담당에게 요청"(화면 안에서만 "요청함") |
| 관련 입찰 탭 | 이 입찰을 참고하는 판정, 같은 고객의 입찰, 같은 제품의 입찰 | `ref`, 입찰 목록 | |
| 문서 탭 | 우리가 제출한 문서, 고객 문서 | `mine`, `cust` | 파일 이름만 (내려받기 없음, 목업과 같음) |
| 이력 탭 | 날짜 · 한 일 · 한 사람(역할) | `hist` | |
| 기본 정보(`aside`) | 입찰 번호, 제출일, 결과 통보, 연결 검토, 담당 엔지니어, 영업 담당, 고객사, 최종 발주처, 국가, 사용 제품, 평가 방식 | | 사용 제품은 제품표로 |

## 수용 기준 (Given / When / Then)

- **Given** 입찰 이력, **When** 입찰 이름을 누르면, **Then** 그 입찰 상세가 예시 띠와 함께 열리고, 가격 평가와 금액은 "영업 권한"으로 가려져 있다. (금액 가림)
- **Given** 고객 평가 의견이 없는 수주·실주 입찰, **When** "영업 담당에게 요청"을 누르고 다른 입찰로 갔다가 돌아오면, **Then** 단추가 다시 "영업 담당에게 요청"이다. (저장하지 않음)
