# 화면 명세: SCR-08 검토 상세 (머리글)

- 연결 요구사항: FR-01·07·09·13, `review-workspace` 검토 정보 입력과 표시 (`add-review-info`), 검토 상세 문서 표 (`update-document-info`), 문서 추가 (`add-document-addendum`, FR-01 ⑤), 검토 도우미 창 (`add-review-assistant`, `update-assistant-panel`, FR-17)
- 기준 목업: `Spec2Win_목업_v4.57.html#Detail`. **v4.96부터 `Spec2Win_목업_v4.96.html`이 기준**(맨 아래 "v4.96 바뀐 점")
- 구현 방식: 머리글은 실제. 탭(SCR-08-1~11)은 `update-review-screens`에서 목업대로 바꾸고, 그전까지 예전 탭 화면을 머리글 아래에 둔다
- 사용 API: `GET /api/runs/{id}`(처리 중이면 2초마다), `PUT /api/runs/{id}/info`, `GET /api/runs/{id}/documents`, `POST /api/runs/preview`·`POST /api/runs/{id}/documents`(문서 추가), `POST /api/runs/{id}/assistant`(검토 도우미)
- 화면 주소: `#/reviews/:id`. 머리글 위치 마지막 칸은 검토 번호

## 수용 기준 (Given / When / Then)

- **Given** 검토 상세, **When** 엔지니어가 머리글에서 고객사를 고치고 저장하면, **Then** 머리글과 목록에 새 고객사가 보이고 이력 탭에 그 변경이 보인다. (머리글에서 고치기)
- **Given** 묶음 A 문서 하나로 판정을 마친 검토, **When** 상세를 열면, **Then** 머리글에 "문서 1개"와 "묶음 A"가 보인다. (판정 묶음 보기)
- **When** "문서 1개"를 누르면, **Then** 파일 이름·문서 종류·분류 방법·묶음 A·판정 대상·요구사항 수가 보이는 창이 열린다. (문서 표 열기)
- **Given** 묶음 C 문서만 있는 검토, **Then** 머리글에 "판정 문서 없음", 표에 "판정 안 함"·이유·"확인 필요"가 강조된다. (판정하지 않는 문서)
- **Given** 판정 1줄을 확정한 검토, **When** 엔지니어가 문서 표에서 docx 하나를 골라 "추가하고 다시 분석"을 누르면, **Then** 끝난 뒤 "문서 2개", 확정한 줄은 "확정" 그대로, 이력에 "문서 추가"와 파일 이름. (문서 추가하고 다시 분석)
- **Given** 담당자 확인 단계 검토, **When** 승인자가 문서 표를 열면, **Then** "문서 추가" 칸이 없다. (승인자에게는 문서 추가 없음)
- **Given** 분석이 끝난 검토, **When** 엔지니어가 검토 도우미 창에서 "ambient temperature"를 물으면, **Then** 창에 그 글자가 들어간 근거 조항과 원문 위치, 상태 한 줄이 보이고 고치기 단추는 없다. (도우미에 묻기)
- **Given** AI 없이 도는 검토, **When** 검토 도우미 창에서 "시험 입회 조건이 있는 조항"을 물으면, **Then** "일치하는 조항이 없습니다."와 영어 낱말로 찾아 보라는 안내가 보이고 근거 조항은 없다. (맞는 조항이 없을 때)
