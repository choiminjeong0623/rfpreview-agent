# 화면 명세: SCR-16-1 제품 상세 (전용 화면)

- 연결 요구사항: `reference-data` 제품표 조회·제품이 쓰인 곳, FR-07 판정 근거, FR-14 제안 포인트, FR-15 현장 이력, CR-02·06
- 기준 목업: `Spec2Win_목업_v4.96.html#ProductView` (v4.96에서 새로 생김)
- 구현 방식: 실제, 읽기 전용 + 예시 영역. 사진·문서는 지금 제품표 패널의 것을 옮긴다(`add-product-photos`, `add-product-docs`)
- 화면 주소: `#/products/:code`. 위치: 홈 > 제품 관리 > 제품표 > 제품 코드
- 사용 API: `GET /products/{code}`, `GET /rules/items`, `GET /rules/compare`, `GET /products?family=`(같은 제품군, 대신 쓸 수 있는 제품)
- 예정 API: 없음 (새 API 없이 만든다)
- 구현됨 (change `add-product-view`, 2026-11-01): `GET /products/{code}`의 판정 줄에 `item_key`·`due_date`를 더해 막힌 판정·D-day를 셈. 목업과 다른 곳은 `SCR-16_공유.md` 10~17

## 화면 구성

| 영역 | 보이는 항목 | API 칸 | 비고 |
|---|---|---|---|
| 머리 | 제품 코드, 제품군, "설계 사례" 꼬리표, 값 종류 · 출처, [제품표](목록으로), [수정 요청](잠김) | `product_code`, `family`, `is_design_card`, `is_assumed`, `source_doc` | 수정 요청은 "제품표는 읽기 전용입니다" |
| 요약 칸: 제품 | 제품군, 정격 전압, 값 종류(카탈로그 정격 / 설계 사례 / 팀 가정), 갱신 | `family`, `rated_voltage_kv`, `is_design_card`, `comparison_values_assumed` | 갱신일은 칸이 없어 "제품표 적재 판" |
| 요약 칸: 근거 상태 | 팀 가정 n, 빈칸 n | `comparison_values_assumed`, `empty_count` | 성적서·카탈로그·설계 사례 칸별 개수는 만들지 않음 |
| 요약 칸: 쓰임 | 진행 중 검토 n, 값이 없어 막힌 판정 n, 제안 포인트 n | `used_runs`, `used_in`(비교 값이 빈 판정), `proposals` | 막힌 판정 = `used_in` 중 결과가 확인 필요이고 비교 칸이 `empty_columns`에 든 줄 |
| 대표 그림 | 제품 계열 사진, "이 모델만의 사진은 아님", 출처 링크 | `productPhotos.ts` | 지금 제품표 패널과 같음 |
| 관련 문서 | 카탈로그·매뉴얼·시험 성적서·인증서 링크(제목·날짜·언어), "제품표 값의 출처" | `productDocs.json` | 문서 보기(쪽 넘김·형광)는 만들지 않고 공식 자료실 링크 |
| 탭 "정격" | 항목, 값(+ 단위), 비교 방향, 근거(출처·팀 가정·비어 있음) | 모든 값 칸, `value_columns`, `/rules/compare` | 옵션 칸 없음 |
| 탭 "치수·운송" | 중량 | `weight_kg` | 치수·운송 중량은 칸이 없어 "제품표에 없음" 한 줄 |
| 탭 "쓰인 곳" | 지금 쓰이는 검토(검토 번호·이름·판정 수·D-day), 자주 나온 판정(결과별 수) | `used_runs`, `used_in` | 검토를 누르면 검토 상세, 판정을 누르면 판정 상세 |
| 탭 "현장 이력" | 사례, 현상, 원인, 조치, 관련 판정 항목 | `field_history`(`root_cause` 포함) | 없으면 "연결된 고장 사례가 없습니다." |
| 예시 영역 | 최근 입찰 결과 | `examples/` | 예시 띠, "금액·경쟁사는 보이지 않습니다" |

## 화면 상태

- 로딩 중: 머리는 코드만, 나머지는 회색 줄.
- 데이터 없음: 없는 코드면 "제품표에 없는 제품입니다 (코드)" + [제품표].
- 오류: 공통 규칙.
- 권한 없음: 수정 요청은 모두에게 잠김(읽기 전용).

## 입력 검증

- 입력 칸 없음 (목업의 현장 조건 입력은 만들지 않음).

## 목업에 있지만 만들지 않는 요소

- 현장 조건(해발 고도·최고 주위 온도 입력으로 정격 보정): 계산·단위 환산에 닿음, 범위 밖(Q6).
- 근거 상태의 형식시험 성적서·카탈로그·설계 사례 개수, 정격 탭의 옵션 칸: 제품표에 칸별 근거·옵션 칸이 없음.
- 탭 "규격·인증" 표: 데이터가 없음. 관련 문서의 인증서 링크로 대신.
- 문서 보기(쪽 넘김, 판정 값 형광, 내려받기): 문서 파일을 서버에 두지 않음(저작권). 공식 링크.
- 최근 입찰 결과: 범위 밖, 예시 영역.
- [설계팀에 요청], [고장 사례 연결]: 해당 API 없음, 잠김.

## 수용 기준 (Given / When / Then)

- **Given** 제품표의 GIS 제품, **When** 제품 코드를 누르면, **Then** 주소가 `#/products/<코드>`가 되고 정격 탭에 정격 전압 값과 비교 방향이 보인다. (제품 상세 화면 열기)
- **Given** 진행 중 검토 하나에 쓰인 제품, **When** 쓰인 곳 탭을 누르면, **Then** 그 검토 번호와 판정 수가 보이고, 누르면 검토 상세로 간다. (쓰인 곳)
- **Given** 팀 가정 비교값 2칸이 있는 제품, **When** 화면을 열면, **Then** 근거 상태에 "팀 가정 2"가 보이고 정격 탭 그 칸에 "팀 가정"이 붙는다. (팀 가정 표시)
- **Given** 비교 칸이 비어 확인 필요가 된 판정 1줄이 있는 제품, **When** 화면을 열면, **Then** "값이 없어 막힌 판정 1"이 보인다. (막힌 판정)
- **Given** 없는 제품 코드 주소, **When** 열면, **Then** "제품표에 없는 제품입니다"와 제품표로 가는 단추가 보인다. (없는 제품)
