# 화면 명세: SCR-18 표준 문구

- 연결 요구사항: 없음 (일탈·질의 문장은 FR-09에서 언어 모델이 쓴다. 표준 문구 저장소는 없음)
- 기준 목업: `Spec2Win_목업_v4.57.html#Phrases`
- 구현 방식: 예시 화면 (`add-example-screens`). 데이터는 `frontend/src/examples/SCR-18.ts`, 화면은 `frontend/src/views/examples/Phrases.tsx`, CSS는 목업 Phrases CSS 그대로
- 사용 API: 없음
- 예정 API: 문구 목록, 문구 추가·검토·배포

## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 예시 띠 | 예시 화면 · 실제 데이터와 연결되지 않음 | — | |
| 제목 | 표준 문구, 문구 추가 | — | 문구 추가는 화면 안에만 초안(DV-05 …)을 만든다 |
| 배포본 안내(`.ph-info`) | 현재 배포본 v3 · 날짜 · 배포한 사람(역할), 설명 | — | |
| 막대(`.ph-bar`) | 구분(전체·일탈 문구·질의 문구·확인 요청, 개수), 문구 찾기, 폐기된 문구도 보기 | 구분, 상태 | 찾기는 코드·상황·영문·국문 |
| 목록(`.ph-box`) | 코드, 구분, 쓰는 상황과 영문 문구, 최근 90일 사용, 최근 수정(사람·날짜), 상태 | 위 칸 | 검토 중은 사용 "—" |
| 펼친 줄(`.ph-det`) | 영문(제출용)·국문(내부 확인용) 문구, 연결된 판정 규칙, 변경 이력, 영문 복사, 규칙 보기 | | `{ }` 자리는 색으로 구분. 규칙 보기는 실제 판정 규칙 화면 |

## 수용 기준 (Given / When / Then)

- **Given** 왼쪽 메뉴, **When** 표준 문구를 열면, **Then** 예시 띠와 사용 중·검토 중 문구 9개가 보이고, 폐기된 문구도 보기를 켜면 10개. (예시 띠)
- **Given** 표준 문구, **When** 문구 추가를 누르고 다른 화면에 갔다 오면, **Then** 추가한 초안이 없다. (저장하지 않음)
