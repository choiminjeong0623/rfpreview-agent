# SCR-18 표준 문구: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 배포한 사람·수정한 사람의 이름 | 역할 이름 (기술 검토 엔지니어 A~D) | 사람 이름을 넣지 않는 규칙 |
| 2 | 맨 위에 띠 없음 | 예시 띠 | 표준 문구 저장소가 없다 |
| 3 | 문구 추가 알림 "… 초안을 만들었습니다. 팀 검토 후 사용 중으로 바뀝니다." | 뒤에 "(예시 화면이라 저장하지 않습니다)" | 예시 화면은 저장하지 않는다 |

## 팀에 알릴 것

- 지금 일탈·질의 문장은 FR-09에서 언어 모델이 쓰고 숫자는 자리표시자로 코드가 채운다(CR-07). 표준 문구를 실제로 쓰려면 문구 표와 "어떤 판정에 어떤 문구"를 고르는 규칙이 필요하다(코드로 고르기, CR-01).
