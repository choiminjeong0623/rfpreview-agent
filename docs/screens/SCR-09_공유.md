# SCR-09 TBE 준수표: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 고객 요구·제품값 숫자에 천 단위 쉼표("4,000 A") | 원문 그대로("4000 A") | 값은 원문 그대로 낸다(CR-10). 화면만 쉼표를 붙이면 엑셀과 달라진다 |
| 2 | 판정 기준 "현재 판정 (10-24 15:20)" = 마지막 판정 시각 | "현재 판정 (화면을 연 시각)" | 판정마다 바뀐 시각을 저장하지 않는다 |
| 3 | 위치 없어 뺀 줄 2개와 항목 이름 목록 | 수와 이유만, 0이면 숨김 | 판정은 원문 위치 없이 만들지 않아(CR-02) 보통 0이다. 이름 목록을 줄 데이터가 없다 |
| 4 | 우리 제품값 "125 kA (계산값)" 같은 꼬리표 | 제품 코드만 | 계산값 표시는 공학 검산(FR-12) 결과라 판정 줄에 없다 |
| 5 | 보증값 작성 줄 처리 안내 없음 | 넣지 않음 | 보증값 작성은 고객 요구가 빈 칸이라 데이터시트(SCR-10)로 간다 |
| 6 | 반려한 판정 처리 안내 없음 | 넣지 않음 | 판정 칩 수와 같게 반려는 뺀다 |
