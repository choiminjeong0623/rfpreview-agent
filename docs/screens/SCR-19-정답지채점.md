# 화면 명세: SCR-19 정답지·채점

- 연결 요구사항: 기획서 2-2 K지표(K4·K5·K6·K11·K12·K13, 처리 시간), 명세서 8장 "정답지·채점", 명세 `evaluation`
- 기준 목업: `Spec2Win_목업_v4.57.html#Eval`
- 구현 방식: 실제 화면 (`add-evaluation`). 화면 `frontend/src/views/Eval.tsx`, CSS는 목업 Eval CSS 그대로
- 사용 API: `GET /api/eval/runs`(넣을 수 있는 검토), `GET /api/eval/keys`(유형 정답지), `GET /api/eval/scores`(채점 기록), `POST /api/eval/scores`(지금 채점하기)
- 정답지 넣기: 명령 `rfp-db load-answer-key 정답지.csv --name 이름 [--human]` (화면에서 올리지 않음)

## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 제목 | 정답지·채점, 설명, 지금 채점하기 | — | 넣은 검토가 없으면 막힘 |
| 안내(`.sh-note`) | 코드로만 잼, K5·K6는 확정·수정한 줄이 정답, 자동 확정 없음 | — | |
| 요약(`.sh-sum`) | 정답지 줄 수, 검토 수, 마지막 채점, 목표 달성 n / m, 지난번보다 좋아짐 | 고른 정답지·넣은 검토·최근 채점 | m = 목표가 있고 값이 있는 지표 수 |
| 채점 결과 탭 | 지표, 무엇을 재나(+참고), 지난, 이번(+분자/분모), 변화(▲▼), 목표(달성 초록·미달 주황) | `eval_score.metrics` | 지난 = 바로 앞 채점. 재지 않는 지표(K1·K2·K3·K8·K9·K10)는 "재지 않음" |
| 정답지 탭 | 넣기 체크, 검토(검토 번호 링크), 확정한 사람, 마지막 확정, 판정 줄 | `/api/eval/runs` | 처음엔 모두 넣음 |
| 〃 유형 정답지 | 고름(정답지 없이 포함), 정답지 이름 + "Claude 초안 · 사람 확인 전", 사람 확인 n / 전체, 넣은 날, 줄 | `/api/eval/keys` | |
| 〃 메모 | 무엇을 고쳤나 | `eval_score.note` | 채점 기록에 남음 |
| 개선 기록 탭 | 날짜, 정답지, 무엇을 고쳤나(검토 수·코드 판), 점수(K5 · K13), 한 사람 | `/api/eval/scores` | 최근 것부터 |

## 수용 기준 (Given / When / Then)

- **Given** 사람이 판정을 확정한 검토, **When** "지금 채점하기"를 누르면, **Then** 채점 결과 탭에 K5와 처리 시간이 보이고 개선 기록에 새 줄이 생긴다. (지금 채점하기)
- **Given** Claude 초안 유형 정답지, **When** 정답지 탭을 열면, **Then** "Claude 초안 · 사람 확인 전"과 사람 확인 줄 수가 보인다. (Claude 초안 표시)
