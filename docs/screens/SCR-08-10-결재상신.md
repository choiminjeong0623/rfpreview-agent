# 화면 명세: SCR-08-10 결재 상신 창

- 연결 요구사항: FR-10, `review-approval` 결재 상신, `review-workspace` 판단 동작
- 기준 목업: `Spec2Win_목업_v4.57.html#Detail` → "결재 상신" 단추로 여는 창 (레이아웃 기준선)
- 구현 방식: 실제 (`update-approval-flow`)
- 사용 API: `GET /api/runs/{id}/approval`(preview, review_ratio), `GET /api/runs/{id}/judgments`(X-Total-Count), `GET /api/runs/{id}/losses`, `GET /api/users`, `POST /api/runs/{id}/finish-review`
- 예정 API: 없음

## 화면 상태

- 로딩 중: 요약 칸과 확인 목록이 비어 있다가 채워진다.
- 오류: 상신 의견 아래 빨간 글(`role=alert`)로 API 오류 문장.
- 권한 없음: 엔지니어가 아니면 상신 단추가 눌리지 않고 "결재 상신은 기술 검토 엔지니어만 할 수 있습니다" 안내.

## 사용자 동작 → 시스템 반응

| 동작 | 누가 | 호출 API | 성공 시 | 실패 시 |
|---|---|---|---|---|
| 머리글 "결재 상신" | 엔지니어 | `GET /approval` 등 | 창이 열림 | — |
| 결재자 고르기 | 엔지니어 | — | 발에 결재자 이름 | — |
| 결재 상신 | 엔지니어 | `POST /finish-review` {approver_id, comment, actor_id} | 창 닫힘, 검토가 승인 대기 → SCR-12 화면 | 오류 문장 (400 의견·결재자, 403 역할, 404 사용자, 409 단계) |

## 입력 검증

- 결재자: 필수, 승인자 역할만 목록에 나온다.
- 상신 의견: 필수(공백만이면 안 됨). 두 칸이 모두 있어야 상신 단추가 눌린다.

## 목업에 있지만 만들지 않는 요소

- 참조(견적·품질·영업), 첨부(일탈 목록 초안.docx 등), 전자결재 문서 만드는 중 진행 표시: `update-approval-flow` Non-Goal.
- 상신 전 확인의 "판정 보기" 이동 단추: 판정 탭이 아직 예전 화면이라 다음 단계(`update-review-screens`)에서 붙인다.
- "115 kV 비교 제품" 요약 칸: 비교 제품이 설비별로 여러 개라 한 칸에 담지 않는다.

## 수용 기준 (Given / When / Then)

- **Given** 일탈 후보가 있는 검토, **When** 엔지니어가 결재 상신 창을 열면, **Then** 지금 걸리는 기준 AR-01이 보이고 결재자와 상신 의견을 넣기 전에는 상신 단추가 눌리지 않는다. (결재 상신 창)
