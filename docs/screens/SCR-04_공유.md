# SCR-04 사업 현황: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 요약에 "등록 전 범위" | 없음 | RFP는 받았지만 검토가 없는 범위를 적어 둘 곳이 없다 (`add-project-status` Non-Goal, 10-30 결정) |
| 2 | 범위 칩에 "Lot 1 협조 대기"처럼 Lot 이름 | 상태 이름만 | 검토에 Lot 칸이 없다. 칩에 마우스를 올리면 설비 범위 이름이 보인다 |
| 3 | 칩 색 8가지(등록 전 포함) | 등록 전 대신 "반려"(빨강, 분석 실패와 같은 색) | 반려된 검토를 숨기면 할 일이 사라진 것처럼 보인다 |
| 4 | 사업명 아래 전체 이름 | 사업 번호(PJ-…) | 사업에는 이름이 하나뿐이다 |
| 5 | 내 역할 "Lot 1 기술 검토"처럼 범위까지 | "엔지니어 · 결재자 · 협조 · 영업 · 만든 사람" 중 하나 | 역할 순서는 엔지니어 → 결재자 → 협조 → 영업 → 만든 사람 (`business-status`) |
| 6 | "내 사업"은 로그인한 사람 기준 | 머리글에서 고른 사용자 기준 | 로그인이 없다 |
| 7 | (v4.96) 요약 칸 4개(등록 전 범위 포함) | 3개 | "등록 전 범위"는 숨기기로 했다(SCR-04 [결정]). 요약 칸으로 거를 때는 상태 칸을 보지 않는다(요약 조건이 이미 "제출 안 함") |
