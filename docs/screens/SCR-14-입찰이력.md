# 화면 명세: SCR-14 입찰 이력

- 연결 요구사항: 없음 (입찰 결과·금액은 범위 밖. 금액은 가격 범위라 영업 권한 필요)
- 기준 목업: `Spec2Win_목업_v4.57.html#Bids`
- 구현 방식: 예시 화면 (`add-example-screens`). 데이터는 `frontend/src/examples/SCR-14.ts`, 화면은 `frontend/src/views/examples/Bids.tsx`, CSS는 목업 Bids CSS 그대로(`frontend/src/mockup/Bids.css`)
- 사용 API: 없음 (서버를 부르지 않는다)
- 예정 API: 입찰 결과 목록, 내보내기

## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 예시 띠(`.exband`) | 예시 화면 · 실제 데이터와 연결되지 않음 | — | 맨 위 |
| 제목(`.ttl`) | 입찰 이력, 기간(1개월 · 3개월 · 전체), 내보내기 | `sub` | 기간 기준일은 목업과 같다(1개월 09-24, 3개월 07-24) |
| 요약(`.bsum`) | 수주율, 결과(수주·실주·유찰, 결과 대기), 실주 사유, 기술 사유로 실주한 요구(상위 2) | `res`, `rsn`, `why` | 제품 필터만 따른다(목업과 같음). 수주율 = 수주 ÷ (수주 + 실주) |
| 머리 줄(`.sech`) | 입찰 n, 금액·경쟁사는 영업 권한이 있어야 보임 | — | |
| 필터(`.filters`) | 검색(입찰명·고객·검토 번호), 제품, 결과, 필터 지우기 | `name`, `cust`, `rv`, `bid`, `prod`, `res` | |
| 표 | 입찰(이름, 입찰 번호, 검토 번호), 고객 · 국가, 제출, 사용 제품, 일탈, 결과, 결과 사유, 금액 | 위 칸 전부 | 제출일 내림차순. 올해는 MM-DD, 그 전은 YY-MM-DD. 금액은 자물쇠 + "영업 권한 필요" |
| 쪽 나눔 | 10·20·50개씩 | — | |
| 내보내기 | 로딩 화면 → 알림 | — | 파일은 만들지 않는다 |

## 수용 기준 (Given / When / Then)

- **Given** 왼쪽 메뉴, **When** 입찰 이력을 열면, **Then** 예시 띠와 입찰 48건 표가 보이고 검토 API를 부르지 않는다. (예시 띠)
- **Given** 입찰 이력, **When** 금액 칸을 보면, **Then** 숫자 대신 자물쇠와 "영업 권한 필요". (금액 가림)
- **Given** 결과 필터를 실주로 바꾼 뒤, **When** 다른 화면에 갔다가 다시 열면, **Then** 필터가 처음(모든 결과)으로 돌아와 있다. (저장하지 않음)
