# SCR-02 처리 상태: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 화면 전체를 덮는 로딩 화면 | 왼쪽 메뉴·머리글은 두고 본문 자리만 덮음 | 처리는 몇 분 걸릴 수 있어 그동안 다른 화면으로 갈 수 있게 한다 |
| 2 | 백분율이 매끄럽게 올라감 | 처리 단계 순서와 문서 읽기 단계의 실제 세부 진행(AI가 처리한 줄 수)으로 올라감 | 시간으로 꾸민 숫자는 멈춰도 움직여 멈춤을 숨긴다. 실제로 처리한 양만 보인다 (2026-10-29 `update-processing-progress`) |
| 3 | "화면 불러오기"·"RFP 등록" 문장 | 처리 단계 문장 + 문서·요구사항 수 | 이 화면은 RFP 분석 진행을 보인다. 등록 중 진행은 SCR-07 등록 화면이 보인다 |
| 4 | 문장 한 줄 | 문장 아래 지난 시간, 예상 시간 안내, 10분 넘게 진행이 없으면 빨간 안내 | 2026-10-29 실제 RFP 테스트에서 15분 동안 고장인지 알 수 없었다 |
| 5 | (목업에 없음) 분석 취소 | 진행 문장 아래 "분석 취소" 단추. 한 번 더 확인한 뒤 취소를 요청하고, 처리가 다음 진행 기록에서 멈추면 분석 실패 화면(SCR-11)으로 바뀐다. 10분 넘게 진행이 없으면 바로 멈춘 것으로 표시한다 (`add-run-control`) | 10-31 주말 검토: 잘못 올렸거나 너무 오래 걸리는 검토를 멈출 방법이 없었다. 백엔드가 꺼져 멈춘 검토도 정리할 수 있게 한다 |
