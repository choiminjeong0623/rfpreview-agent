# 화면 명세: SCR-08-6 상업 조건 탭

- 연결 요구사항: FR-16(비용 조건 요약), `cost-conditions`, `review-workspace` 상업 조건 탭
- 기준 목업: `Spec2Win_목업_v4.57.html#Detail` 상업 조건 탭 (`#comm`)
- 구현 방식: 실제 화면 (`add-cost-conditions`). 예전 예시 화면(`update-review-screens` 묶음 8)을 바꿈
- 사용 API: `GET /runs/{id}/cost-conditions`(비용 조건 + 상업 영향), `GET /runs/{id}/documents`(파일 이름)
- 보내기: 이 탭에는 없다. 견적 담당 협조 요청 메일은 판정 확정 때와 협조 요청 현황(SCR-13)에서 나간다

## 화면 구성

| 영역 | 보이는 항목 | API 칸 | 비고 |
|---|---|---|---|
| 머리(`.sech`) | "비용 조건 n · 기술 판단 영향 n · 안 보낸 협조 요청 n", 협조 요청 현황 연결 | `conditions`, `impacts`, `request_status` | 비용 조건이 없으면 연결 단추도 없음 |
| 안내(`.rdi`) | 규칙으로 찾은 후보, 금액 계산 없음, 메일은 협조 요청 현황 | — | |
| 종류 칩(`.fbar .chip`) | 전체 + 조항 종류별 건수 | `kind` | 누르면 그 종류만 |
| RFP의 비용 조건 표(`.cmt`) | 조항 종류(+위험 표시·계약상대자 부담), 값(원문 그대로)·원문·"후보"·주 유형·반복 수, 원문 위치(파일 이름), 견적 담당, 협조 요청 상태(안 보냄·회신 대기·회신 받음·협조 요청 없음, 발송 실패·주소 없음) | `kind`, `risk`, `burden`, `values`, `text`, `primary_type_name`, `repeat_count`, `locations`, `request_status`, `mail_error` | 종류 순서: 지체상금, 책임 한도, 하자 보증, 이행 보증서, 지급 조건, 가격 유효 기간, 인도 조건, 통화·환율, 손실 평가, 예비품, 특수 공구, 운반·포장, 시험 입회, 설치 감독, 교육, 무상 공급, 기타 비용 |
| 기술 판단에서 생긴 상업 영향 표 | 손실 환산 가산액(제품, 가산액 또는 "확인 필요", 팀 가정) → 손실 환산 탭, 일탈 가격 영향(일탈 문장) → 판정 탭 | `impacts` | 가산액은 손실 환산(FR-13)이 계산한 값 그대로 |
| 아래 문장(`.cmfoot`) | 협조 요청 현황 연결 | — | |

## 수용 기준 (Given / When / Then)

- **Given** 지체상금 줄이 있는 검토, **When** 상업 조건 탭을 열면, **Then** 예시 띠 없이 지체상금 줄이 원문 위치·견적 담당·협조 요청 상태와 함께, 머리에 비용 조건 수. (상업 조건 탭 열기)
- **Given** 하자 보증 2건, **When** "하자 보증" 칩을 누르면, **Then** 그 두 줄만, 칩 눌림. (종류 칩으로 거르기)
- **Given** 비용 영향 줄이 없는 검토, **When** 탭을 열면, **Then** "찾은 비용 조건이 없습니다", 보내기·내려받기 단추 없음. (비용 조건이 없는 검토)
