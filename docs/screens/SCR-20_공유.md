# SCR-20 팀 현황: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 팀원 이름·이름 첫 글자 아바타, 대리인·팀장 이름 | 역할 이름 (기술 검토 엔지니어 A~D, 설계 담당 D, 결재자) | 사람 이름을 넣지 않는 규칙. 다른 예시 화면과 같은 이름을 쓴다 |
| 2 | 외근 장소(사업장 이름) | "외근"만 | 장소 이름을 넣지 않는다 |
| 3 | 도움 요청의 검토 이름·지난 건 지명 | "예시 사업장 A" | 지명을 넣지 않는 규칙 |
| 4 | 줄·검토 열람이 그 사람·그 검토로 감 | 실제 검토 목록으로 감 | 예시 사람·검토 번호는 실제가 아니다 |
| 5 | 의견 남기기 알림 "… 에게 알림이 갑니다." | 뒤에 "(예시 화면이라 실제로 보내지 않습니다)" | 예시 화면은 보내거나 저장하지 않는다 |
| 6 | 맨 위에 띠 없음 | 예시 띠 | 팀 현황 API가 없다 |
