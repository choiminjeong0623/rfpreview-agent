# SCR-15 입찰 상세: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 실제 지명·고객사·발주처 이름 | "예시 사업장 A", "예시 고객사 A", "예시 발주처 A" | 예시 데이터에 고객사·지명을 넣지 않는 규칙 |
| 2 | 담당 엔지니어·영업 담당·이력의 사람 이름 | 역할 이름 (기술 검토 엔지니어, 영업 담당, 결재자, 고객) | 사람 이름을 넣지 않는 규칙 |
| 3 | 가격 평가 칸 "평가 가격 1위" 등 | 자물쇠 "영업 권한" | 가격 평가는 가린다 (가격 범위 밖) |
| 4 | 고객 평가 의견의 가격 문장 ("평가 가격이 낙찰자보다 5.0 % 높았습니다" 등) | "[가격 평가 내용은 영업 권한이 있어야 보입니다]" | 같은 이유. 기술 문장은 그대로 |
| 5 | 낙찰사 "회사 이름 (당사)" | "당사" | 회사 이름을 넣지 않는다 |
| 6 | 맨 위에 띠 없음 | 예시 띠 | 입찰 결과 API가 없다 |
| 7 | "영업 담당에게 요청" 알림에 사람 이름 | "영업 담당에게 … 요청했습니다. (예시 화면이라 실제로 보내지 않습니다)" | 예시 화면은 보내거나 저장하지 않는다 |
| 8 | 연결 검토·참고 판정이 검토 상세로 감 | 검토 목록으로 감 | 예시 검토 번호는 실제 검토가 아니다 |
