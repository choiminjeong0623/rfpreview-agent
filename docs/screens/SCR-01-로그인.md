# 화면 명세: SCR-01 로그인

- 연결 요구사항: 없음 (범위 밖. 앱은 로그인 대신 머리글에서 사용자를 고른다)
- 기준 목업: `Spec2Win_목업_v4.57.html#Login`
- 구현 방식: 예시 화면 (`add-example-screens`). 화면은 `frontend/src/views/examples/Login.tsx`, CSS는 목업 Login CSS 그대로
- 주소: `#/login` (왼쪽 메뉴에 없다). 앱 틀(메뉴·머리글) 없이 화면 전체를 쓴다
- 사용 API: 없음. 입력한 사번·비밀번호·요청 내용은 어디에도 보내지 않는다

## 화면 구성

| 영역 | 보이는 항목 | 비고 |
|---|---|---|
| 왼쪽 소개 | 로고, 소개 그림 4장(여러 언어 문서를 읽는다 · 판정한다 · 돈으로 본다 · 이기는 제안을 만든다), 넘기기 막대, 자동 넘김 멈춤 | 5초마다 넘어가고, 마우스를 올리면 멈춘다. 움직임 줄이기 설정이면 처음부터 멈춤 |
| 오른쪽 위 | 글자 크기(기본·큰 글씨), 도움말 | 글자 크기는 이 화면 안에서만 바뀐다 |
| 로그인 탭 | 사내 계정(SSO)으로 계속, 사번 또는 회사 이메일, 비밀번호(보기 단추), 로그인 상태 유지, 비밀번호 찾기, 로그인 | 빈 칸이 있으면 빨간 칸과 안내. 로그인하면 로딩 화면 뒤 홈으로 간다 |
| 접근 권한 요청 탭 | 이름, 회사 이메일, 맡은 일, 요청 사유, 요청 보내기 | 이름이 비었거나 메일 형식이 아니면 안내. 보내면 "요청을 보냈습니다" (실제로 보내지 않음) |
| 바닥글 | 시스템 이름, 개인정보 처리 안내 · 이용 안내 | 링크는 움직이지 않는다 |

## 수용 기준 (Given / When / Then)

- **Given** 주소 `#/login`, **When** 화면을 열면, **Then** 메뉴·머리글 없이 소개 그림과 로그인 칸이 보인다. (로그인 화면)
- **Given** 빈 칸, **When** 로그인을 누르면, **Then** 두 칸이 빨갛게 되고 "입력하지 않은 칸이 있습니다"가 보인다. (로그인 화면)
- **Given** 사번과 비밀번호, **When** 로그인을 누르면, **Then** 로딩 화면 뒤 홈으로 가고 사용자는 머리글에서 고른 사람 그대로다. (저장하지 않음)
