# 화면 명세: SCR-08-12 판정 상세 (전용 화면)

- 연결 요구사항: FR-07(판정·근거), FR-08(보증값), FR-09(질의), FR-10(확정·수정·이력), CR-02·03(원문 위치·신뢰도), CR-06(팀 가정), `review-workspace` 판정 상세
- 기준 목업: `Spec2Win_목업_v4.96.html#JudgeView` (v4.93에서 새로 생김)
- 구현 방식: 실제. 판정 창(`JudgmentDialog`)을 이 화면으로 바꿨다. 과거 입찰 결과 영역은 만들지 않는다(`_v4.96_결정.md` Q6)
- 구현됨 (change `add-judgment-view`, 2026-11-01). 질의 보냄 표시·되돌리기 구현됨 (change `add-query-sent`, 2026-11-01, `POST /actions` `QUERY_SENT`·`QUERY_UNSENT`, 판정 `query_sent_at`). 목업과 다른 곳은 `SCR-08-12_공유.md`
- 화면 주소: `#/reviews/:id/judgments/:jid?f=<거르기>&type=<유형>` — 판정 목록의 거르기를 그대로 가져와 이전·다음 판정을 정한다. 위치: 홈 > RFP 검토 > 검토 번호 > 판정 D1
- 사용 API: `GET /runs/{id}`, `GET /runs/{id}/judgments?…`(이전·다음 순서), `GET /requirements/{rid}?run_id=`, `GET /runs/{id}/documents`, `GET /rules/compare`, `GET /products/{code}`, `GET /runs/{id}/checks`, `GET /runs/{id}/outputs`, `GET /runs/{id}/history`, `GET /runs/{id}/warranty`, `POST /runs/{id}/actions`
- 원문 줄 범위 `GET /runs/{id}/documents/{file_no}/lines?from=&to=` (`add-judgment-view`)
- 예정 API: 질의 보냄 `QUERY_SENT`·`QUERY_UNSENT` (`add-query-sent`)

## 화면 구성

| 영역 | 보이는 항목 | API 칸 | 비고 |
|---|---|---|---|
| 맨 위 | ← 판정 목록으로, "사업명 · 검토명 · 검토 번호" | `RunSummary` | 목록으로 가면 같은 거르기·쪽 |
| 머리 | 판정 배지, 항목 이름(한국어), 원문 항목 이름, "판정 n / 전체", ↑ ↓ | `result`, `item_name`, `item_name_raw` | 전체는 거른 목록 기준 |
| 원문 머리 | 파일 이름, 언어("EN · 영어"), 위치 탭(본문 7100행 / 표 이름 7161행 / …) | `/documents`의 `file_name`·`language`, `locations[]` | 위치가 하나면 탭 없음 |
| 원문 줄 | 절 번호·제목, 앞뒤 2줄 + 그 줄(강조), 줄 번호 | 예정 `lines` (`line_start-2` ~ `line_end+2`) | 파일이 없어 `partial`이면 "저장된 줄만 보입니다" |
| 표 위치일 때 | No. · Description · Unit · Employer's Req. · Warranted 한 줄 | `/requirements/{rid}`의 표 행 값 | 지금 판정 창과 같음 |
| 비교 | 요구값(원문) + 위치, 부등호, 제품값 + 제품 코드 | `req_value_raw`, `unit_raw`, `margin_direction`, `product_value_raw`, `product_code` | 계산 값(검산)이면 "계산 125 kA · 차단 50 kA × 2.5" |
| 판정 근거 | 비교 방향("정격 전류는 클수록 좋음") + 판정 규칙 보기, 적용 규칙 문장, 반복 위치("3곳에서 모두 4,000 A"), 제품값 출처("LSG-245-50 · 제품표 (GIS 카탈로그 p.18)"), 팀 가정 | `/rules/compare`(`item_key`), `reason_text`, `locations`+`values`, `Product.source_doc`·`comparison_values_source`, `is_assumed` | 위치마다 값이 다르면 "값이 다른 곳 n" (주황) |
| 판정 출처 | 시스템 제안(판정 + "코드 규칙"), 찾은 방법(코드/AI)·신뢰도, 담당자 확정(판정·사람·시각 또는 "아직 확정 안 함") | `review_status`, `/history`, `Requirement.extracted_by`·`confidence` | 신뢰도를 처음 화면에 보인다 (CR-02) |
| 지난 확정 | "지난 검토에서 사람이 고친 기록": 무엇을·누가·언제·검토 번호·사유 | `past_decision` | 참고용 문장 그대로 |
| 질의 (질의 후보만) | "질의 초안" 또는 "질의 보냄 · 10-24" 꼬리표, [질의 보냄 표시] / [되돌리기] | `/outputs`, 예정 `query_sent_at` | `add-query-sent` 전에는 꼬리표만 "질의 초안" |
| 문장 | 일탈 목록 문장 또는 질의 문장 + "AI 초안" 꼬리표 | `/outputs`의 `text_draft` | 고치기는 SCR-08-11 |
| 보증값 (보증값 작성만) | 보증값 후보 + 단위, [데이터시트에서 쓰기] | `/warranty` | 이 화면에서 값을 쓰지 않는다 |

## 화면 상태

- 로딩 중: 머리와 비교 칸은 판정 응답으로 먼저, 원문 줄 자리는 회색 줄.
- 데이터 없음: 판정 번호가 이 검토에 없으면 "이 검토에 없는 판정입니다" + 판정 목록으로.
- 오류: 원문 줄만 실패하면 그 영역에 오류 문장과 다시 불러오기, 나머지는 그대로.
- 권한 없음: 엔지니어가 아니거나 담당자 확인 단계가 아니면 "판정 바꾸기·제안대로 확정·질의 보냄 표시"를 비활성화하고 이유(예: "승인 대기 중에는 고칠 수 없습니다").

## 입력 검증

- 바꾸는 사유: 필수, 앞뒤 빈칸 뺀 1~500자. 비었으면 "판정을 바꾸려면 사유를 적어 주세요."
- 새 판정이 지금 판정과 같으면 적용 비활성화.

## 목업에 있지만 만들지 않는 요소

- 비슷한 요구의 과거 결과(수주·실주, 입찰 이력에서 보기): 입찰 결과는 범위 밖(Q6). 대신 "지난 확정" 영역을 보인다.
- 번역: 명세서에 없음. AI 번역은 숫자 대조가 필요해 다음 단계.

## 수용 기준 (Given / When / Then)

- **Given** 일탈 후보 판정 2줄이 있는 검토의 판정 목록, **When** 첫 줄을 누르면, **Then** 주소가 `#/reviews/<id>/judgments/<jid>`가 되고 "판정 1 / 2", 요구값·제품값·비교 방향이 보인다. (판정 상세 화면 열기)
- **Given** 판정 상세 화면, **When** ↓ 키를 누르면, **Then** 같은 거르기의 다음 판정이 보이고, Esc를 누르면 같은 쪽의 판정 목록으로 돌아간다. (이전·다음과 목록으로)
- **Given** 원문 위치가 두 곳인 판정, **When** 두 번째 위치 탭을 누르면, **Then** 그 위치의 줄 번호와 앞뒤 줄이 보이고 그 줄이 강조된다. (위치 탭과 원문 앞뒤 줄)
- **Given** 팀 가정 비교값으로 한 판정, **When** 화면을 열면, **Then** 제품값 출처 옆에 "팀 가정"이 보인다. (팀 가정 표시)
- **Given** 요구사항을 AI가 찾은 판정, **When** 화면을 열면, **Then** 판정 출처에 "AI가 찾음"과 신뢰도가 보인다. (찾은 방법과 신뢰도)
- **Given** 담당자 확인 단계의 질의 후보, **When** 엔지니어가 "질의 보냄 표시"를 누르면, **Then** 꼬리표가 "질의 보냄 · 오늘 날짜"가 되고 판정 목록 줄에도 같은 꼬리표가 보인다. (질의 보냄 표시)
- **Given** 승인 대기 단계 검토, **When** 판정 상세를 열면, **Then** 판정 바꾸기·제안대로 확정이 비활성화되고 이유가 보인다. (단계 때문에 못 고침)
- **Given** 판정 바꾸기 창, **When** 사유를 비우고 적용을 누르면, **Then** "판정을 바꾸려면 사유를 적어 주세요."가 보이고 판정은 그대로다. (사유 필수)
