## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 제목(`.ttl`) | 사업 현황, RFP 등록 | — | RFP 등록은 검토 등록 화면으로 |
| 요약(`.sh-sum`) | 진행 중 사업, 3일 내 제출 마감, 마감 지남 | `summary.open`, `due3`, `overdue` | 범위(내 사업·팀 전체)를 따른다. 등록 전 범위 칸은 없음 |
| 머리 줄 | 사업 n, 내 사업 · 팀 전체 | `scope` | 내 사업 = 머리글에서 고른 사용자 기준 |
| 찾기(`.sp`) | 1줄: 왼쪽 제출 마감(전체·3일 안·7일 안), 오른쪽 상태(진행 중·제출 완료·전체)·국가. 2줄: 검색 대상, 검색어, 초기화, 검색 | | 화면에서 거른다. 검색 단추나 Enter를 눌러야 적용(목업과 같음) |
| 목록(`.sh-box`) | 순번, 사업명 + 사업 번호, 고객사 · 국가, 고객 입찰 번호, 제출 마감(D-n, 날짜), 범위별 상태 칩, 내 역할, 영업 | `business_name`, `business_no`, `customer_name`, `country`, `tender_no`, `days_left`, `due_date`, `ranges[].state`, `my_role`, `sales_name` | 마감 가까운 순. 칩에 마우스를 올리면 설비 범위 · 담당 · 협조 미확인 수. 줄을 누르면 사업 상세 |

- 범위 상태 칩: 분석 중 · 분석 실패 · 판정 확인 · 협조 대기 · 결재 대기 · 반려(빨강) · 제출 준비 · 제출 완료. 서버가 계산한다(`business-status` 범위별 진행 상태 계산).
- 사업 마감이 비면 연결 검토 중 가장 이른 마감을 쓴다.
- 처리 중인 검토가 있으면 5초마다 다시 부른다.

## 수용 기준 (Given / When / Then)

- **Given** 자기 검토가 연결된 사업, **When** 엔지니어가 사업 현황을 열면, **Then** 예시 띠 없이 그 사업 줄이 범위 상태 칩, 내 역할 "엔지니어"와 함께 보인다. (사업 현황 열기)
- **Given** 반려된 검토가 연결된 사업, **When** 사업 현황에서 보면, **Then** 범위 칩이 빨간 "반려"이고 마우스를 올리면 범위 · 담당이 보인다. (반려 칩)
- **Given** 사업 현황, **When** "팀 전체"를 누르면, **Then** 고른 사용자와 관계없는 사업도 보인다. (팀 전체)
