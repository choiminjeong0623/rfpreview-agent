# SCR-21 공지사항: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 작성자·본문의 사람 이름, "팀장(사람 이름)" | 역할 이름 (결재자, 기술 검토 엔지니어 A~D), "팀장" | 사람 이름을 넣지 않는 규칙 |
| 2 | "신규 입사자 소개 — (이름) (11-02 합류)" | "신규 입사자 소개 (11-02 합류)", 본문 "신규 입사자 1명" | 같은 이유 |
| 3 | 회고 글의 검토 이름 지명 | "예시 사업장 D" | 지명을 넣지 않는 규칙 |
| 4 | 맨 위에 띠 없음 | 예시 띠 | 게시판 API가 없다 |
