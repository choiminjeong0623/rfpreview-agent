# 화면 명세: SCR-20 팀 현황

- 연결 요구사항: 없음 (범위 밖)
- 기준 목업: `Spec2Win_목업_v4.57.html#Team`
- 구현 방식: 예시 화면 (`add-example-screens`). 데이터는 `frontend/src/examples/SCR-20.ts`, 화면은 `frontend/src/views/examples/Team.tsx`, CSS는 목업 Team CSS 그대로
- 사용 API: 없음

## 화면 구성

| 영역 | 보이는 항목 | 데이터 칸 | 비고 |
|---|---|---|---|
| 예시 띠 | 예시 화면 · 실제 데이터와 연결되지 않음 | — | |
| 제목 | 팀 현황, 팀 이름 · 인원 · 기준일 | — | |
| 요약(`.sh-sum`) | 진행 중 검토, 3일 내 마감, 마감 경과, 도움 요청, 지금 접속 | 팀원 합계 | 도움 요청은 의견을 남기면 줄어든다(화면 안에서만) |
| 팀원별 진행(`.sh-box`) | 팀원(역할 이름, 맡은 일, 접속 상태), 진행 중, 단계별 막대, 3일 내 마감, 마감 경과, 그 밖의 일 · 부재 · 도움 요청 | `EXAMPLE_TEAM` | 줄을 누르면 실제 검토 목록 |
| 범례(`.tm-lg`) | 분석 중 · 판정 확인 · 협조 대기 · 결재 대기 · 제출 준비 | — | |
| 도움 요청 | 검토, 묻는 것, 요청한 사람 · 시각, 검토 열람, 의견 남기기 | `EXAMPLE_HELP` | 의견 남기기는 "의견 남김" 표시만 |

## 수용 기준 (Given / When / Then)

- **Given** 왼쪽 메뉴, **When** 팀 현황을 열면, **Then** 예시 띠와 팀원 6명, 도움 요청 1건이 보인다. (예시 띠)
- **Given** 의견 남기기를 누른 뒤, **When** 다른 화면에 갔다 오면, **Then** 도움 요청이 다시 1건이고 단추가 눌린다. (저장하지 않음)
