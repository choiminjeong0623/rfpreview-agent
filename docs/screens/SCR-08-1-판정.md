# 화면 명세: SCR-08-1 판정 탭 (+ 검토 상세 요약 칸·탭 줄)

- 연결 요구사항: FR-07·08·09·10, `review-workspace` 검토 상세 요약 칸과 탭·판정 표 거르기·판정 상세 패널, `review-run` 판정 목록 거르기와 판정 순서·판정 칩 건수
- 기준 목업: `Spec2Win_목업_v4.57.html#Detail` 판정 탭, 판정 줄을 누르면 뜨는 판정 상세 창. **v4.96부터 `Spec2Win_목업_v4.96.html`이 기준**(맨 아래 "v4.96 바뀐 점")
- 구현 방식: 실제 (`update-review-screens` 묶음 1)
- 사용 API: `GET /runs/{id}/judgments?order=priority&result&unconfirmed&q&type_code&offset&limit`(X-Total-Count), `GET /runs/{id}/judgment-counts`, `GET /runs/{id}/warranty`, `/outputs`, `/history`, `/documents`, `/approval`(review_ratio), `/losses`, `GET /requirements/{id}`, `POST /runs/{id}/actions`, `GET /runs/{id}/checks`(공학 검산 표시, update-check-display), 판정 목록 `past=differs`·`past_decision`과 칩 건수 `past_seen`·`past_differs`(지난 확정 힌트, add-review-memory)

### 수용 기준 (v4.96)

> **11-03 결정: 아래 처음 세 기준(꼭 볼 것 칩, 꼭 볼 것을 다 봤을 때, 같은 검토 안 수정 줄)은 기능 동결(11-04) 전에 만들지 않고 다음 단계로 미룹니다.** 지금 판정 탭에는 세 기능이 없어 추적표가 0 / 3입니다. 대신 "꼭 볼 것" 수는 검토 상세 머리글 요약 칸에 보이고, 판정 표는 일탈 → 질의 → 확인 필요 순서로 정렬됩니다.

- **Given** 꼭 볼 것 12줄인 검토, **When** 판정 탭을 열면, **Then** "꼭 볼 것" 칩이 켜져 있고 일탈·질의·확인 필요 줄만 12줄 보인다. (꼭 볼 것 칩)
- **Given** 꼭 볼 것 12줄을 모두 확정하고 준수 45줄이 남은 검토, **When** 판정 탭을 열면, **Then** "남은 것은 준수 45줄 확정입니다." 안내가 보인다. (꼭 볼 것을 다 봤을 때)
- **Given** 이 검토에서 사람이 판정을 바꾼 줄 1개, **When** "지난 수정 있는 줄만"을 켜면, **Then** 그 줄만 보인다. (같은 검토 안 수정 줄)
- **When** 판정 검색어에 "busbar"를 적고 [검색]을 누르면, **Then** 항목·원문에 busbar가 든 줄만 남고 1쪽으로 간다. (검색 단추)
- **When** 줄을 누르면, **Then** 판정 상세 화면 주소로 바뀐다(SCR-08-12). (줄 누르면 판정 상세 화면)
