# SCR-08-6 상업 조건 탭: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 요약 칸에 짧은 한국어 요약("주당 계약금액의 0.5 % · 상한 10 %") | 값(원문 문자열 그대로) + 원문 문장 | 요약을 쓰려면 언어 모델이 문장을 바꿔 써야 한다. 금액·단위를 바꾸지 않는다(CR-10) |
| 2 | 고르기 칸과 "골라서 전달" | 없음. 협조 요청 상태와 "협조 요청 현황" 연결 | 메일 보내기는 협조 요청(SCR-13, update-role-handoff-mail) 한 곳에서 한다 |
| 3 | 담당 고르기(견적/영업) | "견적 담당" 고정 | 비용 조건은 모두 견적 담당(유형 → 담당 규칙). 같은 요청이 두 곳으로 가지 않게 |
| 4 | 회신 내용(시각 · 글) | 상태만(안 보냄·회신 대기·회신 받음). 회신 요지는 협조 요청 화면 | 회신 요지는 협조 요청에 저장된다 |
| 5 | 상태 "미전달·전달·확인·회신" | "안 보냄·회신 대기·회신 받음·협조 요청 없음" | 협조 요청 상태 이름과 같게. 주 유형이 비용 영향이 아닌 줄(예: 시험 입회)은 협조 요청이 없다 |
| 6 | 상업 영향 "옵션 가격", "납기 영향" | "손실 환산 가산액", "일탈 가격 영향" | 옵션·납기는 판단할 데이터가 없다. 있는 결과(FR-13, FR-09)만 읽는다 |
| 7 | 종류 칩 없음 | 종류 칩(건수) | 실제 RFP는 줄이 수백 개라 거르기가 필요하다 |
| 8 | 상신 전 확인의 "상업 조건 미전달 n건" 줄 | 넣지 않음 | 승인 기준(AR)에 없는 항목이다 |
| 9 | 통화 "VND 허용" 등 예시 문구 | 실제 RFP 원문 | 예시 데이터를 지웠다 |
