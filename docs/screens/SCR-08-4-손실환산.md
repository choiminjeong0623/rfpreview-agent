# 화면 명세: SCR-08-4 손실 환산 탭

- 연결 요구사항: FR-13, `review-workspace` 손실 환산 탭, `review-run` 손실 환산 종류별 가산액, `loss-evaluation`
- 기준 목업: `Spec2Win_목업_v4.57.html#Detail` 손실 환산 (참고) 탭 (`#loss`)
- 구현 방식: 실제 (`update-review-screens` 묶음 3)
- 사용 API: `GET /runs/{id}/losses`(`amounts`, `price_locations`), `PUT /runs/{id}/losses/{loss_calc_id}`, `GET /runs/{id}/documents`
- 예정 API: 없음

## 화면 구성

| 영역 | 보이는 항목 | API 칸 | 비고 |
|---|---|---|---|
| 머리 (`.sech`) | "손실 환산 (참고값)" + "단가 a~b행 · 손실값은 팀 가정", "견적 담당에 협조 요청"(비활성) | `price_locations[].line_start`, `is_assumed` | |
| 안내 (`.lsnote`) | 조항이 있을 때만 계산하는 변압기 참고값, "이 RFP는 <조항 위치>에 단가가 있어 계산", 콘덴서·전기실 전체 손실은 계산 안 함 | `locations[0]` | 조항이 없으면 "이 RFP에는 손실 환산 조항이 없어 계산하지 않았습니다." |
| 제품 줄 | "비교 제품 X" (없으면 "없음"), 팀 가정 배지 | `product_code`, `is_assumed` | 손실 환산이 여럿이면 조항 위치도 |
| 표 (`table.mini`) | 무부하·부하·보조 손실: 단가 $/kW ×, 손실값 kW 입력, 가산액(없으면 "입력 필요") / 가산액 합계 | `price_*`, `loss_*_kw`, `amounts`, `total_usd` | 금액은 백엔드가 계산한 값만 (CR-01) |
| 표 아래 | 계산하지 않은 이유 (비교 제품 없음, 손실값 없음, 단위가 $/kW 아님) | `reason_code` | |

## 화면 상태

- 데이터 없음: 안내 칸에 "이 RFP에는 손실 환산 조항이 없어 계산하지 않았습니다."
- 권한 없음: 손실값 칸 비활성화 + 툴팁

## 사용자 동작 → 시스템 반응

| 동작 | 누가 | 호출 API | 성공 시 | 실패 시 |
|---|---|---|---|---|
| 손실값 넣고 칸을 나가거나 Enter | 엔지니어(담당자 확인) | `PUT /losses/{id}` 세 값 | 줄 가산액·합계·요약 칸 갱신, 팀 가정 배지 | 0 미만·숫자 아님은 보내지 않고 문장, API 오류는 표 아래 문장 |
| 견적 담당에 협조 요청 | — | — | 비활성. 툴팁: 입찰 영향 탭에서 손실 환산 제안 포인트를 채택하면 견적 담당에게 간다 | — |

## 입력 검증

- 손실값: 비워 두면 값 없음(null), 0 이상의 숫자. 단위는 kW 고정(단위 환산 안 함).

## 수용 기준 (Given / When / Then)

- **Given** 단가 행이 있고 비교 제품이 없음, **When** 손실 환산 탭을 열면, **Then** 세 줄에 단가, 빈 손실값, 합계 "—". (손실 환산 표)
- **Given** 같은 실행, **When** 엔지니어가 60·300·8 kW를 넣으면, **Then** 줄마다 가산액과 합계 $1,240,400, 팀 가정. (손실값 넣어 다시 계산)
- **Given** 조항이 없는 실행, **When** 탭을 열면, **Then** 계산하지 않았다는 안내. (조항 없는 RFP)
