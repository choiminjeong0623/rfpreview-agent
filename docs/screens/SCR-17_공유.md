## 팀에 알릴 것

- 화면에서 고친 규칙은 DB가 원본이다(10-29 결정). `data/seed` CSV는 시작값이고, `rfp-db setup`·`seed-rules`로 다시 적재해도 화면 고침이 남는다. CSV만 남기려면 `rfp-db seed-rules --reset-edits`(이력은 "버림"으로 남음).
- 규칙을 고치면 사전 판이 바뀌어 다음 검토는 문서를 다시 처리한다(시간이 더 걸림). 지난 검토 결과는 그대로다.
- 지운 비교 방향·위험 표현·표준 항목은 지우지 않고 끈다(지난 결과의 근거). 같은 키로 다시 추가하면 되살아난다.

- 개발 DB의 RFP는 표 이름(TS-115-GIS)은 사전과 같지만 항목 번호가 달라서, 비교 방향 사전 줄이 한 번도 쓰이지 않았다(쓴 판정 모두 0). 판정은 항목 기본 방향으로 돌아간다. 사전은 원래 RFP 파일의 표 번호에 맞춰져 있다.
