# 화면 명세: SCR-06 검토 목록

- 연결 요구사항: FR-10, `review-workspace` 검토 정보 입력과 표시 (`add-review-info`)
- 기준 목업: `Spec2Win_목업_v4.57.html#Main`
- 구현 방식: 실제
- 사용 API: `GET /api/runs?limit=200`, `GET /api/users`
- 화면 주소: `#/reviews`

## 화면 구성

| 영역 | 보이는 항목 | API 칸 (`api.ts`) | 비고 |
|---|---|---|---|
| 제목 줄 | "검토 목록", 기간(1주·1개월·전체) + 기간 글자, "검토 등록" | `started_at` | 기간은 오늘 기준 7일·31일 |
| 요약 줄 | 내가 처리할 건, 결재 대기, 분석 실패 | `stage`, `engineer_id` | 내가 처리할 건 = 담당자 확인 + 담당이 나. 아래 담당 범위 안에서 센다. "결재 대기 n"을 누르면 찾기 상자 단계가 결재 대기로 바뀌고 바로 적용 |
| 구획 머리 | "검토 n", 담당 범위(내 검토·팀 전체·내가 올린 결재), 담당자 고르기(다른 엔지니어, 건수) | `engineer_id`, `requested_by_id` | 담당자를 고르면 "…의 검토를 보고 있습니다" 안내 |
| 결정 칩 (내가 올린 결재만) | 전체·결재 대기·반려·승인 + 개수 | `requested_at`, `decision` | 머리글 사용자가 가장 최근에 상신한 검토만(취소한 상신 빠짐). 개수는 기간·찾기를 적용한 뒤의 수. `#/reviews?scope=submitted`로 바로 열림(홈 링크) |
| 찾기 상자 | 단계, 있는 항목(전체·요구사항·위험·일탈·제안), 검색 대상(전체·검토명·번호·파일명), 검색어, 초기화, 검색 | | 검색 단추나 Enter를 눌러야 적용 (목업과 같음) |
| 표 | 순번, 단계 배지, 사업명, 설비 범위(검토명 + 꼬리표, 아래 번호·고객사·파일·담당·열람), 마감(D-n + 날짜), 시작, 요구사항, 위험, 일탈, 제안, 메뉴 | `stage`, `project_name`, `review_name`, `files`, `review_no`, `customer_name`, `engineer_name`, `due_date`, `requirements`, `risks`, `deviation_candidates`, `proposals` | 시작·요구사항·일탈은 눌러서 정렬 (기본 시작 내림차순) |
| 결재 칸 (내가 올린 결재만) | 결재자 이름, "상신 n일째" 또는 "반려·승인 MM-DD HH:mm" | `approver`, `requested_at`, `decision`, `decided_at` | 다른 담당 범위에서는 표 모양이 그대로 |
| 아래 | 페이지 번호, 10·20·50개씩 | | |

- 검토명이 비면 첫 파일 이름을 보인다. 마감이 비면 마감 칸을 비운다.
- 처리 중: "<단계> 중 n%" 꼬리표(백분율은 SCR-02와 같은 계산), 개수는 `—`. 처리 중인 검토가 있으면 5초마다 목록을 다시 부른다. 처리 실패: 빨간 이름 + "<실패 단계>에서 멈춤" 꼬리표, 위험·일탈·제안은 `—`.
- 승인됨·반려됨 줄은 흐리게(`.dis`). 승인됨의 마감 칸은 "완료", 반려됨은 `—`.
- 담당이 내가 아닌 줄은 "열람" 꼬리표.

## 화면 상태

- 로딩 중: 표 안에 "불러오는 중…" 한 줄.
- 데이터 없음: 표 아래 "조건에 맞는 검토가 없습니다." 내가 올린 결재에서 상신한 검토가 하나도 없으면 "내가 상신한 검토가 없습니다."
- 오류: 찾기 상자 아래 오류 문장 + "다시 불러오기".

## 수용 기준 (Given / When / Then)

- **Given** 마감일이 3일 뒤인 검토, **When** 검토 목록을 열면, **Then** 그 줄에 검토 번호, 사업명, 검토명, 고객사, 담당 엔지니어, "D-3"과 개수 4개가 보인다. (목록에서 마감 보기)
- **Given** 검토 정보 없이 시작한 검토, **When** 목록에서 보면, **Then** 검토명 자리에 첫 파일 이름이 보이고 마감 자리는 비어 있다. (검토명이 빈 검토)
- **Given** 엔지니어가 검토 두 개를 상신하고 하나가 반려됨, **When** "내가 올린 결재"를 고르면, **Then** 두 검토만 보이고 결재 대기 1 · 반려 1, 각 줄에 결재자 이름이 보인다. (내가 올린 결재 보기)
- **Given** 다른 사람이 상신한 검토, **When** "내가 올린 결재"를 고르면, **Then** 그 검토는 보이지 않는다. (다른 사람이 올린 결재)
- **Given** 결재 대기 검토 2개, **When** 요약 줄 "결재 대기 2"를 누르면, **Then** 결재 대기 검토 2개만 보이고 찾기 상자 단계가 결재 대기로 바뀐다. (요약 줄로 결재 대기 거르기)
