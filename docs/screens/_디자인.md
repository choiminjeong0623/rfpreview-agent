# 디자인 기준

목업 v4.57의 모양을 코드로 옮기는 규칙. 색·글꼴·간격을 새로 정하지 않고 **목업 CSS를 그대로 가져온다**.

## 1. 목업 CSS를 쓰는 법

- 목업은 화면마다 `<head>`에 CSS 전체(32~50 KB)를 따로 갖고 있다. 앞부분(앱 틀·버튼·표)은 대부분 같고, 화면별 규칙이 뒤에 붙는다.
- `frontend/src/mockup/<화면 키>.css`에 목업 화면의 CSS를 **고치지 않고** 옮긴다. 바뀌는 것은 두 가지뿐이다.
  - 글꼴 주소 `/_blob/7520ad76…` → `/fonts/PretendardVariable.woff2`
  - 아이콘 글꼴 `<link>`는 `index.html`로 옮긴다.
- `mockup/Main.css`(검토 목록)를 앱 전체의 기본으로 `main.tsx`에서 불러온다. 앱 틀(왼쪽 메뉴·머리글)은 이 CSS로 그려진다.
- 다른 화면의 CSS가 Main과 다른 규칙을 가질 때는(예: Detail, Products, Home) 그 화면을 만들 때 그 화면이 보이는 동안만 화면 CSS를 붙인다. 모든 화면 CSS를 한꺼번에 불러오면 같은 클래스 이름(`.tbl`, `.card` 등)의 규칙이 서로 덮어쓰기 때문이다.
- 목업에 없는 모양이 필요하면 목업 CSS를 고치지 않고 화면 폴더의 작은 CSS(예: `shell/shell.css`)에 더하고, 그 이유를 화면의 `SCR-xx_공유.md`에 적는다.
- 예전 탭 화면과 `index.css`의 `.legacy` 모양은 모든 화면을 목업대로 다시 만든 뒤 지웠다 (`update-review-screens` 묶음 15).
