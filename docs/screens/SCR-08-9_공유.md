# SCR-08-9 이력 탭: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 사람 이름에 직급 ("최민정 대리") | 사용자 이름만 | 직급이 없다 (`_공통규칙.md` 2장) |
| 2 | '위험 조건 "주위 온도"를 정상으로 닫음' | '위험 조건 "표현" 문제 없음으로 닫음' | 상태 라벨은 API(`CLOSED_OK` 문제 없음). 이름 뒤 조사(을/를)는 붙이지 않는다 |
| 3 | "SF6 가스 누설률 확인 필요 유지, 품질팀에 값 요청"처럼 자유 문장 | 기록 종류별로 정한 문장 | 문장은 기록 값으로만 만든다 (AI 안 씀) |
| 4 | 결재 상신의 의견 표시 없음 | "의견: …" | 상신 의견·결재 의견도 이력이다 |
| 5 | 판정 생성 줄의 시각 = 처리 시작 | 처리가 끝난 시각 | 판정이 만들어진 때는 실행이 끝난 때다 |
