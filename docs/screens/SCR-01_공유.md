# SCR-01 로그인: 목업과 다르게 만든 것 (공유)

| # | 목업 | 앱 | 이유 |
|---|---|---|---|
| 1 | 앱의 첫 화면 | 주소 `#/login`으로만 연다. 로그인을 눌러도 계정을 확인하지 않고 홈으로 간다 | 앱에는 로그인이 없고 머리글에서 사용자를 고른다 (`add-example-screens` design.md) |
| 2 | 로그인 뒤 "최민정 대리 · 기술 검토 엔지니어" | 머리글에서 고른 사용자의 이름 · 역할 | 사람 이름을 넣지 않는 규칙. 홈으로 바로 가서 거의 보이지 않는다 |
| 3 | 소개 그림 "돈으로 본다"의 "평가 가격 +$1,240,400"과 계산기 숫자 | "평가 가격 영업 권한 필요", 계산기 숫자는 "$•,•••,•••" | 금액은 영업 권한이 필요한 값으로 가린다 |
| 4 | 글자 크기를 브라우저에 기억 | 이 화면 안에서만 바뀐다 | 예시 화면은 브라우저에도 저장하지 않는다 |
| 5 | "요청을 보냈습니다" 안내 | 뒤에 "(예시 화면이라 실제로 보내지 않습니다)" | 요청을 받을 곳이 없다 |
| 6 | 띠 없음 | 띠 없음 (같음) | 로그인 화면은 앱 틀 밖이라 예시 띠를 넣지 않았다. 대신 위 1~5를 이 문서에 적는다 |
| 7 | 로그인 탭 줄 여백 | 같게 보이도록 앱 틀 CSS의 `.tabs` 여백만 지운다 | 앱 틀 CSS가 늘 깔려 있어 겹친다 |
